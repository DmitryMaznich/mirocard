# Исходные слоги для проверки прописей

21 исходная запись Google Cloud TTS `ru-RU-Wavenet-A`, скорость 0.7,
создана 09.10.2026. Текст: согласная + «а», для Й — «я».
Это исходники, а не готовые записи для диктанта.

Границы извлечения в `scripts/lib/propis-phoneme-bank.mjs` относятся
именно к этим файлам. Генератор сохраняет их, чтобы повторный запуск
не смещал границы из-за нового ответа синтезатора. При замене исходника
необходимо заново определить границу до начала гласного.
