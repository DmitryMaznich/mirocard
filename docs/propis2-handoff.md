## Ключевые технические факты (чтобы не открывать заново)

- Флаги строки движка: хвост `#`-цепочка `[dc1fsorx]|[ig]\d+`: `d` лишние точки, `c` без точек, `o` только точка образца, `1` один раз, `f` затухание копий до середины строки (подразумевает размножение), `s` бледные сплошные копии, `r` принудительное размножение, `x` скрыть копии (точки остаются), `iN` отступ N клеток, `gN` N клеток между копиями. `_N` — N лишних клеток перед следующим словом.
- Модель строки: `{id, kind: text|element|passage|blank, text, mark, marked, repeat: all|one|fade|"auto", dots: all|one|none, copies: dash|solid, asText, gap}`; `rowToLine`, `rowParams`, `pageToLines`, `wrapPassage` (перенос по сетке с `pageSnap`).
- Геометрия: A5 148,5×210 парами, A4 210×297; поля чередуются по чётности; узкая разлиновка 17 строк (A4 24), широкая 16 (23); `narrow17`.
- Страница: `{ruling, grid, gridKind, midDash, writeAfter, margin, format, locked, presetId, kitId, rows}`; набор (`set`) со `pageIds`, `ruling`, `kit`.
- Синхронизация: документы `propis2:page:*`, `propis2:set:*`, `propis2:preset:*` через `kv.upsert` и `GET /account/kv?prefix=propis2:`, last write wins по `updatedAt`, tombstones в `library.deleted`; `syncLib.js` (`diffOps`, `mergeRemote`, `snapshotDocs`).
- Особенности глифов Прописи 2 в `glyphOverrides.js`: соединение отделяется у о, ю, ф, в (`tailSplit`), б, э (`tailStroke`); без с х ж.
- Из `wide.json` буквы г п р л м я хранятся как «элементы» (г1, п1 с алиасами); в плитках элементов их скрывает `LETTER_NAMES` в `Propis2Carousel.jsx`.
