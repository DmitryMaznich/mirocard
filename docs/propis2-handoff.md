## Открытые вопросы и ближайшие шаги

1. Дождаться оценки цифр владельцем (пропорции, сглаживание, знаки, промежутки), при необходимости подкрутить `build_digit_glyphs.py` и пересобрать. После «Заливай» влить.
2. Владелец спросил, почему в тетради нельзя страницы с разной сеткой. Честный ответ: это моё упрощение, не ограничение данных; движок принимает одну геометрию на документ. Предложено: (a) постраничная бумага в редакторе, (b) раскладка по секциям (подряд идущие страницы с одной бумагой), формат A4/A5 оставить на уровне тетради. Ответа нет; до него «бумага общая на тетрадь» не менять.
3. Короткие коды элементов `{э1}…` зависят от порядка в колоде: при вставке элемента в середину номера в поле сдвинутся (страницы не пострадают). Если нужна жёсткая привязка кода к символу, нужно поле `code` в данных колоды. Решает владелец.
4. Из старого списка: у1, у2, в1 в списке элементов (оставить?); спорные соединения (а, е, д, з, у, ч, ы, ц, щ — хвост считается частью буквы); С Х Ж намеренно НЕ отделяются; заглавные Ё Й Ы в наборе нет; красные точки на страницах «с образцом» (по всей строке или только у образца); проверка клавиатуры, копирования/вставки и жеста «назад» на реальном iOS/Android не делалась (только эмуляция); тетрадь с точками, чистые тетради, обложки, пунктуация (отложено).
5. Бэклог: номер страницы и водяной знак при печати/PDF; A4 на телефоне и боковая раскладка; индикатор «синхронизировано».

## Ключевые технические факты (чтобы не открывать заново)

- Флаги строки движка: хвост `#`-цепочка `[dc1fsorx]|[ig]\d+`: `d` лишние точки, `c` без точек, `o` только точка образца, `1` один раз (связный текст, без копий), `f` затухание копий, `s` бледные сплошные копии, `r` принудительное размножение, `x` скрыть копии, `iN` отступ, `gN` клетки между копиями. `_N` — N лишних клеток перед следующим словом.
- Модель строки: `{id, kind: text|element|passage|blank, text, mark, marked, repeat, dots, copies, asText, gap}`; `rowToLine`, `pageToLines`, `wrapPassage`. Страница `{ruling, grid, gridKind, midDash, writeAfter, margin, format, locked, presetId, kitId, rows}`; тетрадь (`set`) со `pageIds`, `ruling`, `title`, `sourceId`, `kit`.
- Геометрия: A5 148,5×210 парами, A4 210×297; узкая разлиновка 17 строк (A4 24), широкая 16 (23); узкая сдвинута вниз на 4,5 мм (`n17Shift`). Система координат глифов 300×150: база y=62, середина 36, верх 10; заглавная от y=−42. Движок растягивает любой глиф по x в 1,806 (`stretch`), сохраняя наклон.
- Свойства глифа в `glyphOverrides.js`: `tailSplit` + `tailSplitCount` (хвост = последние кубики), `tailStroke`, `tailLift`, `tailContinuous`, `joinFrom/joinLike/joinEndLike` (У), `joinAtStart` (соединение идёт к самому началу следующего глифа: ь, ъ), `joinStraight` (без изгиба на конце), `exitNudge` (на сколько единиц может сдвинуться конец хвоста, чтобы дотянуться до следующей буквы; по умолчанию 6), `noJoin` (цифры).
- Синхронизация: документы `propis2:page:*`, `propis2:set:*`, `propis2:preset:*` через `kv.upsert`, last write wins по `updatedAt`, tombstones в `library.deleted`; черновик на устройстве в IndexedDB `propis2:draft` (не синхронизируется).
- Системная «Назад»: у экрана с внутренней навигацией есть перехват (`setBackInterceptor`), возвращающий true, если «Назад» обработана; иначе приложение уходит на прошлый экран.
