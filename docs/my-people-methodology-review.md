# «Мои люди» (my_people): разбор логопеда и предложение по редизайну

2026-10-20. Второй проход после `docs/my-people-review.md` (2026-10-15): тот документ —
журнал правок, этот — оценка того, что получилось, глазами логопеда, работающего с
детьми с РАС (в том числе минимально говорящими), и предложение по интерфейсу.
Разбор сделан по коду текущего `main` (`src/topics/builtinMyPeopleTopic.js`,
`src/topics/renderers/my_people/engine.js`, `index.jsx`, `my_people.css`).
Макеты редизайна: `docs/mockups/my-people-redesign.html`.

Ничего из этого ещё не сделано в коде — это план.

## 1. Общая оценка

Лестница темы выстроена верно и совпадает с тем, как навык учат по ABA/VB-MAPP и в
отечественной логопедии для детей с РАС:

| # | Режим | Навык (вербальный оперант) | Чтение | Оценка |
|---|---|---|---|---|
| 1 | Найди такого же | сопоставление нетождественных фото (визуальное восприятие) | нет | авто |
| 2 | Покажи | понимание слова — слушатель (рецептивная идентификация) | нет | авто |
| 3 | Кто это? | называние — такт (экспрессивная речь) | нет | взрослый |
| 4 | Обо мне | ответ на вопрос — интравербал | нет | взрослый |
| 5 | Подпиши фото | глобальное чтение: слово ↔ фото | да | авто |
| 6 | Представься | связное высказывание, диалог, цепочка | нет | взрослый |

Сильные стороны, которые нужно сохранить при любом редизайне:

- безошибочное исправление в «Покажи»/«Найди такого же» (после промаха светится верное
  фото, ребёнок завершает пробу правильно);
- контроль позиции и повторов (не больше 2 подряд одного человека и одного места);
- лёгкое → трудное в дистракторах (питомец против людей в первом раунде);
- в «Обо мне» треть раунда — уже известные вопросы (чередование лёгких и трудных);
- «Знает» недоступна после любой подсказки — данные честные;
- вопросы строятся только из заполненных данных, адрес и телефон — только с явного «да»;
- «Озвучка» выключается в каждом режиме.

Главные пробелы — не в порядке режимов, а в трёх вещах:

1. **Нет критерия перехода.** Взрослый сам решает, когда переходить на поле 3, на
   «Кто это?», на «Начало фразы». Данные для этого уже собираются, но нигде не
   показываются как «следующий шаг».
2. **Неговорящий ребёнок упирается в «Кто это?».** Режимы 3, 4, 6 оцениваются только по
   устному ответу; на экране нет способа ответить выбором (AAC). Для значительной части
   детей с РАС лестница обрывается на режиме 2.
3. **Экран занятия смешивает ребёнка и взрослого.** Кнопки оценки (красная «Не знает»),
   кнопки подсказок, служебные надписи («ОБО МНЕ», «Перетащи имя на фото или нажми его,
   потом фото») стоят в той же зоне и того же веса, что и материал для ребёнка.

## 2. Разбор по режимам

### 2.1 «Найди такого же» (`match_same`) — оставить, добавить ступень

Верно: без слов, только нетождественные фото одного человека (перенос, а не
сличение картинок), механика «Покажи».

Поправить:
- **Нет ступени «одинаковые фото».** Ребёнку, который не справляется с нетождественным
  сопоставлением, нужен шаг ниже — тождественное (то же самое фото). Сейчас режим
  закрыт, если у людей по одному фото, хотя для тождественного сопоставления одного
  фото достаточно. Предложение: параметр «Образец» — `одинаковое фото` / `другое фото`
  (по умолчанию «другое», если фото хватает).
- **Ответ — касание фото внизу.** Для ребёнка, который ещё учится сопоставлять,
  понятнее перенести образец к паре (или нажать образец → нажать пару). Можно оставить
  касание, но образец должен «прилетать» к верному фото после ответа — так видно, что
  именно совпало.

### 2.2 «Покажи» (`show_me`) — оставить, доработать коррекцию и подсказку по задержке

Верно: «Где мама?», поле 2 → 4, 6–8 проб, слово ребёнка (`sentenceLabel`), знакомство
с новыми людьми.

Поправить:
- **После ошибки нет повторной пробы.** Стандартная процедура коррекции: модель («Вот
  мама») → *повтор той же пробы* (переносная проба, без подсказки) → другая проба →
  снова эта цель. Сейчас ошибка засчитывается и проба уходит навсегда. Предложение:
  после промаха вставлять ту же цель через 1–2 пробы (не оценивать повтор как
  самостоятельный ответ — только как «с подсказкой»).
- **Подсказка только после ошибки, но не после паузы.** У детей с РАС частая реакция —
  не ошибка, а отсутствие ответа. Нужна подсказка по задержке: через N секунд верное
  фото мягко подсвечивается (как при промахе) и проба оценивается «с подсказкой».
  Параметр «Подсказка через»: `нет` / `3 с` / `5 с` (по умолчанию 5 с). Это и есть
  «угасание подсказки по времени» (time delay) — основной приём безошибочного обучения.
- **Дистракторы после первого раунда случайные.** Лучше явная лестница по похожести:
  питомец ↔ человек → мужчина ↔ женщина / взрослый ↔ ребёнок → одного пола и возраста.
  Для этого в карточке человека не хватает только пола/возраста — можно выводить из
  `relation` (мама/бабушка/сестра — ж., брат/папа — м.), без новых полей.
- Похвала «Да, это мама!» — хорошо (называние цели закрепляет слово). Оставить.

### 2.3 «Кто это?» (`who_is_this`) — главный по значимости, требует больше всего работы

Верно: принимаются оба ответа («мама · Анна»), подсказка «Первый слог» → «Показать
ответ», вопрос всегда один — «Кто это?».

Ошибки и пробелы:
- **Раунд = каждый знакомый человек один раз.** При 2–3 знакомых — 2–3 пробы, та же
  проблема, что была в «Покажи» до 2026-10-15. Нужно 6–8 проб с повторами (тот же
  `pointTargetSequence`).
- **Прогресс делится случайно.** Ось выбирается случайно (`axis = random(name|relation)`),
  концепт — `person_naming:<id>:<axis>`, а вопрос и принимаемые ответы одни и те же.
  Один и тот же ответ «мама» попадает то в один концепт, то в другой — статистика по
  человеку размазана надвое. Концепт должен быть один на человека (`person_naming:<id>`)
  — с алиасом для старых данных.
- **Лестница подсказок только «от меньшей к большей».** Для *нового* слова у
  минимально говорящего ребёнка правильнее «от большей к меньшей»: сначала полная
  модель для эха («Это мама. Кто это?» → «мама»), потом первый слог, потом без
  подсказки. Предложение: параметр «Подсказка» — `сразу слово` / `по шагам` (по
  умолчанию «по шагам»); со временем — автоматически по истории человека (две
  ошибки подряд → для этого человека начинаем с модели).
- **Нет ответа для неговорящего ребёнка.** Нужна опция «Ответ выбором»: под фото
  2–3 озвучиваемые кнопки-карточки («мама», «папа», «Мурка») — как на коммуникаторе.
  Ребёнок нажимает — устройство произносит слово — это и есть такт через AAC. Оценка
  автоматическая. Слова — без опоры на чтение: на кнопке маленькая аватарка-символ
  (не фото этого человека, иначе это снова «Найди такого же»), подпись, озвучка.
- **Нет параметров.** Нужны хотя бы «Чьи фото» (как в «Подпиши фото») и «Ответ»
  (`голосом` / `выбором`).
- Подсказка «Первый слог» для имён с гласной («Ан…») — хорошо. Для слов из одного слога
  («брат», «кот») слог совпадает со словом — кнопку «Первый слог» тогда лучше
  заменять на «Первый звук» («Б…»).

### 2.4 «Обо мне» (`about_me`) — оставить, поправить формулировки и опоры

Верно: короткие фиксированные вопросы, разделы, приоритет незнакомых вопросов,
чередование «мальчик/девочка».

Поправить:
- **«Где ты живёшь?» → «В каком городе ты живёшь?».** Интравербальный вопрос должен
  иметь один ответ. На «Где ты живёшь?» ребёнок честно отвечает «дома», «в квартире»,
  «на улице Ленина» — и взрослому непонятно, ставить ли «Знает».
- **«Сколько тебе лет?» без визуальной опоры** (было в прошлом плане, не сделано).
  Первая подсказка — цифра и столько же пальцев (картинка руки), вторая — ответ.
  Пальцы — понятная детям с РАС и жестовая форма ответа.
- **Телефон целиком.** «+7 900 123-45-67» — непосильная строка. Учить по частям
  (цепочкой): ответ на экране разбит на группы, подсказка открывает их по одной.
  Отдельный параметр не нужен — просто показывать номер группами и озвучивать с паузами.
- **«Ты мальчик или девочка?»** — абстрактный вопрос; в ответ полезна опора выбором из
  двух картинок (мальчик / девочка). Это частный случай общего «Ответа выбором».
- **«Ответ выбором» для всего режима** (было в прошлом плане, не сделано): для вопроса
  о маме — 2 фото; для возраста — 2 цифры; для «мальчик/девочка» — 2 картинки; для
  фамилии/города — 2 слова (с озвучкой). Без этого режим недоступен неговорящему
  ребёнку, хотя сами вопросы ему по силам.
- Раздел «Безопасность» (адрес, телефон) стоит отрабатывать и вне экрана: добавить
  в описание режима совет «проверьте с незнакомым для ребёнка взрослым» — перенос
  навыка на другого собеседника здесь важнее всего.

### 2.5 «Подпиши фото» (`label_photos`) — оставить, поправить по чтению

Верно: семья — сначала роль, школа — сначала имя; тап-тап вместо перетаскивания;
параметры вместо семи режимов.

Поправить:
- **Слово озвучивается при касании** (`speak(answer.label)` в `startAnswerDrag`).
  Ребёнок, который не читает, решает задачу на слух — режим перестаёт проверять чтение.
  Нужен параметр «Озвучивать слово при нажатии» (по умолчанию вкл. — как опора на
  этапе знакомства; выключить, чтобы проверить чтение).
- **Слишком мелкие слова.** Подписи в ответах — 16 px, на фото в 3 колонки — 13 px, а
  весь альбом ещё и масштабируется вниз (`usePeopleAlbumScale`). Для глобального чтения
  слово должно быть крупным (от 28 px), одним шрифтом и регистром на всех экранах
  (роль — строчными: «мама»; имя — с заглавной: «Анна»).
- **Ошибка — только красная рамка** (было в прошлом плане, не сделано). Как в «Покажи»: после
  промаха подсветить фото, к которому относится слово. *Сделано в шаге 1.*
- **Экран знакомства пассивный** (было в прошлом плане, не сделано): «Дальше» — кнопка
  для взрослого. Ребёнок должен сам коснуться фото (первая безошибочная проба), после
  этого слово «приклеивается» к фото и озвучивается.
- **По умолчанию 4 фото** — много для начала. По умолчанию 2, дальше 3–4–6.
- Подсказка на экране «Перетащи имя на фото или нажми его, потом фото» — текст для
  взрослого на детском экране. Убрать; способ действия показывать анимацией (палец
  переносит слово) в первой пробе.

### 2.6 «Представься» (`introduce_self`) — оставить как продвинутый, добавить визуальную опору и прагматику

Верно: диалог вместо абстрактных ситуаций, один факт — одна реплика, угасающий
скрипт, адрес и телефон не попадают никогда.

Поправить:
- **Собеседника не видно.** «С тобой знакомится: Доктор» — только текст. Детям с РАС
  нужна визуальная опора: иллюстрация собеседника (учительница, мальчик, доктор) с
  пузырём реплики. Это же даёт материал для зрительного контакта/ориентации на
  собеседника.
- **Приветствие не требует ответа.** Сейчас «Здравствуй!» приклеено к первому вопросу.
  Первая реплика ребёнка должна быть ответным приветствием, и это главный
  прагматический навык режима: взрослому — «Здравствуйте!», ребёнку — «Привет!».
  Собеседники уже разные — осталось сделать приветствие отдельным шагом с правильным
  вариантом.
- **Нет встречного вопроса.** Разговор — это обмен: в конце «А тебя как зовут?» (ответ
  собеседника — «Меня зовут Оля») и прощание «Пока!»/«До свидания!». Это переводит
  режим от «отчёта о себе» к диалогу.
- **«Мой город — Москва»** — неестественная фраза (выбрана, чтобы не склонять). Лучше
  поле «Я живу в …» в «Личных данных» с готовой формой («в Москве») и фраза «Я живу в
  Москве». Без поля — оставить как есть.
- **Итоговое «Расскажи о себе»** — длинная цепочка из 3–4 фраз сразу. Учить обратной
  цепочкой: сначала взрослый говорит всё, кроме последней фразы, ребёнок заканчивает;
  потом ребёнок говорит две последние и т. д. Это можно сделать тем же угасающим
  скриптом: начало ответа на экране заполнено, последние фразы — пропуски.
- Уровень подсказки меняется вручную (параметр). Предложение: после 2 уроков подряд с
  «Знает» на всех репликах показывать на экране выбора режима «Попробуйте: Начало фразы».

### 2.7 Что добавить в тему целиком

- **Критерий перехода и «следующий шаг».** Стандарт — 80 % самостоятельных ответов в
  2–3 уроках подряд. На экране выбора режима показывать у режима отметку «Освоено» или
  «Следующий шаг: поле 3» — по данным, которые уже лежат в сессиях.
- **Перенос в жизнь.** В конце урока (экран итогов, для взрослого) — одна подсказка:
  «Спросите дома: “Где мама?” — пусть покажет на маму». Навык «узнаю на фото» без
  переноса на живого человека ребёнку с РАС мало что даёт.
- **Подкрепление.** Сейчас — только голос «Да, это мама!». Для части детей нужна
  короткая визуальная награда (2–3 с, без звука, отключаемая — у многих сенсорная
  чувствительность). Отключаемость важнее самой награды.

## 3. Итоговая лестница (предложение)

```
1. Найди такого же    одинаковое фото → другое фото
2. Покажи             поле 2 → 3 → 4, подсказка по задержке
3. Кто это?           ответ выбором (AAC) | голосом: модель → слог → сам
4. Обо мне            ответ выбором | голосом; разделы Я → Семья → Мой день → Безопасность
5. Подпиши фото       (если читает) 2 → 3 → 4 фото, озвучка слова вкл. → выкл.
6. Представься        приветствие → факты → встречный вопрос → прощание
```

Порядок разделов «Обо мне»: «Безопасность» (адрес, телефон) — самый трудный по памяти,
его лучше ставить последним, после «Мой день», а не третьим, как сейчас.

## 4. Редизайн (UI для детей)

Макеты — `docs/mockups/my-people-redesign.html` (открыть в браузере).

### 4.1 Принцип: две зоны — ребёнка и взрослого

Каждый экран режима делится на две зоны, которые не спутать:

- **Сцена ребёнка** (сверху, ~75 % высоты): фото, вопрос голосом, крупное слово.
  Ничего, что ребёнку не нужно, — никаких служебных надписей, капса, инструкций.
- **Панель взрослого** (снизу, отделена фоном и линией, ~25 %): подсказки и оценка.
  Спокойные, приглушённые кнопки одинаковой формы.

Почему: ребёнок с РАС нажимает самое яркое на экране. Сейчас самое яркое — красная
кнопка «Не знает» и зелёная «Знает». Красный на детском экране к тому же читается
как «плохо» и может расстроить.

### 4.2 Оценка взрослого

- Кнопки — светлые с цветной пиктограммой (✓ / ½ / ✕), а не сплошная красная/жёлтая/
  зелёная заливка. Цвет остаётся у иконки и рамки: взрослый узнаёт по цвету, ребёнка
  он не притягивает.
- Порядок: «Сам» — «С подсказкой» — «Пока нет» (слова без оценочности; «Не знает»
  звучит как приговор, если ребёнок читает или слышит).
- Подсказки — в той же панели строкой ступенек: «① Слово целиком  ② Первый слог
  ③ Ответ», пройденная ступень отмечается; так взрослый видит, на какой ступени
  ребёнок.

### 4.3 Фото — главный объект

- Фото крупнее и одинаковой формы во всех режимах: квадрат со скруглением 28 px,
  мягкая тень, белая рамка (как сейчас в «Покажи», но единообразно).
- Состояния: верно — зелёная рамка и галочка в углу; подсказка — бирюзовое мягкое
  свечение (как сейчас); остальные — приглушены до 35 %. Тряску в альбоме заменить
  на подсветку верного фото.
- В знакомстве фото занимает почти всю сцену.

### 4.4 Слова (чтение)

- Карточки-слова крупные: 30–34 px, жирный Nunito, высота 64 px, без масштабирования
  альбома вниз — если не помещается, уменьшать число фото, а не шрифт.
- Подпись под фото после верного ответа — тем же шрифтом и размером, что и карточка
  (ребёнок видит, что «это то же слово»).
- Капс и служебные надписи («ОБО МНЕ», «ПОЗНАКОМИМСЯ») убрать с детской сцены.

### 4.5 «Ответ выбором» (AAC)

Под фото — 2–3 кнопки-карточки высотой 88 px: символ + слово, по нажатию звучит
слово. Вид как у коммуникатора (белая карточка, толстая рамка, тень-«кнопка»),
чтобы ребёнок, пользующийся AAC, узнавал формат.

### 4.6 «Представься»

Слева — иллюстрация собеседника (круглый аватар 96 px), справа — пузырь реплики.
Ответ ребёнка — второй пузырь (справа, другого цвета), в нём угасающий скрипт:
полный текст → начало фразы → пустые «окошки» на месте слов. Так диалог виден как
диалог.

### 4.7 Экран выбора режимов — «лесенка»

Вместо списка — вертикальная лесенка из 6 ступенек с иконками: пройденные (освоено)
— с галочкой, текущая — выделена и подписана «Следующий шаг», недоступные — с
причиной словами («Нужно 2 человека с двумя фото») и кнопкой в настройки, как
делает `myPeopleReadiness` сейчас. Метка «нужно читать» у «Подпиши фото».

### 4.8 Палитра и шрифт

Тема остаётся в семье «грамотность»: кремовый фон `#fdfcf9`, акцент бирюзовый
`#4a9b8f`, верно `#22c55e`, ошибка `#ef4444` (только для рамки на 600 мс, не для
кнопок). Панель взрослого — `#f3f6f5` с верхней линией `#dfe9e6`. Шрифт Nunito
везде. Safe area: панель взрослого прибита к низу — `padding-bottom: calc(14px +
var(--app-safe-bottom, 0px))`.

## 5. Порядок работ (предложение)

Шаг 1 — ошибки и данные (маленькие правки движка, без нового интерфейса):
«В каком городе ты живёшь?»; «Кто это?» — 6–8 проб и один концепт на человека
(с алиасом старых концептов); раздел «Безопасность» последним; по умолчанию 2 фото в
«Подпиши фото»; подсветка верного фото вместо тряски в альбоме.
**Сделано 2026-10-20:**
- «Обо мне»: вопрос о городе — «В каком городе ты живёшь?» (и в подсказках настроек).
  В «Представься» вопрос пока прежний: его фраза-ответ меняется в шаге 5.
- Разделы «Обо мне» в порядке «Я» → «Семья» → «Мой день» → «Безопасность»
  (`ABOUT_ME_LEVELS`, параметр `levels` и порядок вопросов в первом раунде).
- «Кто это?»: раунд 6–8 проб через тот же `pointTargetSequence`, что в «Покажи»
  (поровну, не больше 2 подряд одного человека, повтор — на другом фото, если есть).
  Если знаком только один человек — одна проба: шесть «Кто это?» с одним ответом
  подряд — это эхо, а не называние. Концепт — `person_naming:<personId>`, без оси;
  старые записи `person_naming:<id>:<axis>` остаются в истории, подпись в итогах
  читает оба вида. Отдельной миграции старого прогресса нет.
- «Подпиши фото»: по умолчанию 2 фото (у скрытых старых режимов осталось 4).
- Альбом после промаха: тряски там на самом деле не было — была красная рамка на
  600 мс. Теперь рамка остаётся, а фото, к которому относится слово, светится и
  пульсирует (как в «Покажи»), слово остаётся выбранным; следующее касание
  светящегося фото завершает пару. Выбрали другое слово — свет гаснет.

Шаг 2 — коррекция и подсказка по задержке в «Покажи»/«Найди такого же»;
тождественное сопоставление в «Найди такого же»; параметр озвучки слова в «Подпиши
фото».
**Сделано 2026-10-20:**
- Параметр «Подсказка через» (`promptDelay`: нет / 3 / 5 секунд, по умолчанию 5) в
  «Покажи» и «Найди такого же». Ребёнок молчит — верное фото светится, остальные
  бледнеют и не нажимаются, голос «Вот мама.» («Смотри, вот.»). Учёт как у промаха
  (`onStreakReset`: серия звёзд сбрасывается, концепт попадает в ошибки), потому что
  ответ не самостоятельный; отдельной оценки «с подсказкой» в авто-режимах нет.
  Нажатие на динамик «повторить» запускает ожидание заново.
- Повтор после помощи: найдено только после промаха или подсветки →
  `onCorrect(..., { retryLater: true })` → `useSessionEngine` вызывает
  `insertRetryTrial` (engine): та же проба через 1–2 другие (не создавая трёх
  одинаковых людей подряд), фото переставлены, без подсветки. Повтор оценивается как
  обычная проба и сам больше не повторяется. Если промах был в конце раунда — повтор
  закрывает раунд.
- «Найди такого же»: параметр «Образец» (`sample`: одинаковое фото / другое фото, по
  умолчанию другое). «Одинаковое» — тождественное сопоставление, хватает одного фото
  у человека. В списке режимов режим теперь открыт уже при двух людях с фото, а
  проверка «нужно по 2 фото» — на экране параметров для «Другое фото».
- «Подпиши фото»: параметр «Озвучивать слово при нажатии» (`speakWords`, по
  умолчанию вкл.). Выключен — слово при выборе не звучит, ребёнок читает сам;
  «Это мама.» после верной пары звучит как раньше.

Шаг 3 — двухзонный экран (панель взрослого) и новая оценка для всех режимов
с оценкой взрослого; крупные слова в альбоме, активное знакомство.
**Сделано 2026-10-20** (скриншоты 360 px: `docs/mockups/my-people-step3.png`):

  панель сама не добавляет: низ и бока уже закрывает `.session-screen` (иначе отступ

- В панели: «Ответ: мама · Анна», ступеньки подсказок (`HintSteps`: использованная

- Оценка: «Сам» / «С подсказкой» / «Пока нет» (значения те же: correct / prompted /
