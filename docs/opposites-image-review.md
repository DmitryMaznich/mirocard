# Противоположности: замена изображений

Первая партия: 2026-11-09, колода 2.13.0. Подготовлены восемь новых изображений
для четырёх предметных пар. Это частичная переработка материала: остальные
82 карточки сохраняют прежние изображения и не считаются проверенными этим этапом.

## Выполнено

| Пара | Что исправлено | Что проверить на занятии |
| --- | --- | --- |
| Большой / маленький мяч | Одинаковый красный мяч, фон и ракурс; размер различается внутри одинаковой рамки. Нет смены цвета, типа мяча, человека и места съёмки. | Понимание относительного размера при сравнении рядом; затем перенос на новые предметы. |
| Длинный / короткий карандаш | Одинаковые цвет, толщина и ориентация; оба конца видны; длина меняется без увеличения короткого карандаша при кадрировании. | Ребёнок выбирает длину, а не положение предмета или руки. |
| Полная / пустая бутылка | Один тип открытой прозрачной бутылки, одинаковые масштаб и фон; наличие воды видно по уровню жидкости. | Достаточно ли заметна вода на конкретном экране; при затруднениях начать с реальной прозрачной ёмкости. |
| Чистая / грязная обувь | Одинаковый тип белых кед, ракурс и расположение; добавлена заметная грязь, окружение не меняется. | Связать признак с действием «вымыть»; не приравнивать грязную обувь к старой. |

Изображения сгенерированы одним листом 2 × 4 через image_gen, затем разделены
на восемь фиксированных ячеек и сохранены в WebP 512 × 512. Автоматическое
кадрирование по предмету не применялось: иначе разница размеров исчезла бы.
Происхождение и контрольные суммы записаны в `opposites-image-wave1.json`.
Оригинальный лист сохранён в рабочем окружении, исходные генерации не удалялись.

Мяч и обувь назначены основными примерами своих понятий (`primary`), вместо
кошки и рук. Это меняет представительную карточку, но **не фильтрует** упражнения:
сейчас генератор использует все примеры выбранного понятия. Новые восемь карточек
не образуют автоматически отдельный стартовый режим. Для занятия только с ними
можно использовать страницу просмотра и реальные предметы со взрослым.

## Рекомендуемый старт и ограничения

Для первого знакомства рекомендуются большой / маленький, длинный / короткий,
полный / пустой, чистый / грязный — с отобранными предметными примерами.
Горячий / холодный исключён из этой рекомендации: лето и зима не доказывают
температуру конкретного предмета. Доступность `hot_cold` в приложении в этом
изменении не менялась. Влажность и температура требуют безопасного предметного
опыта со взрослым; не предлагать ребёнку трогать горячие предметы.

## Очередь дальнейших замен

| Материал | Решение |
| --- | --- |
| Взрослая кошка / котёнок | Заменить стартовый пример на предметы, размер которых не смешивается с возрастом; мяч уже подготовлен. Саму пару кошек ещё переработать. |
| Широкая / узкая дверь | Обе двери должны быть одинаково открыты или закрыты; сохранить высоту, отделку, ракурс и фон. |
| Мокрая / сухая трава | Одинаковая зелёная трава до и после увлажнения. Жёлтую засохшую траву не использовать как доказательство отсутствия влаги. |
| Мокрый / сухой камень | Один камень, одинаковые фон и ракурс; различается влажность, а не тип и цвет камня. |
| Мокрое / сухое полотенце | Один предмет и положение; вода должна иметь явные наблюдаемые признаки. Проверить необходимость предметной демонстрации. |
| Чистые / грязные руки, лицо, футболка | Один человек и одинаковая сцена в пределах пары; меняется загрязнение. Не считать смену персонажа вариацией целевого признака. |
| Новая / старая вещь | Отложить до понимания истории использования; различать старый, грязный, изношенный и сломанный. |
| Горячая / холодная скамейка, камень, дорога | Заменить подход к предъявлению. Статические сезонные фотографии убрать из начального обучения. |
| Остальные примеры размера, высоты, длины, ширины и наполненности | Проверить попарно: масштаб, точку отсчёта, видимость содержимого, перспективу и посторонние признаки. Решения по ним пока не приняты. |

## Просмотр и упаковка

`public/decks/opposites_draft/preview.html` показывает сначала четыре новые пары,
затем весь оставшийся материал, сгруппированный по реальным `objectId` из манифеста.
Страница статическая; подписи служат проверке взрослым. Устаревшие ссылки на
отсутствующие изображения из прежней страницы заменены актуальными.

ZIP 2.13.0 содержит `topic.json`, страницу просмотра и только изображения,
аватар и значки, на которые ссылается манифест: 99 файлов. Проверены наличие всех
ресурсов, целостность архива, соответствие версии каталогу и побайтовое совпадение
упакованных файлов с исходниками. Старый ZIP 2.12.0 заменяется в этой же партии;
предыдущая версия остаётся в истории Git. Код рендерера не менялся.
