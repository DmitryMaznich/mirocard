# Глаголы (`verbs_v2`) — методический аудит и план переработки

Дата аудита: 2026-10-17. Статус: **колода v2.0.0 собрана (20 глаголов, 142 карточки: контрастный набор «мальчик и мама» + вариации), ждёт отметок автора перед выкаткой.**

### Журнал реализации
- **Шаг 0 (готов).** Источник темы — `tools/verbs_v2/` (`deck.json`, `media/`, `audio/`,
  `generation-report.json`, `build.mjs`). `build.mjs` кладёт в ZIP только файлы, на которые
  ссылается `deck.json`: снятые карточки остаются в `media/` как исходники, но не публикуются.
- **Шаг 1 (готов, v1.3.0).** 20 глаголов, 86 карточек, поле `wave` у каждой карточки,
  карточки отсортированы по волнам (точки выбора глаголов идут в порядке волн).
  Режимы: Знакомство → Покажи: из двух (`find_2`, easy) → Покажи: из четырёх (`find_n`, medium)
  → Найди все картинки (сетка 4) → Похожие действия (`find_similar`, hard, 2)
  → Что делает? → Выбери слово. «Да / Нет» убран. У каждого режима есть `methodology`,
  у темы — `meta.about`.
  - **Найденный по ходу баг данных:** «Найди картинку» не озвучивал слово — рендерер
    берёт звук из `card.promptAudio`, которого не было. Теперь `promptAudio = audio`
    у всех карточек.
  - **Семантика переразмечена** под реальную путаницу: `group1` — семейство похожих действий,
    `group2` — часть тела, `group3` — темп. «hard» теперь даёт настоящие пары
    (идёт/бежит/прыгает, ест/пьёт/чистит зубы, смеётся/плачет/поёт), «easy» — ничего общего.
  - **Отступления от плана:** концепт «режет» оставлен с id `cuts_knife` (не `cuts`), чтобы
    не терять статистику и `cuts_knife.mp3`; карточки ножниц `cuts_1/2/3/5` переведены в него.
    «Катается» пока не переименован в «едет» — нужна новая озвучка (шаг 3). «Пишет» снят до
    шага 3 (у него не осталось ни одной ✅-картинки). Шаблон «Покажи: {label}» и озвучка в
    «Найди все» требуют кода — перенесены в шаг 2 (в `methodology.tips` режима «Найди все»
    взрослого просят называть слово самому).
- **Шаг 2 (готов, колода v1.4.0 + код приложения).**
  - **Исправлено в шаге 1 — без этого он в приложении не работал:** у flashcards-тем
    `topicLoader` подменяет `ui`/`params` режимов со стандартными id (`intro`, `find_n`,
    `choose_all`, `choose_word_by_picture`) на общие, возвращает `yes_no` и пересортировывает
    режимы. Теперь `meta.customModesOnly: true`, а все режимы — с префиксом `verbs_`
    (`customModesOnly` при чтении вырезает стандартные id, как у `people_names`).
    Тест `verbsLadder.test.js` ставит собранный ZIP через `importTopic` и проверяет лестницу.
  - **Параметры по режиму** (`mode.paramsScope: "mode"`, `readModeParams`/`writeModeParams`
    в `topicUtils.js`): параметры связки ученик–тема общие на все режимы, и три режима
    «Покажи» перетирали друг другу число вариантов и похожесть. Теперь значения режима —
    в `params.byMode[modeId]` того же синхронизируемого JSON; остальные темы не затронуты.
  - **Без ошибок** (`params.errorless`, по умолчанию включено во всех «Покажи»): промах
    записывается (`onStreakReset`), неверное гаснет, верное пульсирует, слово звучит снова,
    нажать можно только верное; завершение после промаха и выбор из 1 картинки — `assisted`.
    «Покажи: из двух» получил вариант «1 — без выбора».
  - **`mode.ui.promptTemplate`** («Покажи: {label}», «Найди все: {label}») — рамка на экране,
    звучит по-прежнему записанное слово. **`mode.ui.autoplayPrompt`** — «Найди все»
    озвучивает слово при появлении сетки + кнопка повтора.
  - **`mode.groupByConcept`** для «Знакомства»: все картинки глагола подряд.
  - **Новый тип `act_out` «Покажи, как»**: картинка-образец + команда (`card.imperative`,
    «Прыгай!»; для неудобных — «Покажи, как плачет»), оценка взрослым 4 кнопками, затем
    звучит слово («прыгает»). Пока озвучка команды — синтезатор речи (`imperativeAudio`
    подхватится, когда появятся записи в шаге 3).
  - **Отложено до шага 4** (нет картинок, проверить нечем): `agent_action` «Кто что делает?»,
    фильтр наборов C/V (`mode.cardSet`), шаблон для `yes_no` (режим убран из темы).
  - Проверено: весь vitest, тесты лестницы и смоук-тесты рендерера, `npm run build`,
    скриншоты режимов из временной страницы-превью с настоящим ZIP (сессионная шапка не
    рендерилась, только тело задания).
  - **Выкатка:** код приложения изменён → при мерже в `main` нужен bump `package.json`.
- **Шаг 3, озвучка (готово, колода v1.5.0).**
  - Вся тема переозвучена одним голосом — клон автора в ElevenLabs («Дмитрий Мазниченко»,
    как «Разряды числа» и диктант прописей): 20 глаголов (`audio/<conceptId>.mp3`) и 20 команд
    для «Покажи, как» (`audio/imp_<conceptId>.mp3`, `card.imperativeAudio`). Старые записи были
    другим синтезатором (24 кГц моно) и с новыми звучали бы двумя голосами; остались в git.
  - «Катается» → **«едет»** (подпись, `answerKey`, запись), команда «Поехали!».
  - Генератор `tools/verbs_v2/generate-audio-elevenlabs.mjs` (учёт сделанного — `audio-voice.json`):
    синтез → обрезка тишины → выравнивание громкости (−15 дБ среднее, пик ≤ −1 дБ) → проверка
    scribe + «один кусок речи». Подводные камни, на которые наступил:
    - `eleven_v4` часто говорит короткое слово дважды («Бежит, бежит»), а «Смеётся» сыграл
      смехом (scribe пишет `[смеётся]`). После двух неудач — `eleven_multilingual_v2` тем же
      голосом: так записаны «ешь», «бежит», «едет», «смеётся».
    - Обрезка как в `trim-place-value-numbers.mjs` (50 мс, −45 дБ) съедала начальное «п»
      («Три гая» вместо «Прыгай»): здесь порог 10 мс / −50 дБ.
    - scribe слышит «ест» как «есть» (и старую запись тоже) — «ест» засчитан по «есть»,
      **нужно прослушать человеку**.
  - **Не проверено автоматически:** ударения и тембр (особенно 4 клипа на `multilingual_v2`) —
    прослушать сводный файл (порядок по волнам, «слово → команда»).
Целевой ребёнок: **РАС, минимально вербальный** (единичные слова/приближения, жесты,
AAC-карточки; понимание речи опережает экспрессию, но тоже ограничено).

Этот документ — рабочая спецификация. Каждый пункт плана (раздел 8) должен быть

## 2. Главные методические проблемы (по убыванию важности)

1. **Картинки не изолируют действие.** У каждого глагола свои дети, свой фон и свои
   предметы. В «Найди картинку» ребёнок решает задачу по *месту и предмету*
   (бассейн → «плавает», кровать → «спит», велосипед → «катается»). То есть он учит
   существительные и сцены, а не глагол. Для глагола нужен **контраст: тот же
   исполнитель, тот же фон, меняется только действие**. Такого набора нет совсем.
2. **Нет лестницы.** Режимы стоят в случайном порядке: экспрессивный «Что делает?» —
   первым, «Знакомство» — вторым. Сразу 25 глаголов, по умолчанию 4 варианта и
   «средние» дистракторы. Для минимально вербального ребёнка с РАС вход должен быть
   3–4 глагола, 1–2 варианта, безошибочное обучение.
3. **В словаре есть то, что нельзя увидеть или изобразить:** «думает», «считает»,
   «покупает». Ещё «вырезает» и «режет» — почти синонимы, при этом стоят как разные
   ответы. «Играет» слишком широкое и во всех 5 картинках показано только мячом
   (ребёнок выучит «играет = мяч»).
4. **Ось 5 (силуэты) — слабое место.** Из 25 силуэтов ~10 неоднозначны или
   совпадают с другим глаголом: прыгает = танцует, рисует = пишет, считает = машет,
   умывается = закрыл лицо, смеётся/плачет — силуэт теряет лицо. Силуэт не ведёт
   ни к книге, ни к AAC. Для минимально вербального ребёнка правильный «мост» —
   **AAC-пиктограмма** (ARASAAC-подобная, цветная, контурная): это буквально его
   канал экспрессии.
5. **Ось 4 (антропоморфные животные).** Медведь чистит зубы, бобёр пылесосит, слон
   рисует, сова пишет пером, енот считает. Для ребёнка с РАС с буквальным мышлением
   это фантазийный план, а не генерализация. Плюс 5 из 25 карточек этой оси просто
   не показывают действие (слон *рядом* со стаканом, фламинго *стоит*, щенок *лежит*,
   кролик *сидит*, гиена *лежит*). Генерализация по исполнителю должна идти так:
   другой ребёнок → **взрослый (мама/папа)** → **настоящее животное, которое реально
   так делает** (собака бежит, кошка спит, утка плавает, лягушка прыгает, птица поёт).
6. **Нет взрослых исполнителей.** Почти везде дети 4–7 лет одного типажа. Значение
   глагола не отделено от исполнителя.
7. **Ошибки в текстах режимов:**
   - `yes_no`: у колоды нет `answerPrefix`, рендерер подставляет «Это» →
     «**Это бежит?**», «Нет! Это ест!» — грамматически неверно.
   - `choose_all`: «Найди все: бежит» — неграмматично.
   - `find_n`: подсказка — голое слово «бежит» без инструкции; для минимально
     вербального ребёнка нужна короткая постоянная рамка «Покажи: бежит».
   - `intro` высыпает все 125 карточек вперемешку. Нужно: по выбранным глаголам,
     все вариации одного глагола подряд.
8. **Нет проверки переноса.** В движке уже есть `generalisation_probe` (карточки
   `probeOnly`) и `offphoto_find_n` (`cardType: pictogram/illustration`) — у
   `people_names` они работают. У глаголов не используются.
9. **Нет безошибочного режима.** В `my_people` уже реализован errorless
   (`fieldSize: 1`; при ошибке неверное гаснет, верное подсвечивается и
   называется: «Вот мама»). В `flashcards` `find_n` этого нет.
10. **Нет действия «сделай».** Для РАС самый надёжный путь к пониманию глагола —
    выполнить или изобразить действие (моторная имитация, инструкция
    «Прыгай!»). Повелительное наклонение — к тому же первая усваиваемая форма
    глагола. В теме его нет.
11. Мелкое: в аннотации «24 глагола» (на деле 25); `energy_level` смешивает
    `moderate` и `medium` (у `cuts_knife`), что ломает подсчёт близости в
    `distractorEngine`; `thinks_1` с рамкой-карточкой (нарушение промпта);
    `thinks_5` — не силуэт (промпт отличается); `writes_1` — латиница («cat»).

## 3. Чего тема НЕ даст (честные границы)

Приложение может обеспечить: понимание глагола на картинке, перенос на новых
исполнителей и изображения, выполнение действия по слову, ответ словом, приближением,
жестом или AAC. Употребление глагола во фразе в жизни — работа взрослого вне экрана;
тема даёт для неё материал и подсказки (`about.tips`), но гарантировать её не может.
«Ребёнок чётко усвоил глаголы» = выполнены критерии раздела 6 по каждой волне.

## 4. Словарь: решение

Критерии отбора для минимально вербального ребёнка с РАС: (а) частотность в его дне;
(б) действие видно на статичной картинке; (в) ребёнок может сам его изобразить;
(г) функциональность для просьб и режима; (д) внутри волны нет почти-синонимов.

### Волна 1 — ядро (6)
**ест, пьёт, спит, бежит, прыгает, рисует.** Максимально разные, все изображаемы,
все «проигрываемы» с игрушкой.

### Волна 2 (+8)
**идёт** (минимальная пара к «бежит»), **моет руки** (новый, частотнее «умывается»),
**чистит зубы**, **играет** (переснять: кубики, машинка, кукла, мяч — разные игры),
**читает** («смотрит книжку»), **едет** (вместо «катается»: велосипед, самокат,
машина — шире и частотнее), **плачет**, **смеётся**.

### Волна 3 (+8)
**умывается, плавает, поёт, танцует, режет** (объединить `cuts` + `cuts_knife`:
нож/ножницы как вариации одного глагола), **поливает, пылесосит, пишет**.

### Убрать из темы
- **думает** — внутренний процесс, изображается только конвенцией (пузырь мысли),
  которая при РАС не считывается.
- **считает** — когнитивный процесс; на 3 из 5 картинок читается как «машет».
  Если нужен — в математических темах.
- **покупает** — абстрактный социальный обмен; место ему в социальных историях.
- `cuts` как отдельный концепт — сливается с «режет».

Итого 22 глагола (было 25). Новые: «моет руки» и «едет» (взамен «катается»).
Кандидаты на волну 3+, **требуют вашего решения**: сидит / стоит / лежит (позы —
очень частотные, но «лежит» спорит со «спит»), открывает, кидает, одевается, даёт.

### Подписи
Глагол в 3-м лице настоящего времени — оставить, это правильная базовая форма.
Глагол + объект — только там, где глагол без объекта неоднозначен («чистит зубы»,
«моет руки»). Для каждого глагола добавить **повелительную форму** (аудио + поле
`imperative`): ешь, пей, спи, беги, прыгай, рисуй, иди, мой руки, … — для режима
«Покажи, как» (раздел 7).

### 5б. Решение по животным и источнику картинок (согласовано с автором, 2026-10-17)

1. **Антропоморфные животные — убрать полностью** (медведь чистит зубы, бобёр пылесосит,
   слон рисует, сова читает, медведь-повар, плюшевый мишка ест/спит). Для буквального
   мышления при РАС это противоречие с реальностью, переноса в жизнь не даёт, действие
   неестественное, и на этих картинках у генератора больше всего ошибок.
2. **Настоящие животные — только для естественных действий** и только на поздних этапах
   (Покажи из четырёх, Найди все, проверка на новых картинках; не в Знакомстве и не в
   Покажи из двух). Причина: сверхизбирательность внимания — животное ярче действия,
   ребёнок запоминает «собака», а не «бежит», и на «Что делает?» отвечает существительным.
   Список: бежит (собака), прыгает (лягушка), плавает (утка), спит (кошка), ест (собака из
   миски), пьёт (кошка лакает), идёт (кошка), играет (котёнок с клубком), поёт (птица — под
   вопросом). Остальным глаголам, включая «плачет» и «смеётся», животные не нужны.
   В колоде: поле `agent: "animal"` у карточки и фильтр по нему в режимах (шаг 4).
3. **Реалистичный набор — настоящие фотографии, не генерация.** Генератор хорош в лицах
   крупным планом и плох в анатомии в движении, предметах и механике (пылесосы, ножницы,
   велосипеды, ноги пловца). Фото — из фотобанков со свободной коммерческой лицензией
   (Pexels, Unsplash; условия проверить перед загрузкой, источник и автора записывать в
   карточку). Генерация остаётся для контрастного набора с одним персонажем и для
   иллюстраций в едином книжном стиле; животное в иллюстрации — тоже только с
   естественным поведением.
4. **Чек-лист проверки каждой новой картинки** (в полном размере, не контактным листом):
   люди и животные — анатомия, руки, пальцы, позы; **предметы — устроены как настоящие**
   (ручка, шланг, провод, лезвие, педали — где крепятся и куда ведут), предмет используется
   по назначению и касается того, с чем действует; физика (вода течёт вниз, зеркало
   отражает то, что перед ним); никакого текста, латиницы и логотипов; действие однозначно
   и не путается с соседними глаголами; безопасное поведение (пальцы не под лезвием,
   малыш без острого ножа); спокойный фон без толпы. Картинку смотрит человек; мои
   пометки — первичный фильтр, не окончательное решение.

### 5в. Предмет и обстановка тоже меняются (замечание автора, 2026-10-17)

Все «едет» были про велосипед, все «поливает» — про цветок, все «играет» — про мяч. Для
генерализации меняется всё, что не входит в значение глагола: исполнитель, обстановка, стиль
**и предмет** — иначе ребёнок учит «едет = велосипед». Граница: предмет меняется, пока не
меняется сам русский глагол. **Минимум три разных предмета или обстановки на глагол** (в
вариациях V и пробах T; в контрастном наборе C предмет один и тот же).
- едет: велосипед, самокат, машина, автобус (не санки, коньки, горка — это «катается»);
- поливает: цветок в горшке, грядка из лейки, газон из шланга, дерево (не «моет из шланга»);
- ест: ложкой кашу, руками яблоко, вилкой, мороженое; пьёт: из чашки, стакана, через
  трубочку, из бутылки;
- рисует: карандашом, фломастером, кистью красками, мелом на асфальте, пальцами;
- режет: ножницами бумагу, взрослый ножом хлеб, ребёнок пластиковым ножом банан;
- играет: кубики, машинка, мяч, кукла, пирамидка; спит: в кровати, в коляске, на диване;
- прыгает: на месте, через лужу, на батуте, через скакалку; плавает: в бассейне, в море,
  с кругом; поёт: в микрофон, под гитару, с нотами.

## 7. Лестница режимов (порядок в `deck.json` = порядок лестницы)

Общие правила: работа волнами (раздел 4); на экране — только выбранные взрослым
глаголы текущей волны плюс уже освоенные. Критерий перехода — **≥80 % верных в двух
сессиях подряд**, без подсказки. Каждая инструкция звучит голосом и короткая (одна
рамка на режим, без вариаций формулировки).

| # | Режим (id → type) | Инструкция / речь | Параметры | Карточки | Критерий перехода |
|---|---|---|---|---|---|
| 1 | Знакомство `intro` | Звучит «Ест». Подсказка взрослому: показать действие на себе или игрушке | по выбранным глаголам; все карточки глагола подряд | C → V | просмотрено |
| 2 | Покажи, как `act_out` (**новый тип**) | «Прыгай!» (повелительное). Взрослый оценивает: не сделал / с подсказкой / сделал | — | C | 80 % «сделал» (идёт параллельно с 3–4) |

Почему уходит «Да / Нет»: ответ «да/нет» на вопрос о названии — метаязыковое и
