## 1. Опоры (что доказано, а что нет)

| Решение | На что опирается | Сила |
|---|---|---|
| Предмет → картинка → запись (CRA) | Bouck и др., 2018 — доказанная практика для действий, включая умножение, у детей с трудностями обучения; при РАС — малые исследования (Flores и др.) с положительным результатом | средняя для РАС |
| Счёт группами перед умножением (ступень 2) | Mulligan & Mitchelmore, 1997: счёт по одному → счёт группами → сложение одинаковых → умножение; переход от счёта к записи — большой скачок | хорошая (обычные дети) |
| Ряды и поворот для перестановки множителей (ступени 6–7) | Barmby, Harries, Higgins, Suggate, 2009; поворот массива как показ перестановки. Оговорка: ряды и столбцы ребёнок сам не видит — нужен переход «тарелка → ряд» | хорошая (обычные дети) |
| Не красить числа; подсказка внутри задания | Сверхизбирательность внимания при РАС: внешняя подсказка (цвет) становится тем, на что ребёнок реагирует, и плохо снимается (исследование со шнурками: 11 из 20 выбирали цвет даже ценой ошибки); рекомендации избегать внешних подсказок | хорошая для РАС (не про математику) |
| Много разных групп (руки, носки, коробки…) | Обучение на многих примерах (multiple exemplar training) — один из надёжных путей к переносу навыка при РАС | хорошая (не про математику) |
| Примеры «не поровну» | Обучение понятию на примерах и не-примерах (Энгельман, прямое обучение) | принцип, прямых данных про «поровну» при РАС нет |
| Задачи-истории на равные группы (позже) | Обучение по схеме задачи (MSBI: Root, Cox и др.) — доказано при РАС, в т. ч. на равные группы | хорошая, но для говорящих/читающих |
| Клавиатура вместо выбора ответа | **Не доказано.** Сравнений для математики при РАС не нашли | открытый вопрос |

Источники — в конце файла.

## 2. Сквозные правила

1. **Запись «a × b» = «по a, b раз»** (по Моро: `2 × 3 = 2 + 2 + 2`). Порядок множителей зависит от школы
   и языка (в английской традиции часто наоборот; словенское чтение проверить по учебнику) — **порядок —
   параметр языка**, не константа в коде.
2. **Числа одного цвета.** Смысл числа показывает значок под ним: под размером группы — сами предметы
   (три яблока под «3»), под числом групп — тарелки, позже — ряды. Значки снимаются по плану:
   полные → бледные → нет.
3. **Одна голосовая формула** на всю тему: «по три… четыре раза». Короткие фразы, голос, без текста-инструкции.
4. **Предметы в группе лежат как точки на кубике** (одна раскладка на каждое число 1–6).
5. **Ошибка — подсветка, не текст**: обвести нужную тарелку, погасить неверную кнопку. Ошибиться
   в первых заданиях каждой ступени почти нельзя (лишнее не кладётся, порядок нажатий задан).
6. **Размеры**: в группе 2–5, групп 2–5, до 6 в ряду — ребёнок видит количество с одного взгляда. 2 × 2 и
   a × a — только на поздних ступенях (не видно, какое число что значит).
7. **Каждое задание — много раз с разными числами и разными предметами**, а не три фиксированных.
8. **Перевёрнутый пример (b × a) не даём среди неверных вариантов**, пока не пройдена ступень 7: иначе
   ребёнок выучит «4 × 2 — неправильно», а потом услышит «это одно и то же».

## 3. Лестница

| № | Ступень | Ребёнок делает | Снимаемая подсказка |
|---|---|---|---|
| 0 | Поровну? | смотрит на 2–3 группы, жмёт «= поровну» / «≠ не поровну» | разница сначала большая (4 и 1), потом в один предмет |
| 1 | Сделай поровну | перекладывает предметы между тарелками, пока не станет поровну | пунктир вокруг тарелки, где лишнее |
| 2 | Считаем группами | жмёт на тарелки по порядку, над каждой появляется сумма (3 → 6 → 9) | позже сам выбирает число над тарелкой из 2–3 |
| 3 | Сложение → умножение | смотрит показ: `3+3+3+3` сворачивается в `3 × 4`, значки под числами | показ, решать не надо |
| 4 | Картинка → пример | выбирает запись к картинке (неверные отличаются числом) | значки под числами в кнопках; «+» среди вариантов — после снятия значков |
| 5 | Пример → собери | ставит нужное число тарелок, кладёт по a (предметов больше, чем нужно) | значки под числами задания |
| 6 | Тарелки → ряды | видит, как каждая тарелка становится рядом лотка | значок «тарелки» меняется на «ряды» |
| 7 | Повернули | поворачивает лоток ↻, находит ответ новой записи | закрытый ответ, сначала пересчёт |
| 8 | Пример без картинки | набирает ответ (или выбирает — открытый вопрос) | кнопка «показать» достаёт картинку, засчитывается как «с подсказкой» |
| позже | Задача-история | картинка-история про равные группы со схемой | — |

Замена режима «Переложи яблоки» из первого макета: перекладывание 3 по 2 → 2 по 3 по сути деление и не
показывает структуру; к тому же ответ был виден над вопросом. Перестановку множителей показывает поворот
того же лотка (ступень 7).

## 4. Открыто

- Клавиатура или выбор ответа на ступени 8 — решать по тому, как пойдёт у сына.
- Критерий «освоено» для перехода между ступенями (внутри ступени 0 — 8 из 10, см. раздел 5) — для остальных ступеней не согласован.
- Фото разных групп для ступени 2 и дальше — нет; список кадров и правила съёмки — `docs/multiplication-shotlist.md`.
- Голос формулы «по три… четыре раза» — не записан.
- Порядок множителей для словенского и английского интерфейса — проверить по учебникам.
- Лоток с рядами — новый предмет; если ребёнок привязан к тарелкам, может понадобиться промежуточная ступень (тарелки в ряд).

## 5. Шлифовка по ступеням

Идём по одной ступени, с макетом и решениями владельца. Сделанное записывать сюда.

### Ступень 0 «Поровну?» — решения методиста (2026-11-26)

Макет: `index.html#s0` (живой, уровни и правило перехода работают).

- **Две тарелки, не больше.** Три и больше — на ступени 1: с тремя тарелками «≠» становится «найди не такую», это другой навык.
- **Уровни:** R — под тарелками уже стоят ряды один к одному (подсказка внутри задания, ошибиться почти нельзя) →
  A — разница ≥ 2, раскладка как на кубике → B — разница в 1 → D — у каждой тарелки свой случайный разброс
  («поровну» с разными узорами, «не поровну» с похожими; без D ребёнок может сравнивать узор, а не количество).
- **Кнопки «разложить в ряды» до ответа нет:** ребёнок с РАС быстро начинает нажимать её всегда (зависимость от подсказки).
  Её роль играет уровень R, который снимается по правилу перехода.
- **Проверка рядами после ответа:** после каждого ответа, пока не освоен уровень A; дальше — только после ошибки.
- **Ошибка:** ряды показываются, ответ повторяется на том же задании, следующее задание — на уровень ниже.
- **Переход:** вверх — 8 верных с первого нажатия из последних 10; вниз — 2 ошибки подряд.
- **Ответы «=» и «≠» примерно поровну**, не больше двух одинаковых подряд.
- Голос: «Поровну?»; после верного — «Поровну! По три» / «Не поровну». Слов на кнопках нет: знак и значок-столбики.
- Предложение и порог перехода — рабочие; поправить по наблюдению за сыном.

### Ступень 1 «Сделай поровну» — решения методиста (2026-11-26)

Макет: `index.html#s1` (живой: перетаскивание и нажатия, подсказки, уровни).

- **Действие:** перетащить яблоко на другую тарелку или нажать тарелку «откуда», потом «куда» (для тех, кому трудно тянуть).
- **Кнопки «Проверить» нет.** Как только стало поровну, тарелки загораются зелёным, яблоки встают в ряды один к одному
  (как на ступени 0, на тарелках бледнеют — чтобы не видеть их дважды), голос: «Поровну! По три».
- **Сколько класть — не говорим.** Число «по три» ребёнок находит сам; решение одно (всего делится на число тарелок).
- **Подсказка по нарастающей:** 6 секунд без хода или 2 хода «не туда» (хода, после которого до «поровну» не ближе) →
  мигает тарелка, где больше всего; ещё 2 таких хода или ещё 6 секунд → стрелка «откуда → куда».
  На уровне R подсказка «откуда» видна с начала и снимается на уровне A.
- **Показ образца в начале:** в первом задании занятия рука сама дважды переносит яблоко с тарелки, где больше, на тарелку,
  где меньше (голос «Смотри»), потом ребёнок делает сам. Показ прерывается, как только ребёнок коснулся тарелки.
- **Ход «не туда» не запрещаем:** яблоко ложится, подсказка приходит сама. Запрет хода ничему не учит.
- **«Чисто»** — без подсказки и не больше чем на 1 ход длиннее кратчайшего. Вверх — 8 чистых из 10;
  вниз — 2 задания подряд, где понадобилась стрелка.
- **Уровни:** R — 2 тарелки, 1 ход, подсказка сразу → A — 2 тарелки, 1 ход → B — 2 тарелки, 2 хода →
  C — 3 тарелки, 1–2 хода → D — 3–4 тарелки, лишнее и недостача на нескольких тарелках.
- Яблоки на тарелке после каждого хода раскладываются заново как на кубике — количество видно сразу.
- Тарелок 3 и больше — именно здесь: ребёнок должен проверить все тарелки, а не одну пару.

### Ступень 2 «Считаем группами» — решения методиста (2026-11-27)

Макет: `index.html#s2` (живой).

- **Действие:** нажимать тарелки по очереди; следующая обведена и пульсирует, другие не нажимаются. Над тарелкой — сколько уже всего.
- **Уровни:** R — число появляется само, голос считает «два… четыре…» (образец) → A — выбрать число из двух →
  B — из трёх, по 3 и по 4 → C — прошлые числа над тарелками гаснут (держать счёт в голове) → D — по 2–5, до 5 тарелок.
- **Начинаем с «по 2» и «по 5»** — эти ряды запоминаются легче всего; по 3 и 4 — с уровня B.
- **Неверные варианты — типичные ошибки:** «прибавил одно вместо тарелки» (6 → 7) и «обсчитался на одно» (9 ± 1).
- **Ошибка:** кнопка гаснет, яблоки на тарелке досчитываются по одному от прошлого числа («семь, восемь, девять»),
  голос: «Шесть, и ещё три». Ребёнку показывают способ найти ответ, а не просто «неверно».
- **В конце:** голос «Двенадцать! По три, четыре раза» — та же формула, что станет записью на ступени 3.
- **«Чисто»** — без ошибок. Вверх — 8 чистых из 10; вниз — 2 задания подряд с двумя и больше ошибками.
- **Разные группы — внутри ступени 2, а не отдельной ступенью 2б** (решение 2026-11-27; ступень 2б убрана).
  R и A — тарелки с яблоками: новый навык учим на одном привычном материале. С уровня B группы чередуются
  (в макете — яблоки и бананы на тарелках, яйца в коробках; дальше — руки, носки, букеты, корзинки).
  Почему не отдельной ступенью после освоения: к тому времени навык успевает привязаться к тарелкам, а при РАС
  перенос сам не происходит. Почему не с первого задания: много разных предметов сразу мешает усвоить новое действие.
  Дальше (ступени 3–8) группы тоже чередуются с первых заданий — навык уже есть.
- Неясно: нужен ли на уровне C вопрос в конце «Сколько всего?» без чисел над тарелками — решить после проб.

### Ступень 3 «Сложение → умножение» — решения методиста (2026-11-27)

Макет: `index.html#s3` (живой).

- **Ребёнок собирает сложение сам:** нажимает группы по очереди, строка растёт «3 + 3 + 3 + 3 = 12».
- **Откуда второе число:** под каждым слагаемым появляется номер раза (1, 2, 3, 4, голос «один раз… два раза…»);
  последний номер становится вторым числом записи. Главное место ступени: второе число — «сколько раз», в группе его не видно.
- **Свёртка:** сложение бледнеет, под ним — «3 × 4 = 12» со значками под числами (три предмета под «3», четыре тары под «4»).
  Голос: «По три, четыре раза. Три умножить на четыре — двенадцать» — школьное чтение знака всегда вместе с формулой.
- **Уровни:** R — собрать и посмотреть свёртку → A — после свёртки «Покажи: сколько яблок на одной тарелке?» и
  «Покажи: сколько тарелок?» (в случайном порядке), ребёнок нажимает число в записи → B — то же сразу (без сборки),
  значки бледные → C — одно число в записи пропущено, вставить из трёх (верное, другое число записи, соседнее).
- **Ответ показом, не словом.** Верно — загорается смысл: одна группа «подпрыгивает» (размер группы) или все группы
  по очереди (сколько групп). Неверно — число краснеет, и тот же смысл подсвечивается как подсказка.
- **Числа:** в группе 2–5, групп 2–5, произведение до 20, никогда a × a. Группы с первого задания разные (навык уже есть со ступени 2).
- **«Чисто»** — без ошибок; вверх — 8 из 10; вниз — 2 задания подряд с 2+ ошибками.
- Неясно: не рано ли «умножить на» в голосе на уровне R — если сын начнёт повторять, хорошо; если путается — оставить только «по три, четыре раза» до уровня B.
