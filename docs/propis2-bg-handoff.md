  отдельный ZIP-топик `propis2_bg` с тем же рендерером, только данные (`tools/propis2/variants/bg/variant.json`). В каталоге
  статус `individual`, его видит одна учётная запись.

  косые 76° через 1:4) плюс «Клетка» и «Линейка», формат A5, `meta.script = {slantDeg: 76, upper: 1.526, lower: 1.465}`
  (наклон и пропорции болгарской тетради), заглавная Ъ (старая, от руки).

## Правила, которые владелец задал (не нарушать)
- Ретушь только выравнивает прямые участки и убирает дрожание. Траектория и форма руки остаются. Дуги нельзя выпрямлять.
- Стойки строго по косым линовки, 76°. Верх заглавной на верхней жирной линии, низ на базовой.
- Крюки у базовой линии длинные и круглые (`BOW_H` и эталон `reference_hooks.json`), не менять без сверки.
- «По шрифту» значит по трафарету в собственных пропорциях шрифта (`stencil_map`), а не там, где подложка лежала под рукой.
- Каждую правку показывать картинкой. Сравнение: `compare_font.py <ttf> <png> --built` — серым шрифт, красным траектории,
  точка в начале штриха. Владелец смотрит такие листы и отвечает по буквам.
- Пользователь просит общаться как обычный человек, по-русски, коротко (до ~1000 токенов), критично и без лести.

## Как собирать и проверять
```bash
python3 tools/propis2/variants/bg/build_glyphs.py            # captures/ + шрифт -> variant.json glyphs (TTF не нужен)
python3 tools/propis2/variants/bg/compare_font.py <ttf> out.png --built   # лист всех заглавных поверх шрифта
python3 tools/propis2/variants/bg/compare_font.py <ttf> out.png           # обведённые: шрифт, рука, результат
python3 tools/propis2/variants/bg/review_sheet.py out.png [буквы]  # без TTF: собранные буквы поверх средней линии шрифта
python3 tools/propis2/variants/bg/font_flags.py <ttf>        # точные средние линии флажков и шляпы П -> font_flags.json
npx vitest run src/topics/renderers/propis2 src/topics/renderers/propis/scriptGeometry.test.js
```
Проверка, что эталонная А не сдвинулась: подравнять захват `captures/boyan_A_a_2026-10-18.json` и сравнить штрих 0 с
`reference_hooks.json["letterA"][0]`. Должно совпасть побитно.
Слово через движок: временный vitest в `src/` с `buildGlyphMap({wide, meta:{script}})` и `layoutWideLinesIntoRows`. Файл
после проверки удалять.

**Файл шрифта `Boyan_Maga-Regular.ttf` в репозитории не лежит**, его прислал владелец. Без него сборка глифов работает: средняя
линия шрифта хранится в `boyan_glyphs.draft.json`, место подложек в `underlay_dx.json`, точные флажки в `font_flags.json`.
TTF нужен только для листов сравнения, `font_flags.py` и `make_underlays.py`. Python-зависимости: fonttools, scikit-image,
scipy, pillow, numpy.

## Файлы (`tools/propis2/variants/bg/`)
- `tidy_trace.py` — подравнивание на бумаге: прямые, дуги, крюки, петли, `to_paper` / `to_bank` (точная копия геометрии движка
  и `scriptPointMap`).
- `build_glyphs.py` — сборка: обведённые (`underlay_glyph`), из шрифта (`font_letter`, `FONT_ONLY`), поправки `SHAPES`,
  флажки `font_flag` / `FONT_FLAG`, `stencil_map`, `DEEPEN`, `LETTERS` (Ъ), `BANK_KEPT` (строчная «а» — русская).
- `captures/` — захваты руки; `underlays/` и `boyan_underlays.zip` — подложки для обводки в
  `tools/letter_capture/handwriting_capture.html`.
- `font_glyphs.py`, `make_underlays.py` — извлечение пути пера шрифта и подложек.
