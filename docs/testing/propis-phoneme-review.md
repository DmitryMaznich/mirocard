# Прописи: второй подход к озвучке звуков

Запрос пользователя от 09.10.2026: отдельные записи звуков 33 букв и два
слова «заглавная» / «строчная». Согласные должны звучать как фонемы, без
алфавитных названий «ка», «эс», «ща» и без добавочного гласного.

Набор для проверки: `/audio-review.html?set=audio/propis-phoneme-review`.
**Отклонён пользователем после прослушивания:** согласные слышатся зажатыми и
оборванными. Удаление гласного по сигналу не обеспечило полноценную
учебную артикуляцию. Этот набор не устанавливать в диктант.
Оригинальные 35 человеческих записей `public/audio/propis-dictation` сохранены;
режим диктанта продолжает использовать их до утверждения новых вариантов.

Провайдер: Google Cloud Text-to-Speech. Русский женский голос `ru-RU-Wavenet-A`,
скорость 0.95 для гласных и слов, 0.7 для исходных слогов согласных.
Прямой SSML с одиночной согласной не сработал: сервис принял запрос,
но озвучил название буквы. Сравнение «к» с обычным чтением буквы выявило
совпадающий гласный участок. Поэтому 21 согласная выделена из начала
слога перед «а» (Й — из «я»), с индивидуальной границей до гласного.
Исходные слоги сохранены в `scripts/audio-sources/propis-wavenet-a/`:
границы нельзя переносить на заново сгенерированные записи без проверки.
Добавлены короткие поля тишины, плавные края и выравнивание громкости.
Таблица фонем, границы и единый список: `scripts/lib/propis-phoneme-bank.mjs`.
Е/Ё/Ю/Я в изоляции заданы как й + гласный; Ъ/Ь собственного звука не имеют,
для них подготовлены произнесённые названия «твёрдый знак» и «мягкий знак».
Это 31 фонетическая запись, два названия знаков и два слова регистра — 35 файлов.

Генератор: `node scripts/generate-propis-phoneme-audio.mjs`. По умолчанию
пропускает существующие файлы, поддерживает `--keys=sound_к,sound_с` и `--force`.
Вывод только в `public/audio/propis-phoneme-review`; основную озвучку этот
генератор не перезаписывает. Учётные данные читаются из внешнего файла,
секреты и токены не записываются в репозиторий и не выводятся.
Для декодирования исходных MP3 нужен установленный Chrome; кодирование
обрезанных согласных выполняет `@breezystack/lamejs`.

При прослушивании проверить: отсутствие добавочного гласного, отсутствие
алфавитного названия, сохранность коротких взрывных согласных, чистоту
шипящих и йотированных, обычную интонацию двух слов регистра. Сам факт
успешного синтеза и декодирования не подтверждает произношение на слух.

Документация провайдера: https://cloud.google.com/text-to-speech/docs/phonemes
и https://cloud.google.com/text-to-speech/docs/ssml.

## Следующая проба: целые голосовые действия

Плейлист `/audio-review.html?set=audio/propis-natural-pilot`: пять звуков
С, Ш, М, К, Б. Gemini `gemini-3.8-flash-tts`, голос `Charon`.
Генератор `scripts/generate-propis-natural-pilot.mjs`, задания и порядок
`scripts/lib/propis-natural-pilot-bank.mjs`. Сохранены целые WAV-ответы
провайдера: ни обрезки, ни склейки, ни изменения длительности.

Вместо слога используются inline vocal tags с запросом изолированной
артикуляции; стиль задаётся отдельно через `speech_metadata`. Для
длительных согласных задан протяжный звук с естественным завершением.
Взрывные К и Б запрошены с полной смычкой и высвобождением, а не как
обрезанное начало слога; по природе они остаются короткими.

Это ограниченная проба подхода, а не утверждённый алфавит. Автоматическое
описание звуков другой моделью служит вспомогательной проверкой и не
подтверждает качество на слух. Две пробы Щ были распознаны как Ш;
не включены в плейлист, полноценный алфавит пока не готов. Проверить,
подходят ли короткие К/Б для учебного диктанта. Основная человеческая
озвучка по-прежнему сохранена.

Документация актуального API:
https://ai.google.dev/gemini-api/docs/speech-generation.

## Третья проба: ElevenLabs, голос владельца (10.10.2026)

Плейлист `/audio-review.html?set=audio/propis-elevenlabs-review`: все 35 ключей
диктанта букв (33 буквы + «заглавная»/«строчная»), по два дубля —
`<ключ>.mp3` и `<ключ>__2.mp3`. Голос «Дмитрий Мазниченко» (клон в ElevenLabs),
модель `eleven_v4`. Без обрезки и перекодирования. Тексты и порядок:
`scripts/lib/propis-elevenlabs-bank.mjs`.

- **Раунд 1 — отклонён владельцем** («та же беда, что у Gemini», придыхание).
  Были теги `[friendly] [unhurried]` и `[only the isolated consonant sound, no
  vowel after it]`, взрывные — одной буквой. Теги, по всей видимости, и дают
  придыхание: для отдельных звуков их не использовать.
- **Раунд 2 (текущие файлы)** — по совету владельца: буква повторена несколько
  раз, без каких-либо тегов («Ааааа.», «Ббббб.», «Ссссс.»), чтобы получался
  протяжный звук. Ъ/Ь — «Твёрдый знак.»/«Мягкий знак.», регистр — «Заглавная»,
  «Строчная» без точки. Длительности ровные, ~1,1–1,8 с (Щ ~2,1 с).
  На слух не проверено.

Основная озвучка `public/audio/propis-dictation` не изменена.

### Пилот: Б, В, Г с Э (10.10.2026)

По просьбе владельца — только Б, В, Г в сочетании с Э, четыре формы на букву,
по два дубля, без тегов: «Бэ.», «Бээээ.», «Бббэ.», «Бэ, бэ, бэ.» (и так же
для В, Г). Плейлист `/audio-review.html?set=audio/propis-elevenlabs-e-pilot`,
тексты — `PROPIS_ELEVENLABS_E_PILOT` в `scripts/lib/propis-elevenlabs-bank.mjs`.
На слух не проверено.
