# Проверка произношения

Откройте `/audio-review.html` на сервере приложения или локально после `npm run dev`.
По умолчанию выбран набор «Плюс / минус» и 31 запись чисел и знаков,
которые используются в режиме «Слушаем и считаем». В разделе «Фразы» доступны
остальные записи этой темы. Нажмите «Прослушать» или строку плейлиста.

- «Хорошо» / «Переделать» сохраняют оценку. Можно оставить комментарий перед оценкой.
- По умолчанию после оценки начинает играть следующая запись. Это можно отключить.
- «Играть весь список подряд» запускает переход после окончания записи с выбранной паузой.
- Фильтры позволяют слушать только непроверенные или проблемные записи.
- TXT и копирование содержат все отмеченные для переделки файлы выбранного набора,
  включая скрытые фильтрами. JSON содержит все оценки и комментарии этого набора.
- Пробел: играть / пауза; стрелки: предыдущая / следующая; 1: хорошо; 2: переделать;
  0: снять оценку; R: повторить. При вводе комментария сочетания не срабатывают.

Оценки сохраняются в localStorage этого браузера. При замене содержимого серверного
аудиофайла старая оценка не применяется к новой записи. JSON хранит контрольную
версию файла для точной идентификации. Для резервной копии скачайте отчёт.

Для других тем выберите готовый набор, загрузите несколько файлов или папку.
Локальные файлы никуда не отправляются. После перезагрузки страницы выберите те же
файлы снова: оценки восстановятся по пути, размеру и времени изменения файла.
Для аудио внутри ZIP сначала распакуйте архив и выберите его папку.

Каталог создаётся командой `npm run audio:review` и автоматически перед `npm run dev`
и `npm run build`. Он включает все аудиофайлы из `public/audio` и `public/sounds`.
Новые подпапки автоматически становятся наборами; для неизвестных файлов подписью
служит имя файла. Тексты чисел, фраз, временных значений и диктанта берутся из
исходных банков темы, без запросов к генераторам речи.
