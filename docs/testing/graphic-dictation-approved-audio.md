# Координаты: утверждённые записи

По запросу владельца 09.10.2026 заменены самостоятельные синтетические
записи координат в теме «Рисуем по клеткам»:

- 20 букв столбцов — человеческие записи из `public/audio/propis-dictation`.
- Числа 1–20 — готовые записи из `public/audio/addition-subtraction`, включая
  утверждённые замены 1, 3, 4, 5, 6.

Копирование побайтовое, без генерации, обрезки или перекодирования.
Соответствие столбцов учитывает пропуск Ё и З: столбец 8 — К.
Порядок воспроизведения сохранён: буква, затем номер строки.

`tools/symmetry_draw/sync-coordinate-audio.mjs` синхронизирует источники
при сборке ZIP, поэтому тема работает и без сети. Генератор направлений
теперь тоже копирует координаты и не синтезирует их даже с `--force`.
Фразы команд по направлениям являются отдельными записями и не изменены.

Новая версия темы — 1.12.15. Проверка `dictation-audio.test.mjs`
сравнивает все 40 записей внутри реально собранного ZIP с источниками.

## Команды по направлениям — голос владельца (ElevenLabs)

09.10.2026 все 48 записей `tools/symmetry_draw/audio/dictation/directions/`
переозвучены клонированным голосом владельца «Дмитрий Мазниченко» в ElevenLabs
(модель `eleven_v4`). Подачу утвердил владелец после нескольких проб:
дружелюбно, без драматизма, чуть неторопливо, как учитель диктует ребёнку.

Шаблон текста: `[friendly] [unhurried] <Число словами> <клетка/клетки/клеток> <направление>.`
Например: `[friendly] [unhurried] Две клетки вправо.`; диагонали слитно —
`Три клетки влево-вверх.` Числа пишутся словами (одна, две, … четырнадцать),
чтобы не было ошибок в роде и ударении.

Координаты (буквы и числа) не менялись — см. раздел выше.

Новая версия темы — 1.12.16. `generate-dictation-audio.mjs` (Gemini) по
умолчанию пропускает существующие файлы; не запускайте его с `--force` для
направлений — это заменит голос владельца синтетическим.
