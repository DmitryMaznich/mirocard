# Координаты: утверждённые записи

По запросу владельца 09.10.2026 заменены самостоятельные синтетические
записи координат в теме «Рисуем по клеткам»:

- 20 букв столбцов — человеческие записи из `public/audio/propis-dictation`.
- Числа 1–20 — готовые записи из `public/audio/addition-subtraction`, включая
  утверждённые замены 1, 3, 4, 5, 6.

Копирование побайтовое, без генерации, обрезки или перекодирования.
Соответствие столбцов учитывает пропуск Ё и З: столбец 8 — К.
Порядок воспроизведения сохранён: буква, затем номер строки.

`tools/symmetry_draw/sync-coordinate-audio.mjs` синхронизирует источники
при сборке ZIP, поэтому тема работает и без сети. Генератор направлений
теперь тоже копирует координаты и не синтезирует их даже с `--force`.
Фразы команд по направлениям являются отдельными записями и не изменены.

Новая версия темы — 1.12.14. Проверка `dictation-audio.test.mjs`
сравнивает все 40 записей внутри реально собранного ZIP с источниками.
