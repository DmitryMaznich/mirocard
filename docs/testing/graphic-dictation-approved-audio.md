# «Рисуем по клеткам»: утверждённая озвучка

С 09.10.2026 вся озвучка темы — клонированный голос владельца «Дмитрий
Мазниченко» в ElevenLabs (модель `eleven_v4`). Подачу утвердил владелец после
нескольких проб: дружелюбно, без драматизма, чуть неторопливо, как учитель
диктует ребёнку. Шаблон текста: `[friendly] [unhurried] <текст>.`

Все записи лежат в `tools/symmetry_draw/audio/` и коммитятся как есть; сборка
ZIP (`build.mjs`) кладёт их в колоду без изменений, поэтому тема работает без
сети. Генератор `generate-dictation-audio.mjs` (Gemini) по умолчанию
пропускает существующие файлы и никогда не трогает координаты; не запускайте
его с `--force` — это заменит голос владельца синтетическим.

## Команды графического диктанта: «N клеток» + направление

Команда собирается из двух записей, как координаты (вариант «B», утверждён
владельцем 09.10.2026 после сравнения с целыми фразами и склейкой по словам):

- `audio/dictation/cells/1..20.mp3` — «Одна клетка», «Две клетки», …
  «Двадцать клеток» (число словами, правильная форма слова «клетка»);
- `audio/dictation/directions/<направление>.mp3` — «вверх.», «вниз.»,
  «вправо.», «влево.», диагонали слитно: «вправо-вверх.», «влево-вниз.» и т.д.
  Записаны с точкой — с завершающей интонацией.

Приложение играет их подряд с паузой 120 мс («Две клетки» → «вправо»). Тишина
по краям записей обрезана, чтобы шов был коротким. Любая новая фигура с ходами
до 20 клеток озвучивается автоматически — думать про озвучку не нужно;
ход длиннее 20 клеток валится в тестах (`directionAudioPaths`).

Раньше (1.12.16–1.12.17) было 48 целых фраз `directions/<направление>_<N>.mp3`
— по одной на каждое сочетание из фигур; от этого отказались, потому что каждая
новая фигура требовала новых записей.

## Координаты

- `audio/dictation/coordinate_letters/0..19.mp3` — названия букв столбцов
  («А», «Бэ», «Вэ», … «Ха»). Столбцы пропускают Ё и З: столбец 8 — «Ка».
- `audio/dictation/coordinate_numbers/1..20.mp3` — номера строк
  («Один» … «Двадцать»).

Порядок воспроизведения: буква, затем номер строки. До 09.10.2026 здесь
побайтово копировались звуки букв из `public/audio/propis-dictation` и числа из
`public/audio/addition-subtraction` (скрипт `sync-coordinate-audio.mjs`);
скрипт удалён, теперь записи — самостоятельные файлы темы.

## Навигатор «на слух»

`audio/navigator/<направление>.mp3` — 8 команд: «Вверх», «Вниз», «Вправо»,
«Влево», «Вверх и вправо», «Вниз и вправо», «Вверх и влево», «Вниз и влево».
Раньше режим говорил браузерным синтезом (`speechSynthesis`); теперь он играет
эти записи через `playTopicFiles`, а синтез остаётся запасным вариантом, если
запись не проигралась (звук выключен, файл не найден). Если не работает ни
то, ни другое, команда показывается текстом.

## Проверка

`dictation-audio.test.mjs` проверяет, что все записи (20 «N клеток»,
8 направлений, 40 координат, 8 команд навигатора) попадают в реально собранный
ZIP байт в байт, и что у каждой команды каждой фигуры есть обе записи.

Версии темы: 1.12.16 — направления целыми фразами, 1.12.17 — координаты и
навигатор, 1.12.18 — команды диктанта из двух частей.
