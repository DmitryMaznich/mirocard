# Прописи 2 (propis2) — конструктор страниц прописей

Новая автономная тема, которая заменит «Прописи» (v1) после завершения. v1 заморожена: новых
функций в ней нет; правки форм букв идут в общий `tools/propis` и попадают в обе темы.

## Архитектурные решения (2026-10-03)

- **Zip-тема, как и все остальные** (не builtin — это было отвергнуто 2026-10-03). Пакет:
  `tools/propis2/topic.json` + `scripts/build-propis2-deck.mjs` → `public/decks/propis2_vX.zip`
  и запись в `public/decks/catalog.json` (status beta). В zip подмешиваются данные глифов из общих
  `tools/propis/wide.json` и `elements.json` (≈25 КБ в сжатом виде) — один источник правды с v1.
  Сборка: поднять `meta.version` в `tools/propis2/topic.json`, `node scripts/build-propis2-deck.mjs`.
- **Рендерер в приложении**, как у v1 (`RENDERER_REGISTRY.propis2`), код движка не копируется, а
  импортируется из `renderers/propis/` (`wordEngine.js`, `PrintPageView.jsx`). Страница — задача
  `print_page` (`renderers/propis2/pageTask.js`), данные берутся из установленной темы
  (`topicRecord.wide / wideSheets / elements`).
- **Найденная ошибка установщика:** `importTopic` отбрасывал `wide`, `wideSheets`,
  `wideElementRepeat` при сохранении темы (как раньше `elements`). Исправлено в `topicLoader.js`,
  тест `src/topics/propis2Install.test.js` (и для v1).
- **Домашний экран темы — конструктор.** `App.jsx`: экран `params` для renderer `propis2`
  открывает `features/propis2/Propis2Home.jsx` вместо `ParamsScreen`.
- Хранение страниц: IndexedDB (`kv`), синхронизация с аккаунтом — позже; экспорт/импорт файлом.

## Что сделано

- **Шаг 0 (скелет, v0.1.0):** тема в списке, свой главный экран.
- **Шаг 1 (сквозной сценарий, v0.2.0):** «Мои страницы» (`Propis2Library`) → конструктор
  (`Propis2Editor`: название, разлиновка узкая/широкая, строки трёх видов — образец / образец с
  точками старта / чистая; тип «буквы, слоги, слова» или «элемент»; вверх/вниз, дубль, удаление;
  предупреждения о символах без начертания и о строках шире листа) → «Показать как ученику»
  (общий `PrintPageView`: тап по строке — анимация, зум, листание, «🖨 Печать»). Страницы
  сохраняются автоматически в IndexedDB (`propis2:library`), создаются с нуля, из готового набора
  (листы 1–18) или копированием.
  Файлы: `renderers/propis2/{model,storage,pageTask,data}.js`, `features/propis2/*`.
  Тесты: `model.test.js`, `storage.test.js`, `Propis2Home.smoke.test.jsx` (весь сценарий).
- **Шаг 2 (повторение и тексты, приложение без новой версии колоды):** тип строки «Текст
  (переносится по строкам)» — жадный перенос по ширине листа, каждая строка пишется один раз (метка
  `#1` в движке: однословная строка не размножается), слово шире листа предупреждается, не
  обрезается; тип «Пустая строка для письма» и опция страницы «пустая строка после каждой строки»
  (движок рисует пустую разлинованную строку для `""`); отметка «повторить» у строк и кнопка
  «Страница из отмеченного» (целые строки; новая страница редактируема, исходная не меняется).
- **Шаг 3 (панель показа):** тап по образцу на странице открывает панель (`Propis2ShowPanel`):
  тот же фрагмент (слово под пальцем; у строки с повторами — одно слово) крупно на собственной
  разлиновке, кнопки «Повтор», «Медленно» (скорость ×0,4 без перезапуска), «Закрыть». Страница
  остаётся смонтированной под панелью, поэтому номер страницы, зум и прокрутка сохраняются;
  одновременно идёт только одна анимация (на странице встроенная анимация отключена).
  В v1-код добавлены только опциональные, по умолчанию инертные свойства: `PrintPageView`
  (`onFragmentTap`, `bare`, `focus`, `speedFactor`), `AnimatedStrokes`/`useLoopingStrokes`
  (`speedFactor`).
- **Шаг 4 (комплекты):** «Мои страницы» → раздел «Комплекты». Комплект — упорядоченный список
  страниц библиотеки (одну страницу можно добавить несколько раз), общая разлиновка на весь
  комплект, перестановка, «дублировать» (независимая копия страницы в библиотеке сразу после
  оригинала), правка страницы прямо из комплекта, подпись «с листа N». Показ и печать — одним
  буклетом: каждая страница комплекта дополняется пустыми строками до целого экранного листа
  (`setToLines`), поэтому счётчик движка «Страница k из N» и есть номер страницы комплекта на экране
  и на бумаге; переход вручную. Удаление страницы убирает её из комплектов. Код: `model.js`
  (`newSet/setToLines/setPageStarts`), `storage.js` (`upsertSet/removeSet`),
  `features/propis2/Propis2SetEditor.jsx`.
- **Шаг 5 (предпросмотр):** рядом с редактором (на экранах от 900 px — справа и закреплён, на узких —
  под формой) страница так, как она будет показана и напечатана (`Propis2Preview`, `PrintPageView`
  с `bare`), с переключателем листов и кнопкой «Скрыть/Показать предпросмотр». Раскладка идёт по
  отложенной копии страницы (`useDeferredValue`), ввод не тормозит.
- Не проверено вручную в браузере: печать (используется механизм v1), установка из каталога в
  живом приложении.

## Конструктор v2: карусель + страница (2026-10-03)

Редактор из формы (список строк с селектами) заменён на «сборку руками»: слева вертикальная зацикленная
карусель плиток (вкладки Элементы / Строчные / Заглавные, плитки нарисованы собственными траекториями),
справа страница. Плитка перетаскивается на конкретную строку (pointer events: мышь — сдвиг >5px, палец —
горизонтальный сдвиг, вертикальный остаётся прокруткой карусели) или тапается (встаёт под последней строкой).
Тап по строке страницы выделяет её; панель внизу правит текст, вид (образец / с точками / чистая),
«повторить», порядок, дубль, удаление. Слова и тексты — кнопки «+ Слово», «+ Текст», «+ Пустая строка».
Модель страницы и хранение не менялись; новое в `model.js`: `lineOwners`, `dropTile`, `appendTile`.
Геометрия строк для попадания: `rowAtSvgY` в `PrintPageView.jsx`; подсветки — проп `overlays`.
Слогов в карусели нет (набираются в «+ Слово»). Перестановка строк перетаскиванием не сделана (кнопки ↑ ↓).
`paginateRows(..., { exact })`: страницы v2 не добиваются до чётного числа (флаг `exactPages` в задаче).

### Раскладка v2.1 (2026-10-03, по просьбе пользователя)

Холст-страница сверху (на всю ширину, но не выше доступного места больше чем на 20%: `MAX_OVERFLOW` в
`Propis2Editor.jsx`; небольшой вертикальный скролл допускается), над ним одна линия настроек
(узкая/широкая, «писать под каждой строкой», «Из отмеченного»), внизу табы «Символ / Слово / Текст».
«Символ» — горизонтальная зацикленная карусель (перетаскивание вверх; у касания вертикальный жест = перенос,
горизонтальный = прокрутка карусели). «Слово» и «Текст» — ввод + кнопка добавления + плитка-«чип» для
перетаскивания на строку. При перетаскивании у верхнего/нижнего края холста страница сама прокручивается.
Не сделано: переключатель «редкая / частая косая линейка» (движок: шаг косой сетки `NARROW_CELL`, к нему
привязывается начало букв — нужна проверка готовых наборов); буквы ш, ы, ии не имеют своих штрихов
(`compose`) и показаны в карусели текстом.

### Раскладка v2.2 + линейка (2026-10-03)

Альбомный планшет (≥900px и ширина ≥ высоты, `SIDE_QUERY` в `Propis2Editor.jsx`): лист слева на всю высоту, справа
панель (настройки, панель строки, табы; карусель там — обычная прокручиваемая сетка без цикла, перетаскивание
касанием — горизонтальным жестом). Портрет: как v2.1 (лист ≤ 120% высоты свободного места).
Линейка (уточнено пользователем дважды; итог): `page.grid` = "regular" (редкая, стандартная школьная — наклонная
линия через 20 мм, `SHEET_DIAGONAL_LINES`) | "dense" (частая — шаг следует строке и равен расстоянию между вершинами «и»: 3 мм на узкой строке
(`SHEET_DIAGONAL_LINES_DENSE`, как на листах «Элементы букв» v1), 5 мм на широкой (`SHEET_DIAGONAL_LINES_WIDE_DENSE`)); `page.midDash` — пунктир в серединных линиях (узкая и широкая строка). Обе сетки взяты из готовых
тетрадей v1 (`ELEMENT_DIAGONAL_MM`, `DIAGONAL_MM` в propisRuling.js). При "dense" начала букв привязываются к НАРИСОВАННЫМ линиям (`drawnGridSnapX` в PrintPageView.jsx: линия n = n*шаг − y·tan,
нечётные страницы сдвинуты на ширину листа, как рисует PrintPage). При "regular" (20 мм) привязка осталась по скрытой
методической сетке: к линиям через 20 мм буквы не привязать. Методическая сетка на страницах v2 НЕ рисуется (`simpleGrid` в задаче → `PrintPageView`, у v1 флага нет,
v1 не затронут). Комплект берёт линейку и пунктир первой страницы.

### Знаки препинания (2026-10-03, deck 0.3.0)

`. , ! ?` взяты из v1 (`tools/propis/topic.json`, карточки `type: "punctuation"`, записанный штрих) и добавлены в
`tools/propis/wide.json` как глифы `kind: "punct"` (`noJoin`, `noNormalize`, `stretch: 1`, y сдвинут на −26: база v1 88 →
база захвата 62). Движок: глиф с `noJoin` ставится сразу после предыдущего глифа слова (зазор `WIDE_PUNCT_GAP`), без
соединительной линии и без привязки к сетке; у v1 таких глифов нет, поведение v1 не меняется. В карусели вкладка «Знаки».
Цифр в v1 НЕТ (там они подставляются системным шрифтом, штрихов не записано): цифры требуют отдельной оцифровки.
Не записаны также заглавные Ё Й Ъ Ы Ь.

### Широкая строка: только буквы внутри строки; телефон (2026-10-03)

* «!» и «?» увеличены до высоты заглавной (в wide.json; ×~2.1 от v1, `. ,` как в v1).
* Широкая строка (`page.ruling === "wide"`) — как в методике: только символы, которые не выходят за строку. Выход считается
  по раскладке движка на узкой строке (`glyphReach.js`, допуск 4 ед. на петлю/точку): недоступны все заглавные, строчные
  б в д з р у ф ц щ и знаки ! ?; `. ,` и элементы доступны. В карусели такие плитки скрыты (вкладка «Заглавные» тоже),
  в набранном слове/тексте они подсвечиваются красным с пояснением (`findOutsideRow`, поле `outside` в `analyzeRow`).
  ё и й попали в допустимые (точки/бровка выходят всего на 3 ед.) — при необходимости ужесточить `TOLERANCE`.
* Телефон (≤640px, портрет): лист на всю ширину, виден примерно наполовину, остальное скроллом внутри холста;
  сверху полный набор настроек (переносится на несколько строк), снизу панель строки и табы.
* Не сделано: цифры (нужны собственные захваты, в v1 их нет), «клетка» и «обычная линейка» как типы сетки.
