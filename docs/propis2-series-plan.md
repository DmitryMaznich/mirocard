# Серия готовых тетрадей «Прописи» — подробный план (черновик на согласование, 2026-10-23)

Задача владельца: все готовые тетради — одна методическая серия, как её построил бы учитель начальных классов и логопед,
обучающий письму детей с РАС. Каждая тетрадь — **24 страницы A5** (12 тетрадных листов; печать «Тетрадью» — 6 листов A4,
сложить и скрепить по сгибу, без обрезки). Заменяет нынешние готовые тетради (кроме цифр и чистых); уже взятые копии остаются.

## 1. Принципы

1. **Одна новая вещь за раз.** Новый элемент или буква получает 2–3 страницы, а не строку.
2. **Одинаковая страница.** Каждая страница одного типа устроена одинаково (ребёнок с РАС заранее знает, что его ждёт).
3. **Помощь убывает внутри страницы:** затухающие копии → обводка по пунктиру → по точкам начала → самостоятельно.
4. **Повторение** — каждые 4–6 страниц страница смешанного повторения; последняя страница тетради — итог.
5. **Заканчиваем успехом:** последняя строка страницы — лёгкая (обводка), а не самая трудная.
6. **Широкая строка — только то, что внутри строки** (элементы без петель и строчные а г е ё ж и й к л м н о п с т х ч ш ъ ы ь
   э ю я). Всё, что выходит за строку (петли, б в д з р у ф ц щ, все заглавные), — только на узкой строке.
7. **Сначала все строчные, потом заглавные.** Слова до тетради 10 — только строчными.
8. Слоги и слова — только из уже пройденных букв.

## 2. Типы страниц

Широкая строка — 16 строк на странице, узкая — 17 (лишняя строка — ещё одна самостоятельная).

| Тип | Для чего | Строки (широкая, 16) |
|---|---|---|
| **А. Знакомство** | новый элемент / буква | 4 затухающие копии · 4 обводка по всей строке · 4 по точкам начала · 3 самостоятельно (образец в начале) · 1 обводка |
| **Б. Закрепление** | вторая–третья страница того же | 2 затухающие · 6 по точкам · 7 самостоятельно · 1 обводка |
| **В. Повторение** | смешанное пройденное | каждая строка — другой пройденный элемент/буква: по точкам, затем самостоятельно; последняя — обводка |
| **Г. Слоги и слова** | соединения | на слог/слово 2 строки: обводка по строке, затем образец + самостоятельно |
| **Д. Итог** | последняя страница тетради | всё пройденное по строке, только образец в начале строки |

### Переход

**Тетрадь 6. Знакомые буквы на узкой строке** — те же буквы тетрадей 3–5, меняется только высота строки.
Стр. 1–15: по странице на группу из 2–3 букв (тип Б); стр. 16–23: слоги и слова (тип Г); стр. 24: итог.

### Узкая строка

**Тетрадь 7. Петли** (элементы)
Стр. 1–4 палочка вниз за строку (основа «р») · 5–8 петля вниз (основа «у», «д», «з») · 9–10 повторение · 11–14 петля вверх
(основа «в», «б») · 15–16 повторение · 17–23 чередования петель и знакомых элементов · 24 итог.

**Тетрадь 8. Буквы р у д з ц щ** — по 2 страницы (А, Б) = 12; слова после каждой пары букв (6 стр.): пир, гири, паук, куртка,
радуга, коза, цирк, щука; повторение — 2 стр.; итог — 1; ещё 3 стр. слов.

**Тетрадь 9. Буквы б в ф + весь строчный алфавит** — б, в, ф по 3 страницы (А, Б, Б) = 9; слова: барабан, бабочка, ветер,
павлин, кофе, фонари (5 стр.); стр. 15–23 — весь алфавит по порядку, по 4 буквы на страницу (тип В); 24 — итог.

### Заглавные (узкая строка)

**Тетрадь 10. Заглавные 1:** И Ш Ц Щ У Ч, Г П Т Р Л А, Н Ю К, Й — по странице (16), затем 8 страниц: заглавная + знакомое слово,

### Связное письмо (узкая строка)

**Тетрадь 12. Слоги и соединения** — 24 стр. из 160 слогов нынешней тетради: сначала лёгкие соединения (и, ш, н…), затем трудные
(после о, в, б, ф: «ов», «бо», «фа»).

**Тетрадь 13. Слова 1** — короткие слова из близкого (дом, семья, еда, игрушки), 2 строки на слово.

**Тетрадь 14. Слова и фразы** — длинные слова, имена, фразы из 2–3 слов.

**Тетрадь 15. Знаки препинания** — нынешняя тетрадь (24 стр.), без изменений по составу.

**Тетрадь 16. Списываем текст** — нынешняя тетрадь (24 стр.).

### Вне лесенки

**Цифры** (24 стр., в клетку) и чистые тетради — как сейчас.

## 4. Что уходит

«Листы методики, часть 1/2», «Простые/Сложные буквы: строчная и заглавная», «Весь алфавит А–О / П–Я», «Слоги», «Слова 1/2» —
их содержание разложено по тетрадям 1–14. Решение по «Весь алфавит» — за владельцем (см. вопросы).

## 5. Ограничения набора

- Отдельного **овала и полуовала** среди записанных элементов нет — овал отрабатывается на буквах «о», «а», «с» (тетрадь 4).
  Если нужен элемент «овал» — его надо записать (захват), как остальные элементы.
- Часть элементов из `elements.json` (острый заборчик, крючки влево/вправо) записана неудачно — в план не взяты; в плане только
  элементы, которые проверены отрисовкой.
