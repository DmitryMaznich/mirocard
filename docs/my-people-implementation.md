# Мои люди — рабочая реализация v2

2026-11-04. Согласованная механика реализована в коде приложения. Озвучка использует существующий TTS и переключатель звука; окончательная приёмка голосов остаётся отдельной.

## Как попробовать

«Мои люди» → **Новая механика** → **Для взрослого** → выбрать цель, формат и задание → **Все параметры** → **Подготовить ребёнку** или **Начать вместе**.

Первое включение выполняет взрослый через существующий PIN, если он установлен. Приложение сохраняет выбор интерфейса для ученика через account KV. У пользователей без явного выбора остаётся прежний маршрут. Это пилотное включение, а не автоматическая замена темы у всех учеников.

Самостоятельный план запускается одной кнопкой «Начать». Черновик не меняет подтверждённый план. Настройки изолированы по имени/отношению, выбору/называнию и самостоятельному/взрослому формату. При недостатке однозначных дистракторов занятие не запускается с уменьшенным полем.

В назывании со взрослым внизу только четыре кнопки. Встроенная помощь и начальный образец блокируют «Полностью сам»; помощь переживает восстановление занятия. Самостоятельное называние — практика без проверки речи и процента правильности.

Имена и допустимые отношения хранятся отдельно. В редакторе карточки есть дополнительные отношения, варианты имени, начало имени для подсказки и группа «Друзья»; прежняя группа «Дома» сохранена. Имя и отношение не засчитываются друг за друга. У питомцев тренируется имя.

Новый сценарий использует общий SessionScreen, настройки темпа ученика, политику призов и checkpoint/final. Журнал в statistics.myPeople содержит отдельные ID основных проб, предъявлений и возвратов после помощи. Исправление остаётся одной пробой. Открытая оценка отношения не засчитывает автоматически все связи. Фото сохраняются в результатах как ссылки/хеши, без копий base64.

Взрослая сводка показывает условия, основных людей/слова, помощь и отдельные возвраты. Следующий план остаётся черновиком на той же сложности. Прежняя история не превращается в новые результаты.

## Возврат

В подготовке → **Вернуться к прежней механике**. Старые ID режимов, данные, генератор и рендерер сохранены. В «Дополнительных упражнениях» доступны прежние занятия. Их нижняя панель называния также сокращена до четырёх кнопок.

Схема SQLite не меняется. Изменения карточек аддитивны; строка relation и прежние массивы/ID/флаги продолжают использоваться. Проверены чтение/запись старого формата и сохранность новых полей после таких записей. Резервная ветка исходников: backup/my-people-before-redesign-2026-11-04, SHA 9b7ca097983cd5cc2906563063deab45be7412c5.

Production /api/healthz перед подготовкой выпуска подтвердил db:true и backupAgeMinutes:32 (версия 1.0.2818). Это подтверждает наличие штатного снимка на Railway Volume, но не заменяет проверку восстановления production-копии вне volume. Такая аварийная репетиция сейчас не выполнена. До глобального включения нового входа по умолчанию остаются требования docs/my-people-rollback.md к независимой копии и восстановлению. Пилот переключается интерфейсом на текущих совместимых данных; восстановления старой БД для этого не требуется.

## Проверки и устройство кода

- Доменная логика: src/features/myPeople/peopleLearning.js; словарь и порядок документов: shared/my-people-v2.mjs.
- Контракт событий/помощи/призов: peopleLearningSession.js, подключён к useSessionEngine.
- Локальное атомарное сохранение документа и offline-операции: peopleLearningStore.js. Сервер применяет сравнение revision только к новому пространству my_people:v2, защищая от устаревших offline-записей; конфликт подтверждения показывается взрослому.
- Интерфейс: PeopleLearningHome/Task/Summary.jsx, peopleLearning.css. Фото кэшируются в IndexedDB по аккаунту и ученику; административное удаление ученика очищает этот кэш.
- Сквозная браузерная проверка реальных компонентов: npm run dev, затем PLAYWRIGHT_CHROMIUM_EXECUTABLE=/usr/bin/chromium node scripts/test-my-people-v2-ui.mjs (путь к Chromium задаётся для Linux; без него используется установленный Chrome). Все API перехватываются тестом, используются вымышленные карточки; production не затрагивается. Проверяются восемь сочетаний цели/формата/задания, поле из шести фото, четыре кнопки, восстановление помощи, самостоятельная практика, выключение озвучки и ширины 390/320 px.
- Доменные, интеграционные и серверные тесты лежат рядом с изменёнными модулями и в backend/tests/my-people-v2.test.mjs. Аудит общей статистики использует новый типизированный адаптер, а не выдуманный generic-correct для v2.

Реальное Safari/iOS, окончательный голос и произношение личных имён требуют отдельной проверки на устройстве. HTML-макеты остаются источником дизайна; они не импортированы в приложение.
