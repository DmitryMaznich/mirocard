# Пилот, классификация и следующие задачи

Статус: рабочее предложение по результатам статического аудита. Ни языковая, ни методическая приёмка ещё не проведена. Редактор, методист и тестовые устройства пока не назначены; это блокирует выпуск, но не технический прототип.

## Паспорт A: транспорт

Рабочий кандидат: `transport_photo` вместо одежды: generated inventory указывает 28 карточек против 75 у clothes_basic при одинаковом flashcards renderer и четырёх режимах. Это уменьшает словарный объём кандидата, но не доказывает методическую простоту.

Цель: проверить путь словарной темы целиком — каталог, установка, выбор, инструкции, карточки, ответы, аудио, результат и повтор без сети.

| Часть | Граница пилота / критерий |
| --- | --- |
| Режимы | Начать с знакомства и выбора изображения по услышанному/показанному слову, если именно такие mode IDs подтверждены в текущем ZIP. Сейчас точные ID не известны из текстовых исходников: до их проверки паспорт не считается окончательным |
| Данные | Проверить все 28 карточек, вариации и concept IDs. Согласовать ограниченный учебный словарь; одинаковые изображения не гарантируют одинаковые границы понятия в SL |
| Ответы | Дистракторы из той же утверждённой SL-лексики; не переводить готовые RU-варианты после генерации |
| Озвучка | Один утверждённый SL-ресурс для каждого используемого слова/инструкции. Для слухового задания файлы обязательны и доступны offline |
| Печать | Не включать неадаптированный PDF в готовый SL-набор; если режим предлагает печать, либо адаптировать её, либо явно не публиковать этот режим |
| Приёмка | Нет RU-подстановок; повтор/ошибка/подсказка работают; история RU/SL раздельна; RU-пакет остаётся рабочим |

Блокирующая задача LOC-00: распаковать `transport_photo_v1.1.0.zip`, записать реальные режимы/карточки/файлы и проверить соответствие generated inventory. Не объявлять готовность темы по четырём режимам из числового реестра. Если не находится простой набор целевых режимов, вернуться к clothes_basic по тем же критериям.

## Паспорт B: сравнение

Подтверждённый исходный mode ID — `compare_visual`, type `compare_visual` в `tools/comparison/topic.json`; текущий пакет в каталоге 2.36.1, source manifest 2.36.0. До реализации сверить установленный пакет.

Первый ограниченный вариант: точки, вопрос «где больше», небольшой диапазон, без равенства, без словесных числительных. Это сокращение публикуемых параметров SL-режима; RU-возможности сохраняются. Даже в нём `taskInstruction`, `equalHint` и `getVerdict` проходят engine и renderer и требуют явного языкового модуля. Простая замена `mode.ui.instruction` недостаточна.

| Часть | Граница пилота / критерий |
| --- | --- |
| Цель | Сравнить количество двух групп; ответ касанием, одинаковая механика и критерии ошибки на RU/SL |
| Генерация | Числа/правильная сторона не меняются от UI-языка; задание содержит зафиксированный contentLanguage |
| Тексты | Инструкция, вердикт, подписи/aria-label, помощь взрослому, параметры. Для числового вердикта можно использовать утверждённый шаблон с цифрами, не русские NUM_NOM/GEN/DAT |
| Аудио | Сначала определить роль аудио в этом варианте; если подсказка необязательна — отсутствие голоса объясняется взрослому без голоса другого языка |
| Исключено из первого SL-варианта | compare_first_number, compare_real_life, verbal-style, контрольная и остальные параметры до собственной адаптации. Не делать вывод об их готовности по одной локализованной механике |
| Приёмка | Несколько разных пар, правильные/ошибочные ответы, hint, повтор и продолжение offline; UI RU + lesson SL и наоборот; engine bundle и ZIP показывают согласованные фразы |

«Мои люди» остаётся третьим последующим пилотом: mode IDs `match_same`, `show_me`, `who_is_this`, `about_me`, `label_photos`, `introduce_self` видны в builtinMyPeopleTopic; retired album modes отдельно. Из-за ссылок на объекты/фабрику эти режимы не входят в автоматический прямой проход массивов modes.csv — это известная граница статического извлечения.

## Минимальная матрица проверок реализации

- RU UI + SL lesson; SL UI + RU lesson; изменение UI в активном занятии не меняет tasks/аудио.
- Ученики с разными предпочтениями; временный выбор не переносится на следующего.
- Cold boot, медленный bootstrap, offline выбор, поздний pull, повтор sync, logout/login на общем устройстве.
- RU+SL install, interrupted update, delete одного языка, сохранённая старая версия, старый ZIP без контракта.
- Старый snapshot и история неизвестного языка; два языка одного concept ID; checkpoint/final и повтор загрузки.
- Словенские plurals (включая 2/102), переменные и длинные строки; `č š ž`, экранный диктор, доступный размер кнопок.
- Нет SL-голоса, voiceschanged, запрет autoplay, звук выключен, обязательный файл отсутствует.
- Восстановление пароля и email deep links, продолжение из плана, печать в отдельной вкладке.

Пока выполнена статическая проверка реестров. Эти сценарии ещё не пройдены на реализованной локализации.
