## Что реализовано

UI темы хранится отдельно от учебных реплик. Никаких новых русских фраз в общем словаре-переходнике. Общий экран поддерживает `content_language` без ветки по ID пилота. Выбранный язык и версия пакета передаются engine явно; зависимость от UI/account/browser state запрещена линтером для новых модулей. На старте создаётся фиксированный контекст пакета, включённый в checkpoint и `statistics.conditions.languageContext`. Восстановление проверяет этот контекст. Недоступное предпочтение ученика/аккаунта требует явного выбора; генератор не делает RU fallback.

Один и тот же валидатор вызывается при сборке и импорте. CI проверяет исходники и реальный ZIP, семантические ключи/переменные, идентичность пакетов, доступность режима, отсутствие заявленной неподдерживаемой речи. Хеши исходников в ZIP выявляют забытое пересобирание renderer/engine после правки.

## Как открыть

Существующий доступ `catalog_all_access` показывает скрытый пилот в библиотеке. Альтернатива: скачать https://app.mironium.com/decks/comparison_language_pilot_v0.1.0.zip и импортировать через «Темы → + ZIP». Это бесплатный архив; скрытость в каталоге не ограничивает прямое скачивание. Автоустановки нет, права аккаунтов не изменялись.

## Ограничения и следующий шаг

Только первый режим. Нет учебной речи; общие feedback-сигналы остаются. Пакеты имеют свои ID/версии, но пока доставляются одним ZIP; независимая загрузка не реализована. Нужна редактура словенского носителем и проверка реальных занятий перед публичным выпуском. Далее переносить остальные режимы в копию по одному, с собственными учебными правилами и проверками. Все старые темы не объявляются соответствующими контракту автоматически. UI самого занятия и специальные настройки старых тем ещё не полностью локализованы.
