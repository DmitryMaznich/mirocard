20 октября 2026. Приложение 1.0.2674, копия `comparison_language_pilot` 0.3.0.

- [PR #36](https://github.com/DmitryMaznich/mirocard/pull/36), main `046d9879d6f12a844b51833871acfdcb3e1da8f5`.
- [PR CI](https://github.com/DmitryMaznich/mirocard/actions/runs/39404343509), [main CI](https://github.com/DmitryMaznich/mirocard/actions/runs/39404547587): по шесть успешных jobs.
- Откат: `codex/rollback-before-topic-language-download-2674`, 1.0.2673 / fffa632.

Пользователь попросил убрать постоянный выбор языка из параметров режимов и
скачивать только нужный языковой материал, включая будущую речь и подписанные картинки.
Теперь перед скачиванием/обновлением темы открывается окно с нативными названиями
языков, доступными режимами, наличием речи и размером недостающих файлов.
Выбор сохраняется для ученика/темы; общие файлы переиспользуются на устройстве.
Язык меняется в меню/на главном экране темы. UI и материал независимы, занятие
сохраняет зафиксированный контекст. История и настройки оригинала не затрагиваются.

Общий архив не содержит учебных `content/`-файлов, языковые архивы содержат только
свой материал и объявленные assets. Идентичность, пути, размеры и SHA-256 проверяются
до единой транзакции IDB. Повреждённая загрузка или ошибка записи сохраняет рабочую тему.
Платные части обслуживаются только API с проверками владения/подписки; прямой
статический fallback запрещён. Старые цельные ZIP остаются совместимы.
Пилот по-прежнему содержит два режима и не содержит речевой озвучки.
Отдельное удаление одного пакета и автоматическое обновление разделённых тем пока не включены.

Проверки: 2278 frontend-тестов, 323 backend-теста, 23 языковые/rollout-проверки,
strict lint новых модулей и backend, production build, validator source/core/packs.
Chromium 390×844 и iOS safe-area 59/34: все четыре UI/material сочетания, отмена
без скачивания, только выбранный пакет, запуск и перезагрузка занятия, добавление
другого языка без core-загрузки, офлайн-выбор скачанного. Ошибок страницы и переполнения нет.
Языковые audio/image проверены синтетическими регрессиями; фактическая речь не заявляется.

Railway: точная 1.0.2674 / 046d987, health=ok/db=true. Все три опубликованных
архива побайтно совпали с локально проверенными, их размеры/хеши соответствуют каталогу.
Публичный каталог (25 тем) не изменился, оригинальный comparison ZIP сохранил
SHA-256 `d3b375f204c0cded3d43b3d96aeda47ae2b875b41681e86a1490956ff82a6ccd`.

Импорт откроет выбор языка, скачает только выбранный пакет. Копия всё ещё скрыта
в общем каталоге, ID копии прежний. [Протокол и ограничения](topic-language-download.md).
