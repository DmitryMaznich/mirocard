# Реестр сценариев интерфейса

Основание: `src/App.jsx`, feature-компоненты и общие компоненты на исходном коммите из README. Полный перечень зарегистрированных маршрутов — [screens.csv](inventory/screens.csv). Эта таблица группирует маршруты по пользовательскому пути; состояния ниже — обязательная матрица реализации и проверки, а не утверждение, что каждое уже воспроизведено в браузере.

P0 — основа и первый путь взрослого; P1 — остальные открытые функции до публичного выпуска; P2 — скрытые/архивные функции и редакторские инструменты. Владелец каждой группы до назначения человека — разработчик; редактор проверяет текст, QA — состояния.

## Обязательные макеты следующего прохода

1. Переключатель до входа и на экране настроек: Русский / Slovenščina; English пока не опубликован.
2. Профиль ученика: основной язык и отдельное предпочтение занятий, без двусмысленного общего поля.
3. Каталог: язык занятий, установленные версии, частично доступные режимы и пустая выдача.
4. Подготовка: фактический язык, выбор доступной версии, нет материала/обязательного аудио.
5. Продолжение и история: язык записанного занятия; старый неопределённый язык.

Макеты ещё не созданы. Первый технический прототип LOC-01 должен дать проверяемый экран выбора языка; остальные макеты входят в LOC-03/05. Для каждого экрана: телефон 320–390px, планшет, увеличение текста, псевдолокаль с удлинением, `č/š/ž`, клавиатура и экранный диктор. Целевые устройства и доступность словенского offline-голоса пока не проверены.
