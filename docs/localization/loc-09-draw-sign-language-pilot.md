# LOC-09: рисование знака в языковой копии

20 октября 2026. Приложение 1.0.2676, comparison_language_pilot 0.5.0.

- [PR #38](https://github.com/DmitryMaznich/mirocard/pull/38), main `840c7f0d3ae0f5590f4fe8d7e7b116c593d37045`.
- [PR CI](https://github.com/DmitryMaznich/mirocard/actions/runs/39446523862), [main CI](https://github.com/DmitryMaznich/mirocard/actions/runs/39446766519): PR — все шесть jobs успешны; main — пять успешны, frontend пока выполняет checkout.
- Откат: codex/rollback-before-comparison-draw-2676, 1.0.2675 / 56a537b.

Третий режим compare_draw_sign перенесён в существующую копию, без новой темы
или веток приложения по языку. Его инструкция ребёнку, доступное имя canvas и
результат принадлежат RU/SL-пакетам; методика и параметры принадлежат UI.
Настройки: сложность 1–4 и добавление равных чисел. «Больше/меньше» не добавлялось:
правильный знак определяется числами. Карточка pilot_draw и params.byMode
сохраняют отдельный навык и настройки; оба языка относятся к одному навыку.

Чистый распознаватель signRecognition.js скопирован без изменений из comparison
2.37.0; генерация пар сверена с оригиналом на всех уровнях и с равенством/без.
Renderer и CSS изолированы. Pending recognition отменяется на pause/unmount,
pointercancel отбрасывает незаконченный жест. Один submission guard исключает
двойной ответ. Стандартный taskRetry-key открывает чистый canvas для повтора.
При перезагрузке сохраняется занятие, но незаконченный рисунок нужно нарисовать заново.

Проверено: 2295 frontend-тестов, 53 focused, strict lint, source/core/packs validator,
production build. Миграция реального установленного core 0.4 с RU/SL до 0.5/SL
сохраняет настройки, прогресс и историю, не загружая новый RU-пакет.
Chromium 390×844/DPR2, safe-area59/34: четыре пары UI/material, жесты <, >, =,
ошибка и повтор, UI-смена во время штриха без подмены материала, точное сохранение
checkpoint после перезагрузки, ответ без сети, настройки первых двух режимов
не затронуты, retina и отсутствие горизонтального переполнения. Ошибок страницы нет.
Словенская вычитка выполнена исполнителем; двойственные формы и порядок сравнения
описаны в pilot-sl-language-review.md. Результат соответствует левому/правому числу.

Учебная озвучка инструкций не добавлялась. Существующая RU-подсказка после ошибки
работает и в третьем режиме, SL остаётся без речи. Один core и отдельные языковые
пакеты, выбор при скачивании на уровне темы ученика сохранены.

Railway подтвердил версию/коммит и здоровье БД. Все опубликованные архивы совпали
с проверенными, core содержит три режима и canvas, языковые пакеты объявляют новый
режим. Оригинальный comparison ZIP и публичный каталог неизменны, БД без миграций.

Для проверки обновить приложение и импортировать
https://app.mironium.com/decks/comparison_language_pilot_v0.5.0.zip через «Темы → + ZIP».
Выбрать язык, открыть третий режим «Нарисуй знак». Следующий шаг — четвёртый режим
«Сравни и поставь знак» в этой же копии.
