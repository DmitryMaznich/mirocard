# LOC-08: реальная русская запись в языковом пакете

20 октября 2026. Приложение 1.0.2675, пилот 0.4.0.

- [PR #37](https://github.com/DmitryMaznich/mirocard/pull/37), main `56a537b6f8eb85155bab5e1e9c947cc01830c3f3`.
- [PR CI](https://github.com/DmitryMaznich/mirocard/actions/runs/39415574961), [main CI](https://github.com/DmitryMaznich/mirocard/actions/runs/39415734763): все шесть jobs успешны.
- Откат: codex/rollback-before-topic-audio-2675, 1.0.2674 / 046d987.

Пользователь попросил отрепетировать весь цикл: русский материал со звуком,
словенский пока без речи. Проверка исходного comparison ZIP показала отсутствие
аудиофайлов в двух перенесённых режимах. Для репетиции использована действующая
русская запись «Посмотри ещё раз» из addition_subtraction/phrases/look_again.mp3.
Оригинальная тема и исходный банк не изменены, новых голосов не генерировали.
Пользовательская приёмка произношения этой записи не заявляется (исходные фразы
отмечены как неоценённые в docs/testing/audio-review.md).

Запись включена только в RU ZIP под content/ru/0.4.0/retry.mp3 и привязана к
тексту feedback.retry. Длительность 2.064 секунды, 16512 байт, совпадает с исходником.
После ошибки в обоих режимах wrapper воспроизводит файл через стандартный
playTopicFile/IndexedDB; флаг звука соблюдается. Путь закреплён в задаче из её пакета.
SL не содержит аудио и не получает русский fallback. audioScope=feedback
передаётся в каталог/локальное описание и явно подписан в модалке: озвучена
подсказка после ошибки, а не все учебные инструкции.

Проверено: 2283 frontend-теста, 41 focused pilot/delivery, strict lint, UI-словарь,
source/core/packs validator, production build. Chromium: четыре UI/content пары,
реальные Audio playing/ended события и декодирование MP3 онлайн и офлайн после
перезагрузки; в SL нет речевого playback. Проверены установка только выбранного
пакета, добавление другого без скачивания core, повторный выбор из кеша,
закреплённый язык начатого занятия, отсутствие page errors/переполнения.
Все шесть PR/main CI jobs, включая backend и production container startup, прошли.

Railway подтвердил точную версию/коммит, здоровье БД; core/RU/SL совпали побайтно,
русский ZIP содержит ту же MP3-запись, SL без аудио. Публичный каталог и ZIP
оригинального comparison остались неизменны. Схема БД не менялась.

Для проверки обновить приложение и импортировать
https://app.mironium.com/decks/comparison_language_pilot_v0.4.0.zip через «Темы → + ZIP».
Выбрать русский, начать один из двух режимов и дать неверный ответ. Повторить
без сети; при выборе словенского русская фраза звучать не должна. Копия скрыта
в общем каталоге, настройки и история сохраняются.
