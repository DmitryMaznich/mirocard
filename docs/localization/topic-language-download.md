# Выбор языка при скачивании темы

Реализовано в пилоте `comparison_language_pilot` 0.3, приложение 1.0.2674.
Оригинал `comparison` 2.37.0 и остальные темы не меняются.

## Поведение

При скачивании или обновлении темы открывается одно окно: Русский / Slovenščina,
количество готовых режимов, наличие речи и размер. По умолчанию предлагается
сохранённый язык темы ученика, затем предпочтение ученика/аккаунта. Изменить выбор
можно в меню темы или на её главном экране. В параметрах отдельных режимов
переключателя языка больше нет. Все четыре сочетания UI/материала RU/SL допустимы.

Файлы общие для устройства, выбор — для ученика и темы. Уже скачанный пакет
можно выбрать без сети. Добавление другого языка скачивает только недостающий пакет.
Удаление темы удаляет все её локальные языковые файлы. Отдельное управление
удалением одного языка пока не добавлено. Фоновые обновления разделённых тем
пропускаются: обновление выполняется явно с выбором пакета.

Начатое занятие закрепляет язык/ID/версию пакета. Изменение выбора темы не
переписывает занятие, историю и параметры остальных режимов. При переходе с 0.2
однозначный старый выбор сохраняется; разные языки в старых настройках режимов
требуют единого явного выбора для темы. Файлы оригинала и его история не затрагиваются.

## Архивы

`languageContract.delivery` задаёт URL общей основы. `packages.<language>.download`
задаёт URL, байты и SHA-256 языкового архива. Каталог содержит `languageDownload`
с описанием основы и всех частей, доступных режимов и наличия записанной речи.

Общий ZIP: topic.json, renderer/CSS, нейтральная графика, небольшие UI-словари RU/SL.
Языковой ZIP: JSON учебного материала и объявленные в нём `assets`:
`{path, kind: audio|image, bytes, sha256}`. Языковые медиа лежат под
`content/<language>/<packageVersion>/`. Содержимое пакета, идентичность, допустимые
пути, размер и хеш проверяются до установки. В версии 0.4 русский пакет содержит речевую подсказку после ошибки, словенский без речи.

Оригинальный сжатый core не дублируется в IndexedDB: сохраняются распакованные
файлы и контрольный список. Для добавления языка основа восстанавливается из них
с проверкой хешей. Все подготовленные файлы и метаданные заменяются одной
транзакцией в существующих stores. Неудачная транзакция откатывается полностью.
Схема базы не меняется. HTTP/service-worker кеш имеет обычную для тем политику.

## Доступ и совместимость

Бесплатные архивы доступны напрямую. Каждый платный файл проходит тот же API
и проверку подписки/владения, что и тема: `?part=core` или `?part=language&language=sl`.
URL частей платных/недоступных тем удаляются из ответа каталога; их прямая
статическая выдача запрещена. После отказа API нет перехода на статический URL.
Ручной импорт бесплатной основы сначала открывает выбор и не изменяет установленную
тему до успешной загрузки пакета. Старые цельные ZIP продолжают импортироваться.
Старое приложение отклонит новый пилот по minAppVersion 1.0.2674.

## Проверки

- Валидатор сопоставляет исходники, core, каждый пакет и каталог по содержимому,
  размерам и SHA-256; язык не может добавить файлы другого пакета.
- Регрессии проверяют выбор до сетевых запросов, отмену, загрузку только одного
  языка, повторное использование основы/пакетов, индивидуальный выбор учеников,
  сохранение истории и занятия, повреждённые архивы, сбой IDB, смену аккаунта,
  платный API без статического fallback, языковые audio/image.
- Браузерная проверка: четыре пары UI/материала, узкий экран с iOS safe area,
  запуск/перезагрузка занятия, добавление языка и повторный выбор без сети.
- UI RU/SL имеет одинаковые ключи/переменные и формы количества, включая словенское
  двойственное число «2 načina». Ответственность за языковую вычитку у исполнителя.


Обновление 0.4 / приложение 1.0.2675: русский пакет содержит существующую запись
«Посмотри ещё раз» из `public/audio/addition-subtraction/phrases/look_again.mp3`.
Это озвучка подсказки после ошибки в обоих режимах, а не всех заданий. Исходный
банк и его записи не изменены. Файл включён только в RU ZIP под
`content/ru/0.4.0/retry.mp3`; SL остаётся без речи. Каталог и окно выбора явно
показывают частичный охват (`audioScope: feedback`). Генерация новых голосов
и браузерный TTS не используются. Исходная запись взята из действующего банка;
это не заявление о новой пользовательской приёмке её произношения.

Задача закрепляет путь записи из своего языкового пакета. После неверного ответа
renderer вызывает стандартное воспроизведение файла темы из IndexedDB; выключенный
звук запрещает речь. Смена UI/языка темы не подменяет запись начатой задачи.
Записи сопоставляются с текстовыми ключами через `recordings`, ссылки валидируются
на объявленные аудиоресурсы. Для проверки выбрать русский, начать любой из двух
режимов и дать неверный ответ; повторить без сети. При словенском должны остаться
только обычные сигналы ответа, русская фраза звучать не должна.
