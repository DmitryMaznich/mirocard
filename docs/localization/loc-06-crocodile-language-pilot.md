Режим `compare_sign` доступен на RU/SL. Все реплики ребёнку, подсказка крокодила и результат принадлежат выбранному пакету. UI и методика следуют UI-языку. После правильного ответа пасть раскрывается к большему числу, даже если искали меньшее. При равенстве нажимают на крокодила; повторное быстрое нажатие не удваивает ответ. SVG, CSS и renderer копируются в отдельный модуль; оригинальные файлы не изменены.

Режимы хранят параметры в `params.byMode`. Только первый режим явно читает старые общие параметры 0.1 при отсутствии собственного сохранения; копируются только объявленные ключи. Карточки заданы через `mode.cardIds`, поэтому занятия с крокодилом не повышают освоение первого режима. RU/SL одного режима остаются общим математическим навыком; пакеты фиксируются в истории. Импорт обновления очищает кэш renderer только обновлённой темы, чтобы новый режим появился сразу. Старый ZIP перенесён в `test-fixtures`, актуальный — 0.2.0.

Пользователь подтвердил работу пилота и поручил языковую вычитку исполнителю. Это уточняет прежнюю рекомендацию о носителе: внешняя вычитка не является условием продолжения. Перепроверены двойственное число, сравнительные формы, управление и смысл реплик; использованы статьи Fran/SSKJ². Подпись случайного микса исправлена с «по очереди / Izmenično» на «Смешанный режим / Mešano». [Материалы вычитки](pilot-sl-language-review.md).
