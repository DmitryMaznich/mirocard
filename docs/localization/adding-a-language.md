# Как добавить язык интерфейса

Решение владельца (2026-11-19): приложение многоязычное, словенский — первый
язык после русского, не единственный. Запасной язык для непереведённых строк —
английский, затем русский.

## Где что лежит

| Что | Где |
| --- | --- |
| Список языков: код, самоназвание, локаль, направление письма, статус, есть ли юридические документы | `shared/ui-languages.mjs` (`UI_LANGUAGE_REGISTRY`) — один на приложение и сервер |
| Строки интерфейса | `src/shared/i18n/*Messages.js` — словари `{ ru: {…}, sl: {…}, … }` |
| Названия тем, у которых в метаданных нет языка | `src/shared/i18n/topicTitles.js` (`TOPIC_TITLE_TRANSLATIONS`) |
| Подписи настроек старых тем (по русской фразе) | `src/shared/i18n/setupText.js` (`SETUP_LABEL_TRANSLATIONS`) |
| Короткие описания тем на плитках | `src/features/topics/topicShortDescriptions.js` |
| Названия и описания тем в каталоге | `public/decks/catalog.json`, поля `title`/`description` с любыми кодами языков |
| Условия, политика, возвраты | `backend/legal/<код>/` (русские — в корне `backend/legal/`), заголовки — `LEGAL_DOC_TITLES` в `backend/server.mjs`, тексты согласий при оплате — `CONSENT_TEXT` в `SubscriptionScreen.jsx`, политика внутри приложения — `PRIVACY_HTML` в `PrivacyContent.jsx` |

## Порядок

1. Строка в `UI_LANGUAGE_REGISTRY` со статусом `draft`. Язык сразу принимается
   сервером и аккаунтом, но в меню его нет (кроме устройства, где его уже выбрали).
   Даты, числа, формы множественного числа берутся из `locale`.
2. Словари: блок `<код>: {…}` в каждом `*Messages.js`. Формы множественного числа —
   по категориям `Intl.PluralRules(locale)` этого языка (`_one`, `_two`, `_few`,
   `_many`, `_other`), не по русским.
3. Названия и описания тем: `title.<код>` и `description.<код>` в каталоге, короткие
   описания, при необходимости `TOPIC_TITLE_TRANSLATIONS`.
4. Юридические документы — только если есть проверенный перевод: `backend/legal/<код>/`,
   `LEGAL_DOC_TITLES`, `CONSENT_TEXT`, `PRIVACY_HTML`, затем `legal: true`. Без этого
   условия и согласия показываются на запасном юридическом языке — никогда не машинный
   перевод юридического текста.
5. `npm test` — `src/shared/i18n/uiLanguages.test.js` для опубликованных языков
   требует все строки, те же `{{переменные}}` и все формы множественного числа.
6. Вычитка носителем, затем `status: "published"` — язык появляется в меню.

## Правила кода

- Код не называет языки: никаких `language === "sl"`. Локаль — `localeFor()`,
  выбор текста — `pickUiText()` / `translateUi()`, юридический язык — `legalLanguageFor()`.
- Интерфейс и учебный материал — разные языки (`authoring-language-rules.md`).
  Запасная цепочка (язык → английский → русский) только для текста интерфейса;
  учебный материал никогда не подменяется другим языком.
- В темах с языковым контрактом (`shared/topic-language-contract.mjs`) UI-ресурсы
  обязательны для всех опубликованных языков.

## Чего ещё нет (шаг 2 и дальше)

- Английский словарь — полный черновик (2026-11-19): все строки словарей, тест
  `uiLanguages.test.js` требует его полноты, потому что он запасной для всех языков.
  Статус `draft` — до вычитки носителем; в меню его нет, но выбранный (тестовое
  устройство, аккаунт) он работает целиком на переведённых экранах. Две строки нарочно
  цитируют русский учебный материал (`QUOTES_RUSSIAN_MATERIAL` в тесте).
- Около 310 файлов вне словарей содержат кириллицу. Часть — учебный материал (законно),
  часть — непереведённые подписи интерфейса; их надо вынести в словари.
- Письмо справа налево: `dir` из реестра ставится на `<html>`, но вёрстка под RTL не проверялась.
