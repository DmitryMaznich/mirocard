## 1. Цель

Сейчас перед печатью можно выбрать одну из трёх готовых обложек: «Школьная», «Пропись», «С образцом». Вместо них нужен **один универсальный шаблон обложки**: пользователь собирает обложку из опций (оформление названия, декоративный элемент, поля, цвет) и выбирает **задник** — содержимое задней стороны обложки. Задник тоже универсальный: алфавит, цифры, знаки и т. п., нарисованные нашими же прописями.

## 3. Модель настроек обложки

Одна конфигурация на тетрадь (`CoverConfig`). Предлагаемая схема (можно уточнить, но держать плоской и сериализуемой):

```js
{
  enabled: true,                 // «Без обложки» = false
  title: { text: null,           // null = название тетради; своя строка — если пользователь поменял
           style: "print" | "cursive",   // печатный заголовок / прописью на косой линейке (как «Пропись» сейчас)
           kicker: true },        // строка «ТЕТРАДЬ» над названием
  decor: "none" | "frame" | "corners" | "ruling-band" | "elements-band" | "sample-window",
  fields: ["name", "surname", "started"],  // набор из: name, surname, class, school, started, finished
  accent: "teal" | "blue" | "red" | "green" | "gray",   // цвет акцентов; печать ч/б должна читаться
  logo: true,
  back: { kind: "none" | "alphabet" | "digits" | "signs" | "digits-signs" | "punctuation",
          paper: "copybook" | "square" }   // бумага задника (у цифр по умолчанию клетка)
}
```

- **Три нынешних дизайна — пресеты этого шаблона.** «Школьная» = print + kicker + fields name/surname/started. «Пропись» = cursive + fields name/surname. «С образцом» = print + `sample-window`. Старые значения `cover: "school" | "propis" | "sample" | "none"` из `localStorage` перевести в `CoverConfig` (миграция при чтении).
- **Где хранить.** Решение владельца нужно (см. п. 9). Рекомендация: в самой тетради (`set.cover`) — тогда настройка синхронизируется между устройствами и копируется вместе с тетрадью. Это поле документа тетради, учесть в `syncLib.js` (валидатор `VALID.set` уже пропускает лишние поля) и в `mergeNotebook`. Сейчас — `localStorage`.

## 4. Декоративные элементы (`decor`)

Все — векторные (SVG внутри обложки, размеры в долях ширины обложки), печатаются в цвете `accent`. Набор первой версии:

1. `none` — ничего.
2. `frame` — тонкая рамка по краю листа с внутренним отступом (двойная линия).
3. `corners` — орнаментальные уголки (4 угла).
4. `ruling-band` — полоса косой линейки прописей поперёк обложки (как полоса с названием у «Прописи»), без текста или под названием.
5. `elements-band` — строка элементов прописей (крючки, петли — `tools/propis/elements.json`) по низу или верху обложки, нарисованная движком через `buildPageTask`. В строке задания — id элементов, как их хранят строки страниц (в поле ввода они видны как `{э1}`, перевод — `fieldText.js` `bracesOut`).
6. `sample-window` — окошко с первыми строками тетради (как сейчас «С образцом», `PrintPageTop` по заданию первого участка).

Не использовать растровые картинки и внешние шрифты (печать и офлайн). Шрифт — Nunito (уже в приложении).

## 5. Задник (`back`)

Задник — задняя сторона обложки. Где он печатается:
- **А5:** на левой половине первого листа (сейчас она пустая). Оборот обложки (лист 2) остаётся пустым — решение владельца «оборот пустой» от 2026-10-08 относится к нему.
- **А4:** отдельным листом. Где — открытый вопрос (п. 9): последним листом (настоящая задняя обложка) или сразу после обложки.

Содержимое рисуется **нашими прописями через движок** (`buildPageTask` + `PrintPageTop` или новая обёртка, показывающая всю страницу задания), а не шрифтом:

| `kind` | Содержимое | Бумага по умолчанию |
|---|---|---|
| `alphabet` | Пары «Аа Бб … Яя» прописью; у Ё Й Ы Ь Ъ — только строчная (см. п. 2). Заголовок «Алфавит». | прописи, узкая строка |
| `digits` | 0 1 2 … 9 крупно; ниже числа 1–20 (или таблица 1–10 / 11–20). Заголовок «Цифры». | клетка |
| `signs` | + − = < > с подписями «плюс», «минус», «равно», «больше», «меньше» (подписи печатным шрифтом). | клетка |
| `digits-signs` | цифры 0–9 и строка знаков + − = < >, пример «2 + 3 = 5». | клетка |
| `punctuation` | . , ? ! с подписями («точка», «запятая», «вопросительный знак», «восклицательный знак»). | прописи |
| `none` | пусто | — |

- Всё должно уместиться на одной странице формата тетради. Подобрать размер строк: на А5 узкая строка — 17 строк, клетка — 20 строк (`rowsPerPage`).
- Задник один на тетрадь. Не зависит от бумаги страниц тетради.

## 6. Окно печати (UX)

- Окно остаётся одно (`Propis2PrintDialog`), из двух частей:
  1. **Обложка.** Сверху большое живое превью: лицевая сторона и задник рядом (на телефоне — переключатель «Лицо / Задник»). Ниже опции компактными пикерами в стиле редактора (`Propis2Picker`, иконка + подпись): «Название» (печатное / прописью), «Украшение», «Поля», «Цвет», «Задник», «Логотип». Сверху ряд быстрых пресетов: «Без обложки», «Школьная», «Пропись», «С образцом».
  2. **Номера страниц** — как сейчас.
- Название тетради можно поправить прямо на обложке (поле «Название на обложке», пусто = название тетради).
- Окно не должно вылезать за экран: прокрутка внутри карточки (`.p2-print-card` уже с `max-height` и safe area). Проверить на 390×844 и 820×1180.
- Выбор сохраняется (см. п. 3), «Отмена» ничего не меняет.

## 7. Технические требования

- Новый компонент `src/features/propis2/cover/CoverTemplate.jsx` (чистый: рисует по `CoverConfig` + данным тетради), рядом `coverConfig.js` (схема, значения по умолчанию, пресеты, миграция старых значений, валидация) и `CoverBack.jsx` (задник). `Propis2Cover.jsx` либо заменить, либо оставить тонкой обёрткой над пресетами.
- Размеры — `cqw`, как в нынешней обложке. Превью и печать — один компонент.
- Всё, что пишется прописью, — через движок, с кэшированием заданий (`useMemo` по тексту и бумаге). Окно не должно заметно тормозить при смене опций: задание задника строится только при смене `back`.
- Печать (`PrintPageView`): нужен второй слот — `printBack` (узел задника). Для А5 он идёт в левую половину листа обложки, для А4 — туда, куда решит владелец (п. 9).
- Номера страниц и сквозная нумерация уже есть — не сломать (тест в `Propis2Home.smoke.test.jsx`, блок печати).
- Без растров и сетевых ресурсов.

## 8. Приёмка

1. **Тесты.** Модульные — `coverConfig.js`: пресеты, миграция старых `cover`, валидация. В smoke-тесте окна печати проверить: смена опций меняет превью, «Печать» кладёт на листы (`.propis-print-all`) обложку и задник выбранного вида, выбор запоминается. Должен проходить весь набор `npx vitest run src/topics/renderers/propis2 src/features/propis2 src/topics/renderers/propis`.
2. **Печать в PDF через Playwright.** Как в этой сессии: открыть «Прописи — цифры» → 🖨 → выбрать опции → `page.emulateMedia({ media: "print" })` + `page.pdf({ preferCSSPageSize: true, printBackground: true })`. Перед кликом подменить `window.print`. В PDF проверить:
   - лист 1: задник слева, обложка справа (А5);
   - лист 2: пустой;
   - дальше страницы с номерами.
   Повторить для А4.
3. **Скриншоты владельцу** до выкладки: окно на телефоне и планшете, 3–4 разных набора опций, каждый задник.
4. **Документация.** Раздел в `docs/propis2.md`: что сделано, решения владельца, где что лежит.
