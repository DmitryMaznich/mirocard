# «Портрет по кубику» (drawing_portrait)

Режим темы «Рисование» с пакета 0.32.0 (приложение 1.1.98); стили и показ прорисовки — с 0.33.0. Основа — макет, сделанный с Codex:
`docs/mockups/drawing-portrait-dice/portrait-prototype.html`. Контуры лица и частей перенесены из него
без изменений (`src/topics/renderers/drawing/portrait/parts.js`, сгенерирован из кода макета).

## Стили (выбирает взрослый, параметр `style`)

- **«Простое лицо»** (`simple`, по умолчанию) — первая ступень. Пять шагов: глаза, нос, рот, уши, волосы.
  Все варианты собраны только из точки, круга, прямой и дуги (движения «Первых линий»); глаза и уши —
  пара за один шаг. Формы лица: круглое, овальное, квадратное (суперэллипсы); части строятся от выбранного
  контура (`styles.js`, `simpleSteps`), волосы расставлены по длине контура, а не по углу.
- **«Пикассо»** (`picasso`) — исходный макет: семь шагов, несимметричные части. Давать, когда ребёнок уже
  уверенно рисует обычное лицо (гибкость: лицо можно нарисовать по-разному), не первым.
- Запланирован третий стиль «Разные лица» (`docs/mockups/drawing-portrait-dice/normal-style.html`): разрез
  глаз, формы носа и губ, типы волос. Эмоций в режиме нет (решение владельца 2026-11-15), брови — нейтральные.

Сохранённый портрет другого стиля при смене настройки начинается заново; сохранения до стилей
(версия 1) читаются как «Пикассо».

## Показ прорисовки

Выбранный вариант прорисовывается на лице подпуть за подпутём, как карандашом (зелёная точка — кончик),
с паузой-«отрывом» между линиями, точки и зрачки появляются в конце (`drawPath.js`). Время по длине
линий, 0,9–2,2 с. ▶ на лице показывает ещё раз. Префикс строится настоящей ломаной по точкам пути, не
`stroke-dashoffset` (см. «Первые линии», §18). При `prefers-reduced-motion` часть показывается сразу.

## Ход занятия

1. «Какое лицо?» — три контура: угловатое, овальное, фантазийное.
2. Шаги стиля. На шаге —
   шесть вариантов части с точками кубика и лицо с уже нарисованными частями; место новой части
   показано пунктиром. Выбранный вариант прорисовывается на лице зелёным; ребёнок рисует его на бумаге
   и нажимает круглую зелёную стрелку.
3. «Портрет готов» — ↻ новый портрет, ⌂ закончить.

Кубик — параметр режима `dice`: «Настоящий» (по умолчанию; ребёнок бросает кубик на столе и сам
нажимает вариант с тем же числом точек — задача на соотнесение) или «На экране» (нажатие на кубик,
вариант выбирается сам, варианты не нажимаются).

Меню взрослого — удерживать шестерёнку: распечатать контур лица (выбранной формы), распечатать
готовый портрет, вернуться на шаг, начать новый портрет, закончить занятие. Печать — через скрытый
iframe (всплывающее окно в установленном приложении часто заблокировано).

Режим не оценивается: `evaluation: "none"`, без звёзд и видеоприза. Одно задание на занятие
(`engine.js`, карточка `first_lines:short_line`). Прогресс хранится на устройстве
(`drawing-portrait:v1:<ученик>`), перезагрузка продолжает тот же портрет.

## Что можно улучшить

- Варианты частей — из макета, без проверки логопедом/дефектологом; часть вариантов сложна для
  рисования от руки (ухо спиралью, кудри).
- Нет озвучки шагов.
- Портрет не сохраняется в аккаунт и не синхронизируется между устройствами.
