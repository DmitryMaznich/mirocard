# propis2_kk — казахские прописи (вариант темы propis2)

Начато 2026-10-29 по образцу болгарского (`docs/propis2-variants.md`, `docs/propis2-bg-handoff.md`). Вариант без форка кода: тема-ZIP с тем же рендерером,
данные в `tools/propis2/variants/kk/`. **В `main` не вливалось и не деплоилось; ZIP не собирался, в каталог не добавлялся** (владелец: сначала подтверждение).
Ветка `ccr-e185e8ca-wt6rcg`.

## Что есть
- **Алфавит 42 буквы** (`variant.json` → `meta.alphabet`): русские 33 + Ә Ғ Қ Ң Ө Ұ Ү Һ І. Заглавных нет у Ъ Ы Ь (нет в банке) и пока у Һ.
- **Образец** — казахская пропись для 1 класса (Турганбекова А. С., шрифт Propisi-Light, векторный PDF; **в репозиторий не кладём**, лицензия шрифта неизвестна) и плакат
  алфавита. В PDF нет заглавной Һ и Ң, а строчная һ набрана латинской h (в таблице шрифта пустые глифы Һ и һ).
- **Глифы** собирает `build_glyphs.py` из штрихов русского банка по рецептам владельца (`--write-variant` кладёт их в `variant.json`).
  Готовы: Ғ ғ Ө ө Ү Ұ ү ұ Қ қ Ң ң Ә ә І і һ. Не готова: **заглавная Һ**. У и У берутся из русского банка без правок.
  Рецепты (штрихи в нумерации каталога `tools/propis2/variants/kk/…`, картинка — `preview.sh`): перекладины Ғ/ғ Ө/ө Ұ/ұ короткие и прямые (размеры владельца);
  Қ Ң = К Н с хвостом Ц; Ә = Э до низа + пузо с горизонтальным замыканием; ә = «е» первой версии прописей, повёрнутая на 180° и сглаженная (`smooth_path_d`);
  І = флажок К + стойка У, соединение как у У (служебный глиф `ч_iend`); і = стойка и + точка как у ё; һ = h из PDF (`pdf_glyphs/`, контур → скелет → ход пера,
  стойка строго по наклонной, дальше п).
- **Соединения** (общие для всех строчных; включаются `meta.script`, без флагов тема идёт прежним путём, русская и болгарская побайтно те же):
  - `topJoins` — выход, который часть штриха буквы (п р и н т к ш һ…), вогнутой кривой идёт к верхней точке следующей буквы, входя вдоль её стойки. Расстояние прежнее.
    Куски одной составной буквы (ш, ы, ии) не затрагиваются. Л и м как в русской теме.
  - `growJoins` — для выхода, который отдельный штрих (ә, о…): доращивание до начала следующей буквы.
  - `joinAtStart` у ә: предыдущая буква подстраивает выход под её начало. Тесты: `growJoins.test.js`, `variantKk.test.js`.
- **Надписи обложки** (`coverWords`) — черновик по-казахски, **нужна проверка носителем**; цена пустая.
