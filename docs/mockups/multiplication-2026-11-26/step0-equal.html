Поровну?

Ступень 0 «Поровну?»

Уровень — приложение ведёт само по правилу ниже; кнопками можно переключить для просмотра:
Решения методиста
  • R — подсказка внутри задания. В первых заданиях яблоки уже стоят рядами один к одному под тарелками: сравнивать легко, ошибиться почти нельзя. Кнопки «разложить» нет — ребёнок с РАС быстро начинает жать её всегда.
  • Проверка рядами: после каждого ответа, пока уровень A не освоен; дальше — только после ошибки.
  • Ошибка: ряды показываются, ответ повторяется на том же задании, следующее задание — на уровень проще.
  • Переход: вверх — 8 верных из последних 10 без ошибки на первом нажатии; вниз — 2 ошибки подряд.
  • Только две тарелки. Три и больше — на ступени 1 «Сделай поровну»: с тремя тарелками «≠» превращается в «найди не такую», это другой навык.
  • D обязателен, и разброс свой на каждой тарелке: «поровну» с разными узорами, «не поровну» с похожими. Иначе ребёнок сравнивает узор, а не количество.
  • Ответы «=» и «≠» — примерно поровну, не больше двух одинаковых подряд.
