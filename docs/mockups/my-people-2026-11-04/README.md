Это согласовательные HTML-макеты. Основные экраны уже записаны в HTML и видны без JavaScript. При разрешённых скриптах кнопка в шапке позволяет пройти сценарий. Кнопки на статических экранах показывают состояния; прохождение запускается отдельно.

Для локального просмотра скачайте каталог вместе с `assets`. В GitHub HTML может показываться как исходный текст. При необходимости открыть через простой локальный HTTP-сервер. Интернет для изображений и шрифтов не требуется. Озвучка в интерактивном примере использует возможности браузера и не является принятой окончательной озвучкой приложения.

Файлы сохранены из последних показанных владельцу версий 06 и 07. Встроенные изображения и шрифты вынесены в общий `assets`; поведение и стили сохранены. Это не готовые исходники React, не производственная модель данных и не материал для реального ученика.

## Проверка прототипов

Проверены в браузере: все поля 2/3/4/6 для обеих целей, сохранение параметров по комбинации, блокировка недостаточного поля, имя и роль отдельно, старт по подготовленному плану, неподтверждённые изменения, неоцениваемое знакомство, полный самостоятельный путь, компактная панель, сводка, следующий план и повторный запуск. Отдельно проверены питомцы в именах, отсутствие детской оценки речи при самостоятельной практике, узкие экраны и наличие всех девяти статических экранов при отключённом JavaScript.

Проверка макетов не заменяет тесты будущей реализации приложения. Размеры, тайминги, демо-ID и простые функции склонения в JavaScript не являются production-контрактом; требования к реализации описаны в плане.
