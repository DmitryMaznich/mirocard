# «Портрет по кубику» — прототип (макет)

Собранный однофайловый макет, сделанный с Codex (ноябрь 2026). Исходников нет — только этот HTML,
в репозиторий и пулреквесты он раньше не попадал. Открывается в браузере без сервера.

Ход: выбор формы лица (угловатое / овальное / фантазийное) → 7 шагов: левый глаз, правый глаз,
нос, рот, левое ухо, правое ухо, причёска. На каждом шаге бросают кубик и берут вариант с выпавшим
числом (по 6 вариантов на часть, место части показано пунктиром на контуре лица) → «Сравни портреты»:
готовое лицо, «Раскрась свой портрет», «Ещё раз». Есть кнопка «Печать».

С пакета «Рисования» 0.32.0 это режим `drawing_portrait` — см. `docs/drawing-portrait.md`.
