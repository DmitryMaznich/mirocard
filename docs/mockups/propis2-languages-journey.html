«Прописи»: путь пользователя по языкам

Одна тема «Прописи» со всеми языками и стилями (кириллица и латиница вместе, «Прописи: латиница» уходит в архив). Человек видит только свои языки — список «Мои языки» у аккаунта, не у ученика. Язык — у тетради (выбирается при создании и не меняется), стиль — у страницы и строки. Интерфейс темы — на языке интерфейса приложения (сценарий 3).

Тот же путь, но «Мои языки» по умолчанию = Slovenščina (язык интерфейса). Весь интерфейс темы — по-словенски; русских тетрадей и кириллицы человек не видит, пока сам не отметит.

Группа своего письма — первой. Названия языков всегда на них самих.

Что за этим стоит (не видно пользователю)

1) «Мои языки» — список у аккаунта (синхронизируется между устройствами), по умолчанию: язык интерфейса + языки существующих тетрадей + English, если была установлена «Прописи: латиница».
2) Слияние тем: колода «Прописи» собирается со всеми языками; «Прописи: латиница» → архив; ученикам, у которых она была, тема «Прописи» привязывается сама, с English в «моих». Тетради уже общие — переносить нечего.
3) Черновые языки (словенский сейчас) — только админу; признак админа в клиенте нужно добавить.
