# Обложка-алфавит для тетрадей прописей

## Проблема

Тема «Печатные материалы» (`print_materials`) предлагает 3 тетради (стандарт/плотная/точки), у каждой обложка с одним и тем же стихом на обороте. Нужна дополнительная версия обложки, где вместо стиха — алфавит (33 заглавных + 33 строчных буквы) на тех же линиях прописей.

## Решение

### A. Содержимое и вёрстка (`scripts/cover_tetrad.py`)

- Новая функция `left_page_alphabet(cv)` рядом с существующей `left_page(cv)` — та же сетка прописей (6 строк, ClassRoomCursive, цвета из `left_page`).
- Строка 0: заголовок «Алфавит» (зелёный, как «Любимая мама»).
- Строки 1–5: 33 пары «Аа Бб Вв...» вразрядку, распределены 7/7/7/6/6 по строкам, по центру. Размер шрифта подбирается автоматически через `pdfmetrics.stringWidth`, чтобы самая длинная строка влезла в ширину страницы; потолок — 40pt (как у стиха).
- Логотип/копирайт — без изменений. Подписи автора нет (все 6 строк заняты).
- Правая страница (бланк «ТЕТРАДЬ» + миниатюра) общая для обоих вариантов — не меняется.
- Выбор варианта — новый CLI-флаг `--variant=poem|alphabet` (default `poem`, старое поведение не ломается). Имя выходного файла: `cover_{style}.pdf` для poem (как сейчас), `cover_{style}_alphabet.pdf` для alphabet.

### B. Пайплайн генерации

- `make_notebook.py` → `build()`: для каждого стиля дополнительно вызывает `cover_tetrad.py --style=X --variant=alphabet`, копирует результат в `output/{name}_cover_alphabet.pdf`.
- `make_print_zip.py` → `copy_pdfs()`: добавляет 3 новых записи в mapping → `print/cover_алфавит_{style}.pdf`.

### C. Каталог темы (`src/print_materials/topic.json`)

- У каждого из 3 items текущий файл «Обложка» переименовывается в «Обложка (стих)».
- Добавляется новый файл «Обложка (алфавит)» с тем же hint-текстом, path `print/cover_алфавит_{style}.pdf`, filename `тетрадь_обложка_алфавит.pdf`.
- Версия темы бампается (patch) вместе с пересборкой ZIP.
- Превью-миниатюра карточки не меняется (берётся с первого PDF, как и сейчас).

## Не в скоупе

- Изменение миниатюры карточки под алфавитный вариант.
- Новая отдельная карточка тетради в каталоге (по решению пользователя — это доп. файл к существующим тетрадям, не новая карточка).
- Автотесты PDF-вёрстки (в проекте их нет и для существующих обложек — проверка глазами).

## Тестирование

Ручная генерация (`python scripts/cover_tetrad.py --style=плотная --variant=alphabet`) + визуальная проверка PDF на предмет того, что шрифт не вылезает за поля и пары букв ровно стоят на линиях.
