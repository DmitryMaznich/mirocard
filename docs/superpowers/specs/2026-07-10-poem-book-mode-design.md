# Режим «Педагогические стихи» — книга-листалка из 8 карточек

Дата: 2026-07-10

## Контекст

Тема `reading_dad_poems` («Чтение: Стихи», renderer `reading`) сейчас содержит 4 стиха
(`dad_best`, `mom_love`, `family_poem`, `sister_love`). Каждый стих — объект в `texts[]`
манифеста темы (`kind: "poem"`, поля `title`, `image`, `lines[]`, опционально `questions[]`).
Существующий режим `read_text` (layout `full`) показывает один стих целиком на экране:
заголовок + текст + иллюстрация; тап по экрану переводит к следующей задаче сессии.

Нужно добавить новый режим с набором из 8 новых стихов (про черты характера — непослушный,
трудолюбивая, грязнуля, жадина, трус, смелый, капризуля, ленивый), которые пользователь
листает как книгу: вперёд и назад, отдельными «страницами», где каждая страница выглядит
и ведёт себя как уже существующий полноэкранный показ одного стиха.

Иллюстрации для всех 8 стихов уже готовы: `Teaching poems/*.png` в корне проекта, 1254×1254px,
подписаны словом-чертой характера (`neposlushni.png`, `Trudoljubiv.png`, `Grjaznulja.png`,
`Zhadina.png`, `Trus.png`, `Smelij.png`, `kaprizulja.png`, `Lenivij.png`).

## Точка входа

Новая «книга» появляется как ещё один пункт в общем списке стихов темы (`TextPickerScreen`),
рядом с 4 существующими стихами — со своей карточкой-обложкой (иллюстрация первой страницы,
`neposlushni.webp`) и подписью «Педагогические стихи».

Тап по этой карточке, как и для типов `instruction`/`shopping_list`/`safe_code`, сразу
выставляет активный режим и уходит на экран сессии — минуя обычный экран выбора режима
(`modes`), так как для книги есть ровно один сценарий использования.

## Модель данных

Новый элемент `texts[]` в манифесте `reading_dad_poems` (`scripts/generate-reading-demo.mjs`):

```js
{
  id: "character_traits_book",
  kind: "poem_book",
  title: { ru: "Педагогические стихи" },
  image: "media/neposlushni.webp",
  level: 1,
  pages: [
    { id: "vanya",  kind: "poem", title: { ru: "Ваня-непослушный" },  image: "media/neposlushni.webp",  lines: [...] },
    { id: "lena",   kind: "poem", title: { ru: "Лена-трудолюбивая" }, image: "media/trudoljubiv.webp",  lines: [...] },
    { id: "danya",  kind: "poem", title: { ru: "Даня-грязнуля" },     image: "media/grjaznulja.webp",   lines: [...] },
    { id: "katya",  kind: "poem", title: { ru: "Катя-жадина" },       image: "media/zhadina.webp",      lines: [...] },
    { id: "andrey", kind: "poem", title: { ru: "Андрей-трус" },       image: "media/trus.webp",         lines: [...] },
    { id: "sasha",  kind: "poem", title: { ru: "Саша-смелый" },       image: "media/smelij.webp",       lines: [...] },
    { id: "yulya",  kind: "poem", title: { ru: "Юля-капризуля" },     image: "media/kaprizulja.webp",   lines: [...] },
    { id: "nikita", kind: "poem", title: { ru: "Никита-ленивый" },    image: "media/lenivij.webp",      lines: [...] },
  ],
}
```

Порядок страниц — как прислано пользователем (Ваня → Лена → Даня → Катя → Андрей → Саша →
Юля → Никита). Каждая страница получает `kind: "poem"`, чтобы переиспользуемый компонент
иллюстрации применял к ней те же скруглённые «книжные» уголки, что и к обычным стихам.
Вопросов на понимание (`questions[]`) и автора для этих текстов нет — только чтение.

Тексты 8 стихов (с разбивкой на строки `lines[]`, как в существующих стихах):

1. **Ваня-непослушный** — «Ваня очень непослушный- / Папу с мамой он не слушал! / Не получит
   он за это, / Ни качелей, ни планшета!»
2. **Лена-трудолюбивая** — «Лена очень любит труд / Помогает там и тут! / Убирает и стирает, /
   Пыль все время вытирает! / Все в восторге! Что за диво! / Как она трудолюбива!»
3. **Даня-грязнуля** — «Даня мыться не любил! / Тело очень редко мыл! / Мама с папой лишь
   вздохнули! / Даню все зовут грязнулей! / С ним никто дружить не хочет, / Так как он
   вонючий очень!»
4. **Катя-жадина** — «Кате сложно поделиться / И игрушками, и пиццей! / И сидит в углу одна- /
   Так как жадная она!»
5. **Андрей-трус** — «Наш Андрей всего боится / Грома, пауков и птицу, / И комарика укус… /
   Наш Андрюша просто трус.»
6. **Саша-смелый** — «Ну а Саша смелый очень- / Не боится даже ночью! / Защищает слабых он! /
   Саша просто чемпион!!!»
7. **Юля-капризуля** — «Наша Юля-капризуля! / Ноет, плачет и ревёт… / И поэтому никто ей /
   Ничего и не даёт!»
8. **Никита-ленивый** — «Никита сутки напролёт / С кровати мягкой не встаёт. / Маме он не
   помогает, / Умных книжек не читает, / Чтоб вы знали, между прочим, / Быть ленивым плохо
   очень!»

(Мелкие опечатки/лишние пробелы из исходного текста при переносе в `lines[]` нормализуются;
формулировки и порядок строк не меняются.)

## Иллюстрации

8 PNG из `Teaching poems/` конвертируются в webp внутри `scripts/generate-reading-demo.mjs`
через `sharp` — по образцу уже существующей конвертации фото сестёр (`buildSisterPhoto`).
Отдельного шага ручной подготовки ассетов не требуется; исходники остаются в
`Teaching poems/` и не коммитятся как часть колоды (коммитится только собранный zip).

## Режим `read_poem_book`

Новый тип задачи. В отличие от остальных режимов темы, где каждая страница/строка — это
отдельная задача сессии, вся книга — **одна задача** с внутренним состоянием текущей
страницы (`pageIndex`), по образцу уже существующей построчной навигации `layout: "line"`
в `ReadTextTask`.

Каждая страница рендерится идентично полноэкранному показу обычного стиха: переиспользуются
`ReadingTextBlock`, `ReadingIllustration`, `useFitReadingText` (автоподгонка шрифта под
экран без скролла) и `ReadingCloseButton` (крестик, виден на любой странице).

Навигация между страницами — кнопки, не свайп: `Назад` / счётчик `N / 8` / `Дальше`, на
последней странице `Дальше` меняется на `Готово` и завершает сессию (`onAdvance`). Это
переиспользует существующие CSS-классы `reading-line-nav`, `reading-secondary-btn`,
`reading-primary-btn`, `reading-line-count` — новых стилей не требуется.

### Изменения по файлам

- **`scripts/generate-reading-demo.mjs`** — конвертация 8 PNG → webp, новый объект в
  `texts[]`, запись `{ id: "read_poem_book", requirePin: false }` в `manifest.modes`,
  бамп версии `1.0.20` → `1.0.21`, выходной файл
  `public/decks/reading_dad_poems_v1.0.21.zip`.
- **`public/decks/catalog.json`** — новая версия и `url` для `reading_dad_poems` (старая
  запись не перезаписывается, правило действующего версионирования тем).
- **`src/topics/topicLoader.js`** — регистрация мода `read_poem_book` в
  `DEFAULT_MODES.reading` (id/type/evaluation/ui, иконка переиспользуется —
  `media/icons/reading_read.svg`, как у `follow_instruction`); опционально короткая запись
  в реестре описаний режимов для темы `reading`.
- **`src/topics/renderers/reading/engine.js`** — кейс `read_poem_book` в `generateTasks()`:
  для текста с `kind === "poem_book"` возвращает один task
  `{ type: "read_poem_book", textId: text.id, text }`.
- **`src/topics/renderers/reading/index.jsx`** — новый компонент `ReadPoemBookTask`
  (структурная копия `layout: "line"`-ветки `ReadTextTask`, но по страницам вместо строк),
  регистрация `read_poem_book: ReadPoemBookTask` в `TASK_RENDERERS`.
- **`src/features/reading/TextPickerScreen.jsx`** — в `pickText()` добавляется ветка
  `kind === "poem_book"` (выставляет `activeModeId("read_poem_book")`, уходит на
  `screen("home")`, минуя `modes`); в метаданных списка для этого `kind` показывается
  «8 стихов» вместо «N строк · уровень M».

## Что не входит в эту работу

- Свайп-жесты между страницами (можно добавить позже как альтернативный ввод — сейчас
  выбраны кнопки как более надёжный и быстрый в реализации вариант).
- Вопросы на понимание для новых 8 стихов.
- Изменения в существующих 4 стихах темы.

## Тестирование

- Ручная проверка в браузере: открыть тему «Чтение: Стихи», найти карточку «Педагогические
  стихи», пройти книгу от первой до последней страницы кнопками `Назад`/`Дальше`, проверить
  счётчик, проверить закрытие крестиком на разных страницах, проверить автоподгонку шрифта
  на маленьком экране (текст не должен обрезаться/скроллиться, если помещается).
- Проверка iOS safe-area не требуется отдельно — компонент переиспользует уже существующий
  `ReadingCloseButton`, который эту область уже учитывает.
