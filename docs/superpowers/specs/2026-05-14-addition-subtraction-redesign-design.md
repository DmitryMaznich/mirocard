# Дизайн: Ревизия темы «Плюс и минус»

**Дата:** 2026-05-14  
**Статус:** Согласован  
**Контекст:** Тема `addition_subtraction`. Цель — полная педагогическая лестница от конкретного действия с фишками до решения многошаговых цепочек. Целевая аудитория — дети с РАС, специалист настраивает уровень сложности.

---

## Педагогические принципы

- **CRA + РАС**: конкретное (фишки) → репрезентативное (знак↔слово) → абстрактное (выражение, цепочка)
- **Рецептивное раньше экспрессивного**: понять знак → применить знак
- **Без опоры на единственный инструмент**: палка — инструмент режима 3, а не образ всей темы
- **Хелпер вместо костыля**: в режимах 5–7 счётный инструмент доступен по кнопке, но не даёт ответ сам
- **Язык инструкций**: ≤ 3 слова, глагол первым, без абстрактных слов типа «ответ»
- **Непредсказуемость против автоматизма**: режим 4 чередует направления, чтобы ребёнок не жал машинально

---

## Структура лестницы

| # | ID | Название | Статус реализации |
|---|----|-----------|--------------------|
| 1 | `operation_observe` | Смотри — что случилось | Заглушка |
| 2 | `operation_name_action` | Было — стало | Заглушка |
| 3 | `operation_do_action` | Сделай действие | Доработать (текст + адаптив) |
| 4 | `operation_sign_action` | Знак↔Действие | Доработать (direction + адаптив) |
| 5 | `operation_find_sign` | Найди знак | Новый дизайн |
| 6 | `operation_result` | Сколько стало? | Новый дизайн |
| 7 | `operation_chain` | Цепочка | Новый рендерер |

---

## Режим 3 — «Сделай действие» (`operation_do_action`)

### Что сохраняется
Вся визуализация и структура трёх фаз сохраняется без изменений. Любые визуальные правки — только через явное согласование.

### Изменения

**Инструкции (текст):**

| Фаза | Было | Стало |
|------|------|-------|
| Setup | "Посчитай, сколько было." | **"Покажи [N] на палке"** |
| Action | "Прибавь [N]." / "Убери [N]." | без изменений |
| Answer | "Посчитай, сколько стало, и нажми на число." | **"Нажми сколько стало"** |

**Адаптивный layout:**
- Корректная работа на телефоне (портрет и ландшафт) и планшете (портрет и ландшафт)
- Палка не должна обрезаться и должна оставаться удобной для драга на всех размерах

---

## Режим 4 — «Знак↔Действие» (`operation_sign_action`)

### Что сохраняется
Вся визуализация сохраняется без изменений. Любые визуальные правки — только через явное согласование.

### Изменения

**Параметр `direction`:**

| Значение | Поведение |
|----------|-----------|
| `"alternating"` | знак→слово, слово→знак, знак→слово… (дефолт) |
| `"sign_to_action"` | всегда показывает знак, ребёнок выбирает слово |
| `"action_to_sign"` | всегда показывает слово, ребёнок выбирает знак |
| `"random"` | случайно 50/50 |

Дефолт `"alternating"` предотвращает машинальное нажатие при всего двух вариантах ответа.

**Адаптивный layout:** аналогично режиму 3.

---

## Режим 5 — «Найди знак» (`operation_find_sign`)

### Педагогическая цель
Ребёнок читает выражение с пропущенным знаком и выбирает `+` или `−`. Переход от конкретного действия к работе с математической записью.

### Экран
```
        3  ?  2  =  5
        
        [  +  ]  [  −  ]
        
                    [ 🧮 ]  ← кнопка хелпера (если включена)
```

- Выражение крупное, по центру, знак заменён на `?`
- Две большие кнопки выбора
- Никаких рельсов, историй "до/после", подписей зон
- Правильный ответ подсвечивается, неправильный — встряска

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `operation` | `"add" \| "subtract" \| "both"` | Какие знаки встречаются |
| `maxNumber` | number | Максимальное число в задаче |
| `changeMax` | number | Максимальная разность |
| `showHelper` | boolean | Доступна ли кнопка хелпера |

---

## Режим 6 — «Сколько стало?» (`operation_result`)

### Педагогическая цель
Ребёнок читает полное выражение и вычисляет результат. Fluency — финальная ступень перед цепочками.

### Экран
```
        3  +  2  =  ?
        
        [ 2 ]  [ 4 ]  [ 5 ]  [ 7 ]   ← choices
        
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ← таймер (если включён)
   
                    [ 🧮 ]
```

- В `inputMode: "choices"` — 4 варианта числа (как сейчас в NumberChoices)
- В `inputMode: "pad"` — полная числовая клавиатура (NumberPad)
- Таймер-полоска снизу, если `timer > 0`

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `operation` | `"add" \| "subtract" \| "both"` | |
| `maxNumber` | number | |
| `changeMax` | number | |
| `inputMode` | `"choices" \| "pad"` | Способ ввода ответа |
| `timer` | number \| null | Секунды на ответ, null = без таймера |
| `showHelper` | boolean | |

## Режим 7 — «Цепочка» (`operation_chain`)

### Педагогическая цель
Ребёнок решает выражение из двух операций: `A + B − C = ?`. Пошаговое решение с визуальной подсветкой активной части.

### Экран и поток

**Шаг 1:** активная часть — первая операция
```
    [ 2  +  3 ]  −  1  =  ?
      ↑ подсвечено ↑
      
    [ 3 ]  [ 4 ]  [ 5 ]  [ 6 ]
```

Ребёнок выбирает промежуточный результат (5). Выражение обновляется:

**Шаг 2:** активная часть — вторая операция
```
    [ 5  −  1 ]  =  ?
      ↑ подсвечено ↑
      
    [ 2 ]  [ 3 ]  [ 4 ]  [ 5 ]
```

Ребёнок выбирает финальный результат (4). Анимация успеха.

### Параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `operation` | `"add" \| "subtract" \| "mixed"` | Тип операций в цепочке |
| `maxNumber` | number | |
| `steps` | number | Количество операций (сейчас всегда 2) |
| `showHelper` | boolean | |

## Хелпер (общий для режимов 5–7)

### Принцип
Хелпер — счётный инструмент, доступный по кнопке. Помогает посчитать, но не даёт ответ. Ребёнок считает на хелпере, затем вводит ответ сам в основном интерфейсе.

### Управление
- Специалист включает `showHelper: true` в настройках режима
- На экране появляется кнопка (иконка счёт/калькулятор)
- Ребёнок нажимает кнопку → хелпер раскрывается (панель или оверлей)
- Закрытие хелпера → возврат к задаче, ответ не зафиксирован

### Инструмент
- По умолчанию — компактная версия палки из режима 3
- Палка в хелпере работает в свободном режиме: ребёнок ставит любое число
- Позиция фишек НЕ считывается как ответ задачи
- Возможность добавить альтернативные инструменты в будущем (числовая прямая, точки) — заложить в архитектуру через `helperTool: "stick" | ...`

---

## Заглушки (режимы 1–2)

Режимы `operation_observe` и `operation_name_action` реализуются как пустые placeholder-экраны с текстом "Скоро" или аналогичным. Полноценный дизайн — отдельная итерация.

---

## Что НЕ входит в эту итерацию

- Полноценный дизайн режимов 1–2
- Альтернативные хелперы (числовая прямая, точки)
- Цепочки длиннее двух операций (`steps > 2`)
- Аудиосопровождение инструкций
