# Таймер: ненавязчивое уведомление, минуты без секунд, подпись шага

## Контекст

Компонент таймера (`src/features/timer/TimerContext.jsx`, `AnalogTimer.jsx`,
`GlobalTimer.jsx`) — аналоговый циферблат с drag-выбором минут, свёрнутый в
«язычок», прибитый к верхней кромке экрана. Когда рецепт (`reading/index.jsx`)
доходит до шага с фразой «(установить таймер...)», сейчас происходит два
нежелательных эффекта:

1. Циферблат **сам раскрывается** (`setIsOpen(true)`), прерывая чтение рецепта.
2. Диск **сам накручивается** на предложенное количество минут
   (`timerRequest.minutes` → `setSetMinutes`).

Кроме того, обратный отсчёт всегда показывает секунды (в тексте, в крупной
подписи над циферблатом и на самом язычке с мигающим двоеточием) — точность до
секунды не нужна для готовки и усложняет считывание ребёнком с РАС. Наконец,
если в будущем понадобится несколько параллельных таймеров, сейчас нет способа
понять, какой шаг рецепта стоит за конкретным отсчётом.

Эта задача решает все три момента для **одного** (текущего, singleton) таймера.
Поддержка нескольких одновременно идущих таймеров — не в охвате; см.
«Явное ограничение охвата».

## Явное ограничение охвата

- Архитектура остаётся «один таймер». Подпись шага — это ярлык на
  существующем едином `TimerContext`/`GlobalTimer`, не параллельные экземпляры.
- Видео-награда «Играем в тишину» (обратный отсчёт времени мультика,
  `rewardSecondsLeft`) не трогается — секунды там остаются, это не про точность
  готовки.
- Контент рецептов (`content/recipes/*.txt`) не меняется — подпись берётся из
  уже существующего текста шага в рантайме, никаких новых полей в файлах.

## Дизайн

### 1. Язычок больше не раскрывается сам и не крадёт фокус

`TimerContext.requestTimer(minutes)` → `requestTimer(label)`:

- Не вызывает `setIsOpen(true)`.
- Не пишет число в `setMinutes` (диск остаётся на том значении, что было
  выставлено вручную в прошлый раз).
- Вместо `timerRequest: {minutes, nonce}` стейт разделяется на два:
  - `timerSuggested: boolean` — есть ли непросмотренное предложение от рецепта.
  - `pendingLabel: string | null` — подпись последнего предложения (см. §3).
- `requestTimer(label)` выставляет `timerSuggested = true`, `pendingLabel = label`.
  Новый вызов (следующий шаг рецепта тоже просит таймер) перезаписывает оба —
  всегда актуален только последний.
- Открытие язычка (тап) гасит `timerSuggested` (визуальное подтверждение), но
  **не** трогает `pendingLabel` — ярлык нужен ещё при последующем запуске.
- `resetSession()` дополнительно сбрасывает `timerSuggested` и `pendingLabel`.

`AnalogTimer.jsx`: эффект, читавший `timerRequest` для накрутки диска
(строки 104–110), удаляется целиком; `timerRequest` убирается из
деструктуризации `useTimer()`.

`reading/index.jsx` (текущий вызов на строке 640): вместо
`requestTimer(minutes)` — `requestTimer(buildTimerLabel(resolvedText))`, где
`resolvedText` — та же строка, что уже идёт в `parseTimerMinutesFromText`
(результат `applyOptionValueConditional(applyOptionSelections(applyPortions(...)))`).
Условие вызова не меняется — по-прежнему только когда `parseTimerMinutesFromText`
нашёл минуты (то есть шаг реально содержит «установить таймер»).

### 2. Язычок: только иконка, состояние — цветом/анимацией

Убираются `tabMM`/`tabSS`/`pad()` и вся раскладка с цифрами и двоеточием из
`GlobalTimer.jsx`. Язычок всегда компактного размера (иконка ⏱, ~80×46px —
как сейчас в состоянии idle), большая раскладка 240×102 для бегущих цифр
(`.global-timer-tab--set`, `--running` с `font-size: 45px`) удаляется из CSS
как мёртвый код вместе с ней.

Три визуальных состояния язычка (класс-модификатор, без текста):

- **idle** — нейтральный фон, как сейчас (`#fffdf9`).
- **suggested** (`timerSuggested && !isRunning`) — тёплое дышащее оранжевое
  свечение тени, интервал ~1.8s, бесконечно до тапа. CSS-анимация по мотивам
  согласованного в интерактивном превью варианта A:
  ```css
  @keyframes gt-suggest-glow {
    0%, 100% { box-shadow: 3px 3px 8px rgba(200,75,42,0.18), -3px 3px 8px rgba(200,75,42,0.18); }
    50%      { box-shadow: 3px 3px 20px rgba(200,75,42,0.55), -3px 3px 20px rgba(200,75,42,0.55); }
  }
  ```
- **running** — сохраняется нынешний жёлтый breathing-эффект
  (`gt-breathe`/`#f5c842`), но без каких-либо цифр внутри — просто подсвеченная
  иконка.

Приоритет: `running` перекрывает `suggested` (если во время текущего отсчёта
рецепт попросил ещё один таймер — глоу дождётся, пока текущий отсчёт
закончится). Состояние «session» (время с начала работы) как отдельный
видимый на язычке режим убирается — раз показывать нечего (цифр нет), не
нужно и визуально отличать его от idle.

### 3. Подпись шага в открытом циферблате

`AnalogTimer.jsx` получает из контекста `pendingLabel`. При запуске
(`startTimer()`) значение **захватывается** в локальный стейт `activeLabel`
(`pendingLabel || "Таймер"`) — то есть если человек открыл язычок и накрутил
время сам, без ожидающего предложения от рецепта, подпись — обычное
«Таймер», как и сегодня. `activeLabel` сбрасывается вместе с остальным в
`hardReset()`.

**Важная поправка по месту показа.** `AnalogTimer` в единственном месте
использования (`GlobalTimer.jsx:80`) всегда рендерится с `clockOnly` —
поэтому ветка `if (clockOnly) {...}` (компактный циферблат-дропдаун) это
**единственное**, что пользователь когда-либо видит; блок ниже
(`.analog-timer-inner`/`.analog-timer-topbar` с заголовком «Таймер», кнопками
звука/закрытия — строки ~716–908) сейчас мёртвый код, никогда не
монтируется. Подпись показываем не в этом заголовке (он не виден), а прямо
над циферблатом в компактной раскладке — там же, где сейчас `drag-label`
(крупное число+слово): при `running && activeLabel` рендерим маленький
текстовый блок с подписью шага над обычным drag-label (который по-прежнему
показывает «Осталось N минут» / «меньше минуты»). Обрезка длинных подписей —
`text-overflow: ellipsis`/`white-space: nowrap` с ограничением по ширине
циферблата (`--gt-clock-size`).

Мёртвую ветку `.analog-timer-inner` не трогаем — она вне охвата этой задачи
(могла быть заготовкой под будущий полноэкранный режим); просто не кладём в
неё новую логику, раз она всё равно не рендерится.

**Формирование текста подписи** (новая маленькая утилита, например
`buildTimerLabel(text)` рядом с `parseTimerMinutesFromText` в
`parseRecipeTxt.js`):

1. Вырезать конструкцию `(установить таймер...)` целиком — новый паттерн вида
   `/\(\s*установить\s+таймер[^)]*\)/i` (в файле уже есть соседний
   `TIMER_PAREN_RE`, который ловит только открывающую скобку для других целей;
   для вырезания нужен именно парный вариант, закрывающий на `)`).
2. Обрезать пробелы/висячую пунктуацию по краям.
3. Если длина больше ~50 символов — обрезать по границе слова и добавить «…».

Примеры (реальные строки из рецептов):
- `"Обжаривать 4 минуты (установить таймер)."` → `"Обжаривать 4 минуты."`
- `"Добавить морковку. Обжаривать вместе 4 минуты, помешивая (установить таймер)."`
  → `"Добавить морковку. Обжаривать вместе 4 минуты, помеш…"` (обрезано по
  границе слова у ~50 символов).

### 4. Секунды убираются из всех числовых индикаторов

Действует независимо от язычка (который теперь и так без цифр) — относится к
**раскрытой** панели/циферблату:

- **Цифровой текст** (`timeDisplayString` в `AnalogTimer.jsx`): ветка
  `remainingSeconds > 0 && remainingSeconds < 60` (сейчас
  `` `Осталось ${remainingSeconds} ${getSecondLabel(...)}` ``) заменяется на
  статичную строку `"Осталось меньше минуты"` — без цифр, без обновления
  каждую секунду. Выше последней минуты поведение не меняется (уже целые
  минуты: «Осталось 5 минут»).
- **Крупная подпись над циферблатом** (`analog-timer-drag-label`, видна и в
  `clockOnly`, и в полной панели): та же граница `remainingSeconds < 60` во
  время `running` — вместо `value=remainingSeconds`/`unit=секунд` рендерится
  один текстовый блок `"меньше минуты"` (без пары «крупное число + мелкое
  слово», просто текст помельче на том же месте). Выше последней минуты —
  как сейчас (`value=displayMin`, `unit=минут`).
- **Секундная стрелка и тиканье** (`playTick`, `secondHandStep`/
  `secondHandPoint`) — без изменений, это непрерывное аналоговое движение и
  звук, не число для считывания.

## Явно вне охвата / не трогаем

- Множественные параллельные таймеры (несколько язычков/циферблатов
  одновременно) — отдельная будущая задача, если действительно понадобится.
- Обратный отсчёт видео-награды («Играем в тишину») — секунды там остаются.
- Контент рецептов — подпись собирается из существующего текста шага в
  рантайме, файлы `content/recipes/*.txt` не редактируются.
- `configMinutes`/`setConfigMinutes` в `TimerContext` — существующий,
  неиспользуемый нигде извне стейт, не относится к этой задаче, не трогаем.

## Тестирование

- Юнит-тест на новую утилиту разбора подписи (обрезка «(установить
  таймер...)», обрезка по длине) — рядом с существующими тестами
  `parseRecipeTxt.test.js`.
- Ручная проверка в браузере (Playwright, headed — по договорённости с
  пользователем): открыть рецепт с фразой «установить таймер», убедиться, что
  циферблат не раскрывается сам, язычок начинает светиться; открыть язычок,
  убедиться что диск НЕ накручен автоматически; накрутить и запустить вручную,
  убедиться что в заголовке панели отображается подпись шага; дождаться
  последней минуты, убедиться в статичном тексте «Осталось меньше минуты» без
  посекундного обновления; проверить, что язычок нигде не показывает цифр.
