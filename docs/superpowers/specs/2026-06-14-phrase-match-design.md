# Design: phrase_match — Тренажёр точного чтения фраз

**Дата:** 2026-06-14
**Статус:** Approved

---

## Контекст и проблема

Упражнение для взрослого человека с РАС, обученного чтению глобальным методом. Такой читатель воспринимает слово как целостный визуальный образ: ловит одно знакомое слово из предложения (существительное или объект) и угадывает смысл, не дочитывая фразу до конца.

Классическая ошибка: «На чём едут по дороге?» → ученик слышит «дорога» → отвечает «машина» без учёта глагола «едут» и предлога «по».

Показывать фразы ПО ОДНОЙ бесполезно — всегда можно угадать по одному ключевому слову. Решение: показывать **несколько похожих фраз одновременно** с одним и тем же «отвлекающим» словом. Тогда угадать невозможно — нужно прочитать дискриминирующий элемент (глагол, предлог, вопросительное слово).

---

## Формат упражнения

**Один экран = одна группа из 3 фраз:**

```
Левый столбец          Правый столбец
──────────────────     ──────────────────────────────
[Чем наливают суп?]    [🥄ложка] [🍴вилка] [🫕кастрюля]
[Чем едят суп?     ]   [🥄половник] [🍽тарелка]
[В чём варят суп?  ]
```

- **Левый столбец:** 3 фразы-зоны приёма (drop targets)
- **Правый столбец:** 5 картинок (3 правильных + 2 дистрактора), перемешаны
- **Взаимодействие:** drag-and-drop в обоих направлениях (картинка → фраза или фраза → картинка)
- **Без режима знакомства** — ученик уже знает все жизненные ситуации, тренируется только точность чтения

---

## Механика

**Правильное совпадение:**
- Картинка защёлкивается в слот фразы
- Зелёная подсветка, фраза блокируется
- Дистракторы остаются доступными до конца (нельзя вычислить оставшиеся через исключение)

**Неправильное совпадение:**
- Картинка возвращается на место, красная вспышка
- Никакой подсказки — просто «нет», попробуй ещё раз

**Завершение группы:**
- Все 3 пары верно соединены → анимация успеха → следующая группа

**Дистрактор-картинки:**
- Если ученик пытается прикрепить фразу к дистрактору → красная вспышка, возврат
- Дистракторы никогда не принимаются как правильный ответ
- 2 дистрактора на группу (выбраны из того же домена, но не совпадающие с фразами)

## Engine (engine.js)

```js
// Для каждой группы → одна задача типа "match"
export function generateTasks(modeType, groups, params = {}) {
  if (modeType !== "match") return [];
  return shuffle(groups).map(group => ({
    type: "match",
    items: group.items,           // [{id, phrase, image}] × 3
    images: shuffle([             // все 5 картинок перемешаны
      ...group.items.map(i => ({ id: i.id, image: i.image, isDistractor: false })),
      ...group.distractors.map(d => ({ id: d.id, image: d.image, isDistractor: true })),
    ]),
  }));
}
```

## Пилотный контент (5 групп)

| # | Тема | Дискриминирующий элемент | Фразы | Правильные картинки | Дистракторы |
|---|------|--------------------------|-------|---------------------|-------------|
| 1 | Суп | глагол (налить/есть/варить) | Чем наливают суп? / Чем едят суп? / В чём варят суп? | половник / ложка / кастрюля | вилка, тарелка |
| 2 | Резать | объект (хлеб/бумага/ногти) | Чем режут хлеб? / Чем режут бумагу? / Чем режут ногти? | нож / ножницы / щипчики | карандаш, линейка |
| 3 | Транспорт | среда (дорога/небо/море) | На чём едут по дороге? / На чём летят по небу? / На чём плывут по морю? | автобус / самолёт / корабль | велосипед, поезд |
| 4 | Одежда | глагол (стирать/гладить/сушить) | Чем стирают одежду? / Чем гладят одежду? / Где сушат одежду? | стиральная машина / утюг / верёвка с прищепками | шкаф, вешалка |
| 5 | Игра | вопросительное слово (с кем/где/во что) | С кем играет девочка? / Где играет девочка? / Во что играет девочка? | подруга / площадка / мяч | кукла, велосипед |

## Изображения

- 3 правильных × 5 групп = **15 картинок**
- 2 дистрактора × 5 групп = **10 картинок**
- Итого: **25 изображений**, формат webp, квадрат 1:1
- Стиль: photorealistic educational, clean white/light background, sharp focus, no text

### Промпт для генерации
```
high-quality photorealistic educational flashcard image,
natural soft lighting, sharp focus, clean light background,
true-to-life colors, square 1:1 composition,
[subject], no text, no watermark, child-friendly
```

## Потенциальное развитие (не в этом PR)

- **Уровень сложности:** 4 фразы + 3 дистрактора вместо 3+2
- **Оси тренировки:** подборка фраз по типу ошибки (приставки, предлоги, вопросительные слова)
- **Статистика:** фиксировать к каким дистракторам чаще всего тянутся — для выявления паттернов ошибок
