## 2. Режим и параметры

Один режим: `column_arithmetic`.

| Параметр | Тип | Значения | По умолчанию |
|----------|-----|----------|--------------|
| `operation` | enum | `add` / `subtract` / `mixed` | `add` |
| `carryMode` | enum | `none` / `carry` / `mixed` | `none` |
| `digits` | enum | `2` / `3` | `2` |

`carryMode` работает для обеих операций: при сложении — перенос (carry), при вычитании — заём (borrow). В UI: **«Перенос / заём»**.

## 3. Структура задачи (task object)

```js
{
  type: "column_arithmetic",
  cardId, conceptId,
  operation: "add" | "subtract",
  digits: 2 | 3,
  top: 27,        // верхнее число
  bottom: 15,     // нижнее число
  result: 42,     // итоговый ответ

  // Разбивка по столбцам, индекс 0 = единицы, 1 = десятки, 2 = сотни
  columns: [
    {
      position: "units",
      topDigit: 7,
      bottomDigit: 5,
      carryIn: 0,       // (add) сколько пришло с предыдущего столбца
      borrowIn: 0,      // (sub) нужен ли заём из этого столбца
      writeDigit: 2,    // цифра результата, которую ребёнок вписывает
      carryOut: 1,      // (add) перенос в следующий столбец
      borrowOut: 1,     // (sub) заём из следующего столбца
    },
    {
      position: "tens",
      topDigit: 2,
      bottomDigit: 1,
      carryIn: 1,
      borrowIn: 0,
      writeDigit: 4,
      carryOut: 0,
      borrowOut: 0,
    }
  ],

  // Список шагов, которые должен выполнить ребёнок (порядок drag-and-drop)
  steps: [
    { cellType: "result",   position: "units", digit: 2 },
    { cellType: "carry",    position: "tens",  digit: 1 },  // перенос над десятками
    { cellType: "result",   position: "tens",  digit: 4 },
  ]
}
```

Для вычитания с займом (`42 − 17`):
```js
steps: [
  { cellType: "borrow",  position: "tens",  digit: 1 },  // заём: 1 десяток берём
  { cellType: "result",  position: "units", digit: 5 },  // 12 − 7
  { cellType: "result",  position: "tens",  digit: 2 },  // 3 − 1
]
```

После того как ребёнок вписал `borrow=1`, приложение автоматически показывает два визуальных изменения одновременно:
- над клеткой единиц верхнего числа → маленький текст `¹²` (голубой цвет, ≈50% размера цифры)
- клетка десятков верхнего числа → исходная цифра зачёркивается, рядом (или над ней) появляется уменьшенная цифра `3`

Эти изменения остаются видны до конца задачи — ребёнок опирается на них при заполнении десятков результата.

## 4. UX — Визуал «Клеточная тетрадь»

### Фон

CSS-сетка, имитирующая тетрадь в клетку: светло-голубые линии ~2px, шаг ~44px, белый фон. Ячейки примера выровнены точно по клеткам.

### Расположение на экране (2 цифры + перенос)

```
┌──┬──┬──┬──┬──┬──┐
│  │  │  │░1│  │  │  ← ряд переноса/займа (мелкие клетки ≈60%)
├──┼──┼──┼──┼──┼──┤
│  │  │  │ 2│ 7│  │  ← верхнее число
├──┼──┼──┼──┼──┼──┤
│  │  │+│ 1│ 5│  │  ← знак + нижнее число
├──┴──┴──┴──┴──┴──┤
│    ─────────────│  ← горизонтальная черта
├──┬──┬──┬──┬──┬──┤
│  │  │  │░░│░░│  │  ← результат (░ = пустые клетки)
└──┴──┴──┴──┴──┴──┘
```

Для 3-значных чисел сетка расширяется на 1 столбец вправо.

### Лоток цифр

Фиксированный ряд внизу экрана — 10 тайлов `[0][1][2]...[9]`. Каждый тайл — карточка с цифрой, стилизована как резиновый штамп или деревянный кубик с цифрой.

Цифры в лотке **неисчерпаемы** — можно брать одну и ту же несколько раз.

## 5. Взаимодействие — Drag & Drop

### Поток

1. **Активная клетка** — одна за раз (управляемый режим), мягко пульсирует / светится.
2. Ребёнок **перетаскивает** цифру из лотка на активную клетку.
3. Приложение проверяет: правильно ли? 
   - **Да** → цифра «впечатывается» (анимация появления, как чернила), переходим к следующему шагу.
   - **Нет** → цифра улетает обратно в лоток, клетка коротко вибрирует.
4. После заполнения всех клеток — анимация успеха, вызов `onCorrect`.

### Порядок шагов (управляемый, справа налево)

**Сложение без переноса (`23 + 14`):**
1. Результат единиц → `7`
2. Результат десятков → `3`

**Сложение с переносом (`27 + 15`):**
1. Результат единиц → `2`
2. Перенос над десятками → `1`  (маленькая клетка, сразу становится видна)
3. Результат десятков → `4`

**Вычитание без займа (`45 − 23`):**
1. Результат единиц → `2`
2. Результат десятков → `2`

**Вычитание с займом (`42 − 17`):**
1. Заём над десятками → `1`  (появляется зачёркивание 4→3, над единицами ¹²)
2. Результат единиц → `5`
3. Результат десятков → `2`

## 6. Генератор задач (engine.js)

### carryMode: none (без переноса/займа)

**Сложение:** единицы₁ + единицы₂ < 10, десятки₁ + десятки₂ < 10.
**Вычитание:** единицы₁ ≥ единицы₂, десятки₁ ≥ десятки₂.

### carryMode: carry (с переносом/займом)

**Сложение:** единицы₁ + единицы₂ ≥ 10, десятки₁ + десятки₂ + 1 < 10 (чтобы результат был 2-значным).
**Вычитание:** единицы₁ < единицы₂ (нужен заём), десятки₁ − 1 ≥ десятки₂.

### carryMode: mixed

Случайно выбирается между `none` и `carry`.

### digits: 3

Добавляется столбец сотен с теми же правилами.

### Фильтрация карточек в engine

Карточки темы несут `params.operation: "add" | "subtract"`. Engine фильтрует пул:
```js
const allCards = cards.filter(c => c.renderer === "column_addition");
const pool = operation === "mixed"
  ? allCards
  : allCards.filter(c => (c.params?.operation ?? "add") === operation);
```

### Генерация чисел

```js
function generate(operation, carryMode, digits) {
  // attempts loop (max 100) до валидного примера
  // для сложения: top = random(10..99), bottom = random(10..99), проверить carryMode
  // для вычитания: top > bottom всегда (гарантирует результат ≥ 0), проверить carryMode по единицам/десяткам
}
```

## 7. Педагогические заметки

- Управляемый порядок (справа налево) моделирует реальную процедуру.
- Заём визуализируется немедленно после drag — ребёнок видит следствие своего действия.
- Перенос-клетка маленькая и появляется только когда нужна — не перегружает экран.
- Режим `mixed` вводить только после уверенного освоения `none` и `carry` отдельно.

## Что НЕ входит в MVP

- Трёхзначные числа с двойным переносом

- Аудиосопровождение шагов
