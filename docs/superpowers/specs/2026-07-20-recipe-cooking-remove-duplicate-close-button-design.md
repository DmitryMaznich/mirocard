# Убрать дублирующую кнопку «Закрыть» на экране готовки рецепта

## Проблема

На экране готовки рецепта (`follow_instruction`, компонент `InstructionTask` в
`src/topics/renderers/reading/index.jsx`) сейчас две кнопки «Закрыть»:

- в главном хедере сессии (`SessionHeader`) — открывает подтверждение выхода
  (`openSessionExitPrompt`);
- рядом с прогресс-баром рецепта внутри самого рендерера
  (`.instruction-close-btn`, `onClick={exitInstruction}`) — выходит сразу,
  без подтверждения.

Дублирование сбивает с толку и даёт два разных поведения для одного и того
же действия.

## Решение

- Убрать `<button className="instruction-close-btn">` из
  `.instruction-header-row` в `InstructionTask` (reading/index.jsx). Остаётся
  единственная кнопка «Закрыть» — в главном хедере, с подтверждением.
- `.instruction-progressbar-wrap` уже `flex: 1` внутри `.instruction-header-row`
  — после удаления соседней кнопки прогресс-бар автоматически займёт всю
  ширину строки; дополнительный CSS не нужен.
- Функцию `exitInstruction` не удалять — она используется клавиатурной
  навигацией (Escape, стрелка назад/Backspace на первом шаге).

## Не в скоупе

- `InstructionRunnerScreen.jsx` (отдельный, отмирающий экран «Инструкций» вне
  `SessionScreen`) — там только одна кнопка «Закрыть», дублирования нет.
- Любые изменения поведения `SessionHeader`/`openSessionExitPrompt`.

## Тестирование

Визуальная проверка в браузере: на экране готовки рецепта видна одна кнопка
«Закрыть» (в хедере), прогресс-бар рецепта растянут на всю ширину строки.
