# Design: Тема «Чтение. Инструкции»

**Date:** 2026-06-22  
**Status:** Approved  

---

## Цель

Новая тема для ежедневной логопедической практики. Ребёнок читает короткое предложение-инструкцию, отвечает устно на вопрос логопеда «что ты должен сделать?», затем выполняет действие. Каждый день — другой набор из 10 предложений, без ручной настройки.

---

## Решения (принятые в ходе brainstorming)

| Вопрос | Решение |
|---|---|
| Смена предложений | Детерминированная выборка по дате (seed = topicId + YYYY-MM-DD) |
| Структура пула | Один общий пул, без категорий |
| Взаимодействие | Только чтение + тап «Дальше», без экранов вопросов |
| Режимов в теме | Один: `daily_sentences` |

## Изменения в коде

### `src/topics/renderers/reading/engine.js`

Добавить в функцию `generateTasks`:

```js
case "daily_sentences":
  return buildDailySentencesTasks(text);
```

Новая функция:

```js
function seededShuffle(arr, seedStr) {
  let s = 0;
  for (let i = 0; i < seedStr.length; i++) s = (Math.imul(31, s) + seedStr.charCodeAt(i)) | 0;
  const copy = [...arr];
  for (let i = copy.length - 1; i > 0; i--) {
    s = (Math.imul(s, 1664525) + 1013904223) | 0;
    const j = Math.abs(s) % (i + 1);
    [copy[i], copy[j]] = [copy[j], copy[i]];
  }
  return copy;
}

function buildDailySentencesTasks(text) {
  const dailySize = text.dailySize ?? 10;
  const today = new Date().toISOString().slice(0, 10); // YYYY-MM-DD
  const seed = `${text.id}_${today}`;
  const shuffled = seededShuffle(text.lines ?? [], seed);
  const selected = shuffled.slice(0, dailySize);
  return [{
    type: "read_text",
    textId: text.id,
    text: { ...text, lines: selected },
  }];
}
```

## UX сессии

```
┌─────────────────────────────────┐
│  Чтение. Инструкции             │
│                                 │
│  Дотронься правой рукой         │
│  до левого уха.                 │
│                                 │
│           3 / 10                │
│                                 │
│  [← Назад]          [Дальше →]  │
└─────────────────────────────────┘
```

- Предложение крупным шрифтом
- Счётчик N/10
- На 10-м — кнопка «Готово»
- Логопед ведёт: задаёт вопрос устно, ребёнок отвечает и выполняет, тап «Дальше»

---

## Что НЕ входит в V1

- Режим вопросов/ответов (understand_text) — не нужен, логопед ведёт устно
- Редактор пула — не нужен в V1
- Иллюстрации к отдельным предложениям — невозможно при случайной выборке
- Статистика выполнения по предложениям
