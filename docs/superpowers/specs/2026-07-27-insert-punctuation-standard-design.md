# Лист-вставка «Знаки препинания» для тетради-стандарт

## Проблема

Тема «Печатные материалы» (`print_materials`) предлагает 3 тетради (стандарт/плотная/точки). У тетради «стандарт РФ» (`notebook_standard`, косая линейка 20мм) нужен дополнительный печатный лист — тренажёр для обводки знаков препинания (точка, запятая, восклицательный и вопросительный знаки), который пользователь будет вручную вкладывать в собранные тетради. Лист не привязан к автосборке тетради и не дублируется — печатается и используется в единственном экземпляре.

## Решение

### A. Новый скрипт `make_insert_punctuation_standard.py`

Располагается в корне репозитория, рядом с `make_lined_paper_landscape_standard.py`, по образцу которого построен.

Формат страницы — идентичен обычной странице стандарта:

- A4 landscape (297×210мм), разворот из двух половин A5 (0–148.5мм и 148.5–297мм).
- Горизонтальные линии: чередование `narrow_spacing=4мм` / `wide_spacing=8мм` (как в `make_lined_paper_landscape_standard.py`).
- Косые линии: шаг `spacing_diagonal=20мм`, угол `angle_from_vertical=65°`.
- Поля: красные линии на `margin=15мм` от левого и правого края страницы.
- Белая разделительная линия по центру (148.5мм), отверстия для степлера, copyright-подвал — как в оригинальном скрипте (код секций 4–7 переносится без изменений).

**Левая половина (0–148.5мм)** — без изменений: обычная сетка линий стандарта, как и на любой другой странице тетради.

**Правая половина (148.5–297мм)** — та же сетка линий (не убирается, остаётся визуальным фоном), поверх которой отрисовываются знаки препинания:

- Шрифт `ClassRoomCursive` (уже зарегистрирован в проекте — см. `scripts/cover_tetrad.py`), цвет заливки — серый `(0.62, 0.62, 0.62)` (RGB, 0..1).
- Размер шрифта: `narrow_spacing_pt / X_RATIO`, где `X_RATIO = 0.285` (тот же коэффициент x-height/em для ClassRoomCursive, что и в `cover_tetrad.py`) → при narrow_spacing=4мм получается ≈40pt.
- Строки (baseline) берутся из той же горизонтальной сетки линий, что и фон: baseline — линия перед узким шагом, верх рабочей зоны — линия после узкого шага (аналогично сбору `top_line_positions` в `make_lined_paper_landscape_dots_only.py`).
- Знак повторяется вдоль строки с фиксированным шагом ≈9мм (не привязан к шагу косых линий 20мм), в границах правой половины, начиная сразу после центральной разделительной линии и заканчивая перед правым полем (margin).
- Символ рисуется через `drawCentredString(x, y_baseline, char)` — вертикальное позиционирование (запятая ниже baseline, точка на baseline, `!`/`?` во весь рост рабочей зоны) обеспечивается самим шрифтом, без дополнительной логики.

**Деление строк на четверти** — все строки рабочей сетки правой половины (сверху вниз) делятся на 4 примерно равные по числу строк группы, каждой группе присваивается один знак, в порядке:

1. точка `.`
2. запятая `,`
3. восклицательный знак `!`
4. вопросительный знак `?`

Выходной файл скрипта: `insert_punctuation_standard.pdf` (по аналогии с `output_file` в существующих скриптах).

### B. Каталог темы (`src/print_materials/topic.json`)

- Файл вставки копируется в `src/print_materials/print/insert_знаки_standard.pdf`.
- В `files` карточки `notebook_standard` добавляется новая запись:

```json
{
  "label": "Вставка — знаки препинания",
  "path": "print/insert_знаки_standard.pdf",
  "filename": "тетрадь_вставка_знаки.pdf",
  "hint": "1 доп. лист, альбомная; печатать один раз и вложить в собранную тетрадь"
}
```

- `meta.version` темы бампается на patch (1.0.6 → 1.0.7).

## Не в скоупе

- Автосборка/дублирование листа в `make_notebook.py` — лист печатается и используется в одном экземпляре, пользователь вставляет его вручную.
- Применение к вариантам «плотная» и «точки» — только `notebook_standard`.
- Изменение существующих `*_pages.pdf` или обложек.
- Автотесты PDF-вёрстки (в проекте их нет и для существующих страниц/обложек — проверка глазами).

## Тестирование

Ручной запуск `python make_insert_punctuation_standard.py`, визуальная проверка PDF:

- Левая половина не отличается от обычной страницы стандарта.
- На правой половине знаки препинания корректно садятся на линии (не «плавают» и не проваливаются сквозь baseline), серый цвет не сливается с линиями сетки.
- Деление на четыре знака примерно равномерное по высоте страницы.
- Итоговый PDF корректно открывается и отображается в карточке `notebook_standard` в приложении.
