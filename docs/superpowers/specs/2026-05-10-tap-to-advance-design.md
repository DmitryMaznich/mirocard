# Дизайн: настройка темпа продолжения (tap-to-advance)

**Дата:** 2026-05-10  
**Статус:** Approved

---

## Контекст

В интерактивных режимах после правильного ответа карточка сейчас всегда авто-перелистывается через `FEEDBACK_DELAY_MS = 3000ms` (хардкод в `useSessionEngine.js:9`). Нужно сделать это поведение настраиваемым на уровне приложения.

После **неправильного** ответа — всегда авто-повтор той же карточки (без изменений).

---

## Новые настройки

Два поля добавляются в объект `settings` Zustand-стора (`src/core/store.js`):

| Поле | Тип | Дефолт | Описание |
|------|-----|--------|----------|
| `tapToAdvance` | boolean | `true` | Ждать тапа пользователя после правильного ответа |
| `autoAdvanceDelay` | number | `3` | Секунды до авто-перехода (активно только если `tapToAdvance = false`) |

Персистентность через `kv` / IndexedDB уже работает — дополнительных изменений не требуется.

---

## Изменения в движке сессии

**Файл:** `src/features/session/useSessionEngine.js`

- `FEEDBACK_DELAY_MS` (константа 3000) заменяется динамическим значением из стора.
- В `onCorrect`:
  - Если `tapToAdvance = true` → переход в состояние `awaitingTap: true`; авто-переход не запускается; карточка ждёт тапа.
  - Если `tapToAdvance = false` → запускается таймер `autoAdvanceDelay × 1000` мс, после чего авто-переход.

---

## Изменения в экране сессии

**Файл:** `src/features/session/SessionScreen.jsx`

- Когда `awaitingTap = true`, оверлей «правильно» остаётся видимым.
- Тап по оверлею вызывает `onAdvance()` и сбрасывает `awaitingTap`.
- Никаких отдельных кнопок — весь оверлей является зоной нажатия.

## UI настроек

**Файл:** `src/features/settings/SettingsScreen.jsx`

Новая секция «Темп продолжения» (после существующих разделов, перед build info):

```
─────────────────────────────────────
 Темп продолжения
─────────────────────────────────────
 [✓] Следующая карта по тапу

     Задержка (сек): [3] ▲▼     ← disabled если чекбокс включён
─────────────────────────────────────
```

Используются существующие компоненты `BooleanParam` и `NumberStepper` из `src/features/session/ParamsScreen.jsx`.

Диапазон `autoAdvanceDelay`: 1–10 сек, шаг 1.

---

## Что не меняется

- Логика после неправильного ответа (`onIncorrect`) — без изменений.
- Режимы с `evaluation = "quality"` или `"none"` (чтение, browse) — без изменений.
- Параметры конкретных тем/режимов (`ParamsScreen`) — без изменений.
