# Дизайн: Режим «Счёт на пальцах» для темы column_addition

**Дата:** 2026-06-26  
**Статус:** Согласован  
**Контекст:** Два новых режима внутри существующего ZIP-пакета `column_addition`. Терапевтический инструмент — логопед ведёт занятие, ребёнок выполняет физические действия (поднимает/загибает реальные пальцы), экран служит визуальной опорой.

---

## 1. Система пальцев (0–10, Near-halves bilateral)

Каждое число имеет единственное каноническое представление:

| Число | Правая рука | Левая рука |
|-------|-------------|------------|
| 0     | 0           | 0          |
| 1     | 1           | 0          |
| 2     | 1           | 1          |
| 3     | 2           | 1          |
| 4     | 2           | 2          |
| 5     | 3           | 2          |
| 6     | 3           | 3          |
| 7     | 4           | 3          |
| 8     | 4           | 4          |
| 9     | 5           | 4          |
| 10    | 5           | 5          |

**Правило:** правая ≥ левой, разница 0 или 1. Число 1 — единственное исключение для «обе руки» требования.

Хранится в `FingerSystem.js`:
```js
export const FINGER_MAP = {
  0: { right: 0, left: 0 },
  1: { right: 1, left: 0 },
  // ...
  10: { right: 5, left: 5 },
};
```

---

## 2. SVG-компонент руки

**Файл:** `HandSVG.jsx`

```jsx
<HandSVG
  count={3}           // сколько пальцев поднято (0–5)
  side="right"        // "right" | "left" (зеркалим SVG)
  fingerMode="solid"  // "solid" | "ghost" | "folded"
  animated={true}     // CSS-переходы на поднятие/опускание
  highlight={[2]}     // индексы пальцев с пульсацией (необязательно)
/>
```

Режимы пальцев:
- **solid** — закрашенный цветной палец (поднят)
- **ghost** — контурный полупрозрачный (цель, ещё не достигнута)
- **folded** — палец «загнут» вниз (для вычитания)

CSS-переход `transform: scaleY + rotate` ≈ 300ms на каждый палец.

---

## 3. Режим «Показ» (`fingers_show`)

**Цель:** ребёнок видит цифру, воспроизводит позу реальными пальцами. Логопед оценивает и переходит дальше.

### Структура карточки

```
┌──────────────────────────────────┐
│                                  │
│              7                   │
│         (большая цифра)          │
│                                  │
│       [левая]    [правая]        │
│       L:3 ↑↑↑    R:4 ↑↑↑↑      │
│      (SVG-руки — эталон позы)    │
│                                  │
│          [ → следующая ]         │
│                                  │
└──────────────────────────────────┘
```

### Параметр `hint`

- **`hint: true`** («С подсказкой») — показываем цифру + SVG-руки. Ребёнок копирует позу.
- **`hint: false`** («Без подсказки») — показываем только цифру, руки скрыты. Ребёнок воспроизводит из памяти.

Переключается в настройках сессии, не в карточке.

### Поведение

- Нет самопроверки — логопед видит результат и жмёт «следующая»
- Кнопка «следующая» — большая, в правом нижнем углу

### Структура task

```js
{
  type: "fingers_show",
  cardId,
  n: 7,          // число для показа (0–10)
  hint: true,    // подставляется из настроек сессии
}
```

### Карточки в topic.json

11 карточек (n: 0–10):
```json
{ "id": "fshow_0",  "renderer": "column_addition", "params": { "mode": "fingers_show", "n": 0  } },
{ "id": "fshow_1",  "renderer": "column_addition", "params": { "mode": "fingers_show", "n": 1  } },
...
{ "id": "fshow_10", "renderer": "column_addition", "params": { "mode": "fingers_show", "n": 10 } }
```

## 4. Режим «Счёт» (`fingers_count`)

**Цель:** ребёнок видит пример, поднимает/загибает реальные пальцы и одновременно тапает экран — виртуальные пальцы повторяют движение. В конце считает результат вслух.

### 4а. Сложение (a + b, где a ≤ 5, b ≤ 5)

Три фазы, управляемые `phase` в state: `"left"` → `"right"` → `"merge"` → `"done"`.

**Фаза 1 — Левая рука (первое слагаемое `a`)**

```
┌──────────────────────────────────┐
│         3  +  4  =  ?            │
│                                  │
│  [левая: 3 призрака]   [правая]  │
│  ↑↑↑ (ghost)            ждёт     │
│                                  │
│   Подними 3 пальца левой руки    │
│            [ тап ]               │
└──────────────────────────────────┘
```

Каждый тап: один ghost → solid на левой руке. После `a` тапов → фаза 2.

**Фаза 2 — Правая рука (второе слагаемое `b`)**

```
┌──────────────────────────────────┐
│         3  +  4  =  ?            │
│                                  │
│  [левая: 3 solid]  [правая: 4 ghost] │
│                     ↑↑↑↑ (ghost) │
│                                  │
│   Подними 4 пальца правой руки   │
│            [ тап ]               │
└──────────────────────────────────┘
```

После `b` тапов → фаза 3.

**Фаза 3 — Сдвигаем, считаем**

```
┌──────────────────────────────────┐
│         3  +  4  =  ?            │
│                                  │
│  [левая: 3]   [правая: 4]        │
│                                  │
│      [ Соединяем руки! → ]       │
└──────────────────────────────────┘
         ↓ CSS-анимация сближения
┌──────────────────────────────────┐
│                                  │
│       [ ↑↑↑ | ↑↑↑↑ ]           │
│   1  2  3  4  5  6  7            │  ← пальцы подсвечиваются по одному
│                                  │
│         3  +  4  =  7  ✓        │
│         [ → следующая ]          │
└──────────────────────────────────┘
```

### 4б. Вычитание (a − b)

Три фазы: `"show"` → `"remove"` → `"count"` → `"done"`.

**Фаза 1 — Выставляем минуенд (автоматически)**

Руки показывают `a` по near-halves системе. Минуенд отображается сразу — ребёнок ещё не тапает.

```
┌──────────────────────────────────┐
│         7  −  3  =  ?            │
│                                  │
│   [левая ↑↑↑]   [правая ↑↑↑↑]  │
│       3               4          │
│                                  │
│  Вот 7 пальцев. Убираем 3.      │
│         [ Готов ]                │
└──────────────────────────────────┘
```

**Фаза 2 — Убираем (два суб-варианта)**

**Суб-вариант А: «Убираем руку»**

Применяется, когда `b = left(a)` или `b = right(a)` — вычитаемое совпадает ровно с одной рукой.

Пример: 7 − 3, левая рука = 3 = вычитаемое.

```
│   [левая 🔴]   [правая ↑↑↑↑]   │
│                                  │
│   Убери левую руку!              │
│     [ тап по левой руке ]        │
```

Тап → левая рука уезжает за экран. Остаётся правая (4 пальца).

**Суб-вариант Б: «Загибаем пальцы»**

Применяется во всех остальных случаях. Загибаем с большей руки первой, если надо — переходим на меньшую. Пример: 7 − 2 (L:3, R:4 → загибаем 2 на правой).

```
│   [левая ↑↑↑]  [правая ↑↑↓↓↓]  │
│                  2 ghost-загиба  │
│                                  │
│   Загни 2 пальца — тапни!        │
│         [ тап ]                  │
```

После `b` тапов → фаза 3.

**Фаза 3 — Считаем оставшееся**

```
│   [левая ↑↑↑]   [правая ↑↑]    │
│                                  │
│   Сколько осталось? Посчитай!   │
│   1 — 2 — 3 — 4 — 5             │
│                                  │
│         7  −  3  =  4  ✓        │
│         [ → следующая ]          │
```

### Структура task

```js
{
  type: "fingers_count",
  cardId,
  op: "add" | "sub",
  a: 3,        // первое слагаемое / минуенд
  b: 4,        // второе слагаемое / вычитаемое
  result: 7,   // вычисляется в engine

  // для вычитания: тип удаления
  removeMode: "hand" | "fold",  // "hand" если b совпадает с одной рукой
  removeHand: "left" | "right", // какая рука уходит (только при removeMode: "hand")
}
```

## 5. Архитектура файлов

### Новые файлы

```
src/topics/renderers/column_addition/
  FingerSystem.js       ← FINGER_MAP: {0..10 → {left, right}}
                           + helpers: getRemoveMode(a, b)
  HandSVG.jsx           ← SVG-рука: count, side, fingerMode, animated, highlight
  FingersShowTask.jsx   ← режим "показ": цифра + SVG-руки + кнопка «следующая»
  FingersCountTask.jsx  ← режим "счёт": фазы, тапы, анимация сближения
```

### Изменения в существующих файлах

| Файл | Изменение |
|------|-----------|
| `index.jsx` | роутинг по `task.type`: `fingers_show` → `<FingersShowTask>`, `fingers_count` → `<FingersCountTask>` |
| `engine.js` | генераторы `generateFingersShow(card)` и `generateFingersCount(card)` |
| `column_addition_topic.json` | добавить карточки fshow_* и fcount_* |

## 6. Педагогические заметки

- **Near-halves bilateral** выбрана потому что правило «правая ≥ левой, разница ≤ 1» легко запоминается и создаёт предсказуемый паттерн.
- Режим «Показ» без самопроверки — логопед оценивает качество позы (напряжение, точность), чего алгоритм сделать не может.
- Для сложения: левая рука = первое слагаемое (статична), правая растёт — ребёнок видит структуру примера в пространстве.
- Анимация сближения рук — ключевая метафора сложения: «объединяем части».
- «Убираем руку» при вычитании — сильный визуальный образ, лучше запоминается, чем загибание.
- Диапазон слагаемых ≤ 5 для режима сложения — педагогически обоснованное ограничение для начального этапа.

---

## Что НЕ входит в MVP

- Слагаемые > 5 в режиме сложения (требует перераспределения между руками)
- Вычитание с переходом через «руку» (e.g. 8 − 5 где нужно загнуть пальцы с обеих рук)
- Аудиосопровождение (озвучка счёта)
- Режим «угадай число» (ребёнок видит руки, называет число)
