# Дизайн: Тема «Письменные буквы»

**Дата:** 2026-06-23  
**Автор:** Dima  
**Статус:** Approved

---

## Цель

Тема-тренажёр для детей, обучающихся распознавать рукописные буквы русского алфавита. Три учебные задачи:

1. Соответствие печатной и рукописной буквы (строчная и заглавная)
2. Различение строчных и заглавных рукописных букв
3. Соответствие заглавного и строчного написания одной буквы

---

## Данные

### Алфавит

Русский алфавит, 33 буквы. Исключения по заглавной форме:

- **ъ, ь, ы** — заглавная форма отсутствует (`upper_strokes: null`, `upper_viewBox: null`)
- Итого: **30 заглавных** + **33 строчных** = **63 SVG-начертания**

### Структура концепта

Каждая буква — один концепт. ID формата `letter_а`, `letter_б`, …, `letter_я`.

```json
{
  "id": "letter_а",
  "conceptId": "letter_а",
  "params": {
    "printed_upper": "А",
    "printed_lower": "а",
    "has_upper": true,
    "upper_viewBox": "0 0 80 120",
    "upper_strokes": ["M 40 20 C ..."],
    "lower_viewBox": "0 0 80 100",
    "lower_strokes": ["M 35 30 C ..."]
  }
}
```

Для ъ, ь, ы:

```json
{
  "params": {
    "printed_upper": null,
    "printed_lower": "ъ",
    "has_upper": false,
    "upper_viewBox": null,
    "upper_strokes": null,
    "lower_viewBox": "0 0 80 100",
    "lower_strokes": ["M ..."]
  }
}
```

### Система координат SVG

Единая разлиновка для всех букв:

| Линия | Y-координата |
|-------|-------------|
| Верхняя (cap line) | 10 |
| Верх строчной зоны | 30 |
| Baseline | 80 |
| Нижняя (для хвостов) | 110 |

ViewBox по категориям:
- Строчные без хвостов (а, е, о, и…): `"0 0 80 100"`
- Строчные с хвостами вниз (д, з, у, р, ф, ц, щ): `"0 0 80 120"`
- Заглавные: `"0 0 80 120"`

### Формат штрихов

Массив SVG path строк. Каждая строка — один непрерывный штрих (перо не отрывается). Порядок — порядок написания по прописям.

```json
"lower_strokes": [
  "M 40 30 C 55 20 68 35 62 55 C 56 75 38 82 22 72 C 8 62 12 42 28 36 C 36 33 40 30 40 30",
  "M 62 32 L 62 85"
]
```

### Эталон

SVG-пути создаются по прописям **Нечаевой / Горецкого, 1 класс** (государственный стандарт РФ). Порядок штрихов — строго по методике написания.

### Группы визуального сходства (для дистракторов)

```json
"similarityGroups": [
  ["а", "о", "е", "д"],
  ["и", "у", "н", "ю"],
  ["ш", "щ", "м", "ц"],
  ["б", "в", "ъ", "ь"],
  ["з", "э", "е"],
  ["л", "м", "я"],
  ["р", "ф", "у"],
  ["г", "п", "т", "и"],
  ["к", "х", "ж"],
  ["с", "о", "е"]
]
```

## Режимы

### Режим 1: `sort_case` — «Строчная или заглавная?»

- **Стимул:** одна рукописная буква по центру (случайно верхний или нижний регистр)
- **Ответ:** drag & drop в одну из двух зон: «Заглавные» / «Строчные»
- **Механика:** портирует паттерн `vowel_consonant` (drag с визуальным feedback зоны)
- **Примечание:** буквы ъ, ь, ы появляются только как строчные (нет заглавной)
- **Сессия:** все 33 буквы × 2 формы − 3 (без заглавных ъ/ь/ы) = 63 задачи, перемешанных

### Режим 2a: `match_print_to_written` — «Найди рукописную»

- **Стимул:** крупная печатная буква (А или а)
- **Варианты:** сетка 2×2 — 4 рукописных буквы (правильная + 3 дистрактора)
- **Ответ:** тап по правильной рукописной
- **Дистракторы:** из той же `similarityGroup`, что и целевая буква

### Режим 2b: `match_written_to_print` — «Найди печатную»

- **Стимул:** крупная рукописная буква
- **Варианты:** сетка 2×2 — 4 печатных буквы (правильная + 3 дистрактора)
- **Ответ:** тап по правильной печатной
- **Дистракторы:** печатные буквы из той же группы сходства

### Режим 3: `match_pair` — «Найди пару»

- **Стимул:** рукописная заглавная буква
- **Варианты:** сетка 2×2 — 4 рукописных строчных буквы
- **Ответ:** тап по строчной паре
- **Примечание:** ъ, ь, ы не участвуют (нет заглавной формы)
- **Дистракторы:** строчные из той же группы сходства

## Архитектура

### Файловая структура

```
src/topics/renderers/written_letters/
  index.jsx              ← точка входа, switch по task.type
  engine.js              ← generateTasks() для всех 5 режимов (2a и 2b считаются отдельными)
  SortCaseView.jsx       ← режим sort_case (drag & drop)
  MatchView.jsx          ← режимы match_print_to_written, match_written_to_print, match_pair
  LetterSvg.jsx          ← статичный SVG-рендер из strokes[]
  PrintedLetter.jsx      ← печатная буква (CSS text)
  written_letters.css
```

### `LetterSvg`

Рендерит статичное SVG (без анимации). Принимает `viewBox`, `strokes[]`, `size`. Отображает буквы на фоне с разлиновкой (опционально — для режима demo).

```jsx
<LetterSvg
  viewBox="0 0 80 100"
  strokes={["M 40 30 C ..."]}
  size={120}
  showLines={false}
/>
```

### `MatchView`

Универсальный компонент для режимов 2a, 2b, 3:
- Сверху: стимул (крупно, 160px)
- Снизу: сетка 2×2, каждая ячейка — кнопка с буквой
- Тап → зелёный/красный feedback → `onAdvance()`

### `SortCaseView`

Буква в центре, две зоны снизу. Drag & drop: буква следует за пальцем/мышью, при попадании в зону — highlight, отпустить → проверка. Паттерн из `vowel_consonant/index.jsx`.

### `engine.js`

```js
export function generateTasks(modeType, cards, _sessionSize, params) {
  // cards — массив концептов с params.upper_strokes / lower_strokes
  switch (modeType) {
    case "sort_case":              return generateSortTasks(cards);
    case "match_print_to_written": return generateMatchTasks(cards, params, "print→written");
    case "match_written_to_print": return generateMatchTasks(cards, params, "written→print");
    case "match_pair":             return generatePairTasks(cards, params);
  }
}
```

Дистракторы подбираются через существующий `selectDistractorConceptIds` с `similarityGroups` из topic.json.

## Процесс создания SVG-данных

1. Берём эталонные прописи (Нечаева/Горецкий 1 класс) как референс
2. Рисуем буквы группами по сходству элементов:
   - Группа 1 (овал): **о, а, д, е, э** — 9 начертаний
   - Группа 2 (зубцы): **и, й, н, ю, п, т** — 11 начертаний
   - Группа 3 (дуга): **с, е, ъ, ь, ф** — 8 начертаний
   - Группа 4 (хвост): **у, з, р, ц, щ** — 9 начертаний
   - Группа 5 (прямые): **г, л, м, ш, я, б, в, к, х, ж, ч** — 26 начертаний
3. Каждую букву проверяем визуально в `LetterSvg` на экране
4. Начинаем с 10 приоритетных букв для запуска MVP: **а, о, и, у, е, н, с, т, р, п**

## MVP vs Полная версия

**MVP (итерация 1):** 10 приоритетных букв, режим `sort_case` + `match_pair`. Достаточно для первого занятия.

**Полная версия:** Все 33 буквы, все 5 режимов.
