# Режим «Код от сейфа» (safe_code) — дизайн

Дата: 2026-07-08
Тема: «Инструкция» (`reading_dad_texts`, renderer `src/topics/renderers/reading/`)

## 1. Цель

Игровой тренажёр понимания прочитанного для темы «Инструкция»: ребёнок читает
короткую инструкцию, находит по смыслу **физическую бумажную карточку с
цифрой**, спрятанную родителем/логопедом где-то в квартире, возвращается к
устройству и вводит найденную цифру. После того как все цифры собраны и
подтверждены — сейф открывается и запускается видео-награда.

Ключевое отличие от типового мокапа "виртуальные объекты на экране": весь
физический мир (места хранения, сами цифры) существует только офлайн. Роль
приложения — (1) перед занятием собрать у взрослого информацию о том, что где
спрятано, (2) во время занятия показывать по одной инструкции и принимать
ввод найденной цифры с немедленной проверкой, (3) в конце — открыть сейф и
показать награду.

## 2. Размещение и модель контента

Новый режим `type: "safe_code"` добавляется в манифест существующей темы
`reading_dad_texts` (не новый ZIP/топик). Контентная единица — новый
`text.kind: "safe_code"`, хранящий не готовую загадку, а **фиксированный пул
мест хранения**, используемый только как источник вариантов для настроек:

```json
{
  "id": "safe_code_locations",
  "kind": "safe_code",
  "title": { "ru": "Код от сейфа" },
  "spots": [
    { "id": "pillow",   "label": "Подушка",             "phrase": "под подушкой" },
    { "id": "box",      "label": "Коробка",              "phrase": "в коробке" },
    { "id": "table",    "label": "Стол",                 "phrase": "на столе" },
    { "id": "wardrobe", "label": "Шкаф",                  "phrase": "в шкафу" },
    { "id": "shelf",    "label": "Полка",                 "phrase": "на полке" },
    { "id": "book",     "label": "Книга",                 "phrase": "за книгой" },
    { "id": "carpet",   "label": "Ковёр",                  "phrase": "под ковром" },
    { "id": "sofa",     "label": "Диван",                 "phrase": "под диваном" }
  ]
}
```

- `phrase` — готовая предложная конструкция, подставляемая в шаблон
  инструкции; авторский контроль над формулировками (предлоги в/на/под/за)
  остаётся за генератором контента, а не за свободным вводом.
- Пул расширяемый: пользователь может добавить своё место свободным текстом
  через настройки (см. §3) — такие пользовательские места сохраняются в
  KV-хранилище темы (аналогично `getGroup`/`saveShoppingOrder` в
  `groupStore.js`) и в следующий раз предлагаются в списке выбора наравне со
  встроенными.
- Изображения не нужны — единственная графика режима — визуал самого сейфа с
  клавиатурой.

## 3. Экран настроек перед занятием

Отдельный компонент `SafeCodeParamsContent` (по аналогии с
`InstructionParamsContent.jsx`), открывается по тому же short-circuit
паттерну, что уже применяется для `kind === "instruction"` /
`"shopping_list"` в `TextPickerScreen.jsx` (клик по тексту сразу ведёт в
настройки этого режима, минуя общий `ModePickerScreen`).

Элементы экрана:
- Степпер **codeLength**: 2–5, по умолчанию **3**.
- Список из N строк, каждая — одна позиция кода по порядку:
  **[выбор места: список ▾ / «своё место» → текстовое поле] — [цифра 0-9]**.
- Кнопка **«🎲 Сгенерировать случайные»** — проставляет случайные цифры (по
  умолчанию без явных повторов) во все уже выбранные строки, чтобы взрослый
  мог просто списать получившиеся цифры на бумажные карточки и разложить их
  по дому.
- Кнопка «Начать» активна только когда во всех N строках выбрано место и
  указана цифра.
- Выбранная на этом экране конфигурация (`locations: [{spotId|customLabel,
  phrase, digit}]`) передаётся как `sessionParams` в сессию — она не
  сохраняется между занятиями (каждый раз локации/цифры вводятся заново),
  кроме пользовательских произвольных мест, которые остаются в пуле выбора.

## 4. Экран занятия — раскладка

Три зоны по вертикали (макет подтверждён интерактивным прототипом,
см. обсуждение в диалоге):

1. **Шапка (тонкая, не более прогресс-бара):** сегментный прогресс по
   количеству цифр + трекер кода (`Код: 3 _ _`), текущий пустой слот
   подсвечен акцентным цветом. Стилистически — прямое расширение уже
   существующего `InstructionProgressBar`.
2. **Центр (доминирующий элемент):** текущая инструкция крупным текстом —
   *«Иди и найди {phrase} {порядковое слово} цифру кода.»*, например «Иди и
   найди под подушкой первую цифру кода.» Ниже — место под короткую
   мягкую обратную связь ("Верно! Идём дальше." / "Не подходит — попробуй
   ещё раз."). Это самый заметный элемент экрана, потому что именно чтение
   с пониманием — тренируемый навык, а не ввод кода.
3. **Низ:** цифровая клавиатура 0-9, крупные кнопки, всегда доступна (не
   требует отдельного «Я нашёл!» перед появлением).

Логика по цифре:
- Тап по клавиатуре сверяется с ground-truth цифрой этой позиции
  (введённой взрослым в настройках).
- Верно → слот заполняется, помечается как решённый, прогресс-бар растёт,
  инструкция переключается на следующую позицию. Если это была последняя
  цифра — небольшая пауза и переход к экрану открытия сейфа.
- Неверно → мягкая тряска/подсветка слота, короткая фраза-фидбек, инструкция
  и прогресс не меняются, попытка засчитывается в статистику ошибок.
  Ограничения на число попыток нет.

Финальный экран (после последней верной цифры) — уже не проверка, а чисто
праздничный момент: «Сейф открыт! 🔓🎉» + кнопка запуска видео-награды. Так
как корректность каждой цифры уже была подтверждена по пути, ничего не может
«сорваться» на этом шаге.

## 5. Награда

Переиспользуем существующий `RewardVideoModal` **локальным вызовом из самого
компонента задачи** сразу по открытию сейфа — по паттерну, уже применяемому в
`src/topics/renderers/column_addition/index.jsx` (свой локальный триггер, а
не через общий 5-streak `rewardPending` в `SessionScreen`). Источник видео —
обычный `student.rewardVideos`, никакого отдельного «супер-приз» пула в v1.

## 6. Логирование

Расширяем запись сессии (`computeSessionRecord`/`finishSession` в
`useSessionEngine.js`) полем:

```json
{
  "safeCode": {
    "codeLength": 3,
    "locationIds": ["pillow", "wardrobe", "shelf"],
    "wrongAttempts": 2,
    "elapsedMs": 96000,
    "opened": true
  }
}
```

`wrongAttempts` — суммарное число неверных тапов по клавиатуре за всё
занятие (без привязки к конкретной позиции — этого достаточно для базовой
аналитики "где чаще ошибается").

## 7. Вне рамок v1

- Уровни сложности 2–4 из исходного ТЗ, дистракторы, виртуальные кликабельные
  объекты с раскрытием цифры по тапу (не нужны — цифры физические).
- 4-уровневая система подсказок — оставляем только то, что инструкция не
  исчезает, пока цифра не найдена и не введена верно.
- Отдельный «супер-приз» пул видео, отдельный от обычных наград ученика.
- Ручной ввод/автоподстановка кода как настройка — снято самой механикой
  (ввод всегда пошаговый, через клавиатуру).

## 8. Точки интеграции (для плана реализации)

1. `scripts/generate-reading-safe-code.mjs` — добавляет `text.kind:
   "safe_code"` (пул мест) в манифест `reading_dad_texts`.
2. `src/topics/topicLoader.js` — новый дефолтный mode-объект `safe_code` в
   `DEFAULT_MODES.reading` + запись в `DEFAULT_MODE_METHODOLOGY.reading`.
3. `src/features/home/ModePickerScreen.jsx` — правило фильтрации по
   `text.kind === "safe_code"` (аналогично существующим правилам для
   `instruction`/`story`/`poem`).
4. `src/features/reading/TextPickerScreen.jsx` — short-circuit навигации для
   `kind === "safe_code"` в `SafeCodeParamsContent`.
5. Новый компонент `src/features/reading/SafeCodeParamsContent.jsx` — экран
   настроек (§3), включая KV-хранение пользовательских произвольных мест.
6. `src/topics/renderers/reading/engine.js` — новый `case "safe_code":` в
   `generateTasks`, строящий один task из `sessionParams.locations`.
7. `src/topics/renderers/reading/index.jsx` — новый компонент `SafeCodeTask`
   (три зоны §4), локальный вызов `RewardVideoModal`.
8. `src/features/session/useSessionEngine.js` — расширение `record` полем
   `safeCode` (§6).
