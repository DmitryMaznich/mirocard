# Тренировка закрашивания

Режим `drawing_coloring` темы «Рисование», пакет 0.25.1, приложение 1.1.79.

Занятие — бесконечная последовательность листов до ручного завершения через
штатное меню занятия. Служебный блок из 15 задач не завершает занятие: после
него движок генерирует новые seed и новые листы. Каждая задача — один лист,
один зачёт за выполнение всех фигур. Ошибка учитывается общей системой звёзд
один раз за лист; последующие ошибки дают обратную связь без повторного списания.

На листе несколько фигур со случайными размерами, пропорциями и поворотом.
Генератор размещает их последовательно по фактическим габаритам с промежутками,
пока остаётся место; фиксированного количества фигур нет. Геометрия создаётся
однократно по seed и исходному размеру холста, сохраняется вместе с работой.
На телефоне текущая фигура увеличивается; «Весь лист» показывает общий лист.

В наборе круг, овал, квадрат и прямоугольник (обычные и скруглённые),
треугольник, трапеция, пятиугольник, шестиугольник, яйцо, капля, лист,
сердце, облако, плавная звезда, прямая и волнистая дорожки со скруглёнными концами.
Дорожки получают разные направления; крутизна волн ограничена, чтобы боковые
границы не пересекались. В настройках доступны все фигуры, базовые или дорожки.

## Два этапа

1. Обводка использует `firstLines/curveAttempt.js` и профили `screenProfile`:
   начало с зелёной точки, последовательное движение по светлой дорожке,
   контроль ухода с дорожки и лишних движений. После отрыва нужно продолжить
   от зелёной точки на конце своего следа. Показан фиолетовый ориентир начала,
   к которому нужно вернуться; крайние точки линии должны соприкоснуться.
   Требуется пройти не менее 94% пути (как в «Первых линиях») **и замкнуть
   линию**. Заранее нарисованного тонкого контура нет ни при обводке, ни при
   закрашивании: виден только след ребёнка. Незавершённая обводка старого
   формата начинается заново; готовая обводка/закраска сохраняется.
2. Закрашивание: рисование настоящей кистью, без автоматического заполнения
   и без обрезания следа по контуру. Учитывается объединение закрашенных
   участков **только внутри фигуры**; повторный проход не добавляет площадь.
   Обводка хранится отдельно и в закрашенную площадь не входит.

Выходы проверяются по расстоянию до ближайшего участка контура, включая край
кисти и её круглые концы. Площадь снаружи не оценивается. Взрослый выбирает
допуск 0–16 CSS px (по умолчанию 6) и заполнение 50–100% (по умолчанию 90%).
Допуск и кисть компенсируют масштаб экрана. Внутренняя площадь измеряется маской
с шагом 2 единицы исходного листа; край кисти проверяется с дискретизацией
окружности в 24 точки, перемещения — с шагом не более 2 единиц.

При выходе за допуск текущий этап сбрасывается целиком, рисование блокируется
до отрыва. При обводке очищается весь её след и весь прогресс контура. При
закрашивании очищаются все штрихи закраски и внутренняя маска, процент
возвращается к нулю; готовый контур остаётся. Предыдущие готовые фигуры
сохраняются. После отрыва этап выполняется заново. Сброс сохраняется сразу
при ошибке, даже до отрыва или перезагрузки. Завершение этапа происходит только после отрыва. Отмена жеста,
потеря контекста, скрытие страницы и поворот не засчитываются как ошибка.

Прогресс, геометрия, обводка, штрихи закраски, внутренняя маска и первая ошибка
сохраняются локально при отрыве/скрытии страницы. Хранятся последние 12 листов.
Звёзды и результаты занятия сохраняются штатным механизмом сессии.

## Проверка

```sh
node tools/drawing/build.mjs
npx vitest run src/topics/renderers/drawing/coloring src/topics/renderers/drawing/drawing.test.js
npx eslint src/topics/renderers/drawing/coloring tools/drawing/check-coloring.mjs
npm run build
npm run dev
node tools/drawing/check-coloring.mjs
```

Стенд реального ZIP и сессии:
`/tools/drawing/first-lines-preview.html?fresh&coloring&noVideo`.
Параметры стенда: `touch`, `passive`, `figures=basic|paths`, `tolerance=6`, `fill=90`.
Браузерная проверка проходит обводку и закраску реальной фигуры, ошибку,
перезагрузку, 16 листов с переходом через генерацию нового блока, дорожки
на телефоне, обзор и поворот. Снимки — в `output/drawing-coloring/`.
На целевом планшете остаётся проверить ощущение кисти и удобство с ребёнком.

В 0.22.1 исправлен обрыв штриха при обновлении родительского экрана: сессия
создаёт новый объект параметров, но при прежних значениях инструмент и активный
штрих сохраняются. Проверяется движение туда-обратно между отдельными кадрами,
несколько штрихов с отрывом и обновления экрана при удерживаемом указателе.

В 0.22.3 добавлена «Толщина пера»: 3/6/10/16/24/32 CSS px для обводки
и закрашивания. «По способу ввода» сохраняет прежние автоматические размеры.
Ширина компенсирует масштаб; площадь и допустимый выход используют ту же
кисть, которая видна на экране. Выбор понятий в настройках этого режима скрыт.

В 0.24.0 толщина, допуск и заполнение настроены ползунками с числом
и живым графическим образцом: круг/штрих, полоса за границей и заполненная
фигура. Толщина 1–32 CSS px (по умолчанию 12), допуск 0–16 CSS px, заполнение
50–100%, шаг 1. Прежнее сохранённое «auto» сохраняет автоматическую толщину
до первого изменения ползунка. UI: `DrawingColoringSlider` в настройках сессии.

В 0.25.0 на этапе закрашивания в верхней панели показаны пять цветных
карандашей. Выбор одним нажатием; активный карандаш приподнят, обведён
и отмечен галочкой. Во время обводки, обзора и после завершения палитра скрыта.
Размер кнопок не меньше 44×44 CSS px, включая экран 320 px. Во время штриха
цвет менять нельзя. Каждый новый штрих хранит свой цвет; выбор не перекрашивает
предыдущие линии и не меняет оценку площади. Цвет восстанавливается вместе
с листом и запоминается для следующего листа/занятия ребёнка. Старые штрихи
без цвета отображаются прежним голубым. Контур сохраняет прежний цвет.

В 0.25.1 направляющая от зелёной точки увеличена с 24 до 48 CSS px.
На конце — два открытых штриха-крылышка, без заливки треугольником;
стрелка следует касательной к дорожке и сохраняет размер при увеличении.
