# «Мои люди» (my_people) — методический и дизайн-разбор режимов

Начат 2026-10-15. Разбор сделан по коду (`src/topics/builtinMyPeopleTopic.js`,
`src/topics/renderers/my_people/engine.js`, `index.jsx`), скриншотов ещё не было —
визуальную часть нужно подтвердить на экране перед правками.

Тема встроенная (`builtin: true`), deck-zip нет: правки рендерера и движка едут
обычным bump `package.json` + push.

## Сейчас: 11 режимов

`about_me`, `show_me`, `family_names`, `family_relations`, `home_names`,
`home_relations`, `school_names`, `school_relations`, `mix`, `who_is_this`,
`introduce_self` — в таком порядке они и стоят на экране выбора режима.

## Найденные ошибки (чинить в первую очередь)

1. **«Кто это?» пуст для ребёнка, который не читает.** `personNamingTasks` берёт
   только людей с `introducedAxes`, а знакомство (`person_intro` →
   `markPersonAxisIntroduced`) живёт только в режимах-альбомах, где нужно читать.
   Ребёнок, который проходит только «Покажи», никогда не получит «Кто это?».
   Решение: верный ответ в «Покажи» (или отдельный экран знакомства там же)
   тоже отмечает человека знакомым.
2. **В альбомах тап по слову не работает с тач-экрана.** Выбор слова и тап по фото
   есть только с клавиатуры (Enter/Space); `pointerdown` сразу начинает drag, а
   `pointerup` без фото под пальцем ничего не делает. Для детей с моторными
   трудностями перетаскивание — отдельный барьер. Нужен полноценный «тап-тап».
3. **«Покажи» игнорирует поле «как ребёнок называет».** В настройках есть
   `sentenceLabel` («мама», «дядя Коля»), а `mainWord()` угадывает слово по
   списку `KIN_WORDS`. Получается «Где Николай?» вместо «Где дядя Коля?».
   Одно поле — один источник: брать `sentenceLabel`, если он задан.
4. **Оценка после подсказки.** В «Обо мне» после «Показать фото/ответ» взрослый
   всё ещё может нажать «Знает». После любой подсказки «Знает» должна быть
   недоступна (максимум — «С подсказкой»), иначе статистика врёт.
5. `about.flow` темы описывает только альбомы — устарел.

## Методика: порядок навыков

Правильная лестница для РАС/ЗПР: узнать (рецептивно) → назвать (экспрессивно) →
ответить о себе → подписать (чтение) → рассказать о себе связно.
Сейчас «Обо мне» стоит первым, «Кто это?» — после шести режимов с чтением.

## Режимы: оставить / поправить / убрать / добавить

### «Покажи» — оставить, поправить
Сильное: нет чтения, поле 2 по умолчанию, безошибочное исправление ошибки
(«Вот мама»), разные фото одного человека.
Поправить:
- Раунд = каждый человек один раз. При 2–3 людях это 2–3 пробы — слишком коротко.
  Минимум 6 проб, цели повторяются, не больше 2 одинаковых подряд, цель не стоит
  на одном месте больше 2 раз подряд (иначе ребёнок учится позиции, а не лицу).
- Дистракторы сейчас случайные. На старте — максимально непохожий (питомец vs
  взрослый, мужчина vs женщина), позже — похожие.
- Добавить поле 1 («Это мама. Покажи маму») — безошибочный вход для самых младших.

### «Кто это?» — оставить, поправить, поднять в списке на 2-е место
- Чинить ошибку №1.
- Принимаются оба ответа («мама» и «Анна»), но показывается один — взрослого это
  сбивает. Показывать модель «мама · Анна».
- Добавить ту же лестницу подсказок, что в «Обо мне»: «Первый звук» → «Показать
  ответ» (озвучить для эха). Единый паттерн во всей теме.

### «Обо мне» — оставить, поправить
Сильное: короткие фиксированные вопросы, лестница подсказок, вопросы строятся
только из заполненных данных.
Поправить:
- «Ты мальчик или девочка?» — у ребёнка с эхолалией повторяется последнее слово
  вопроса. Чередовать порядок вариантов между раундами.
- «Сколько тебе лет?» без визуальной опоры — подсказкой показывать цифру + пальцы.
- Для неговорящих: опция ответа выбором из 2 карточек (фото/цифра/слово).
  Сейчас AAC упомянут только в «Представься».

### Альбомы (6 режимов + «Все люди») — схлопнуть в один режим
Шесть режимов «круг × ось» плюс `mix` перегружают экран выбора, а «Семья» vs
«Люди дома» взрослому неочевидны. Один режим **«Подпиши фото»** с параметрами:
круг (семья / дома / школа / все) и что подписываем (кто это / имена / сначала
одно, потом другое). Старые `mode.id` сохранить как алиасы для истории.
Поправить внутри:
- Для семьи сначала «кто это» (мама), потом имена — имя мамы сложнее роли.
  Для школы наоборот: ребёнок знает «Марию Ивановну», а не «учительницу».
- Размеры альбома 2/4/6/8 → 2/3/4/6. Восемь слов на экране для этой группы детей
  — перебор; 3 вёрстка уже поддерживает.
- Ошибка: сейчас только тряска. Как в «Покажи» — после промаха подсветить
  правильное фото.
- Экран знакомства пассивный (кнопка «Дальше»). Пусть ребёнок сам тапает по фото —
  это первая безошибочная проба, а «Дальше» оставить взрослому мелко.

### «Представься» — оставить как продвинутый, переписать
Ситуации абстрактные («у твоей работы на выставке есть карточка») и требуют
понимания чужой перспективы; фраза «Наша семья — семья Петровых» неестественна.
Сделать диалог: фото незнакомого взрослого + «Привет! Как тебя зовут?» →
«А сколько тебе лет?» → …, ответ из тех же фактов, что «Обо мне». Подсказка —
угасающий скрипт (полный текст → пропуски слов → только первое слово).

### Добавить (позже)
- **«Найди такого же»**: сопоставление двух разных фото одного человека. Шаг до
  «Покажи» для ребёнка, который ещё не реагирует на слово, и прямая тренировка
  переноса между фотографиями.

## Итоговый список режимов (предложение)

1. Покажи
2. Кто это?
3. Обо мне
4. Подпиши фото (параметры: круг, что подписываем)
5. Представься
(+ позже «Найди такого же» перед «Покажи»)
