# «Учим словенский» — методика и план темы

Начато 2026-10-22. Новая тема для сына владельца: ребёнок с РАС, слабовербальный, родной
язык русский (понимает много, говорит плохо), живёт в Словении и ходит в словенскую
коррекционную школу. По-словенски понимает набор команд и слов на слух, не читает и не пишет;
по-русски пишет письменные буквы.

Макеты режима 1 (холст, 9 экранов): https://claude.ai/artifact/TnUNuAQMGBvdtcTr7osMnw

Это **не** словенская локализация приложения (`docs/localization/`, `comparison_language_pilot`):
там переводится интерфейс для словенского рынка. Здесь словенский — учебный материал.

## 1. Опора из исследований (кратко)

- Двуязычие не вредит детям с РАС (Hambly & Fombonne 2012; Drysdale и соавт. 2015;
  Gonzalez-Barrero & Nadig 2018). Отказ от родного языка вредит общению в семье
  (Kremer-Sadlik 2005). Дома остаётся русский.
- Навык чтения переносится между языками (гипотеза взаимозависимости Каммингса).
- Неговорящих детей учат читать с ответом выбором, без требования говорить (ALL, Light & McNaughton).
- Словенская орфография прозрачная: с ней учатся декодировать быстрее (Seymour и соавт. 2003).
- Словенский — славянский язык: когнаты (voda, roka, sok, mleko…) облегчают запоминание.
- Кириллица и латиница опасны буквами-ловушками B, C, H, P (сербские исследования,
  Lukatela, Turvey и соавт.).

## 2. Лестница тем (общий план, режимы 2+ ещё не проработаны)

| № | Режим | Суть |
|---|---|---|
| 1 | **Одна вещь — два слова** (этот документ) | Слушание: русское слово → словенское, выбор картинки |
| 2 | Слушаю по-словенски | Словенское слово → картинка, без русского, некогнаты |
| 3 | Моё слово | Глобальное чтение: имя, WC, MALICA, надписи школы |
| 4 | Звук → буква | Порядок групп: «друзья» A E K M O T → новые → «шапочки» Č Š Ž → ловушки B C H P последними |
| 5 | Как это по-русски | Сопоставление букв **по звуку**, не по виду |
| 6–9 | Слоги, сборка слова, письмо ВЕЛИКИМИ ПЕЧАТНЫМИ, чтение школьных фраз | |

Правила для всей темы: буквы не по алфавиту; кириллица и латиница никогда в одном слове или
строке; словенский пишем печатными заглавными (русский — прописью, это разводит языки);
только звуки, не названия букв; ответ по-русски в словенском задании — не ошибка.

## 3. Режим 1 «Одна вещь — два слова»

**Цель:** «у одной вещи два названия: домашнее и школьное»; понимание словенского слова на
слух с опорой на русское. Русское слово — подсказка, которую постепенно убирают.

**Постоянная раскладка экрана:** слева «дом» (тёплая оранжевая рамка, фото дома ученика,
русский голос), справа «школа» (синяя рамка, фото школы, словенский голос). Места не меняются
никогда. Флагов нет. Фото дома и школы загружает взрослый в настройках ученика; без них —
нарисованные значки. Говорящий светится, пока звучит его слово.

**Ступени:**

| | Что звучит | Картинок | Ошибка |
|---|---|---|---|
| А | История из 3 экранов голосом папы: «Дома мы говорим по-русски / В школе говорят по-словенски / Одна вещь — два слова». Один раз, можно пропустить | — | нет |
| Б | «яблоко» (дом) → 0,7 с → «jabolko» (школа); касание картинки — дальше | 1 | нет |
| В | оба слова, потом выбор | 2 | почти нет |
| Г | только «jabolko»; при затруднении — подсказки | 2 | да |
| Д | только словенское; русское — только после ошибки | 3 | да |

**Цепочка подсказок (Г, Д):** 5 с → повтор словенского → 5 с → русское слово, рамка дома
светится → 5 с → нужная картинка растёт, остальные бледнеют. Задержка настраивается (3/5/8 с).

**Ошибка:** неверная картинка бледнеет; без красного и резкого звука; звучит пара
«voda — вода», правильная подсвечена, ребёнок касается её сам; слово возвращается через
2–3 задания в другой раскладке. **Верно:** картинка растёт, звёздочка, пара «voda — вода».
Без голосовой похвалы: третий голос ломает пару.

**Учёт:** по каждому слову — сам / с повтором / с русской подсказкой / с выделением.
Освоено: 3 занятия подряд сам на ступени Д. Переход между ступенями предлагается взрослому
(В→Г: два уверенных занятия; Г→Д: 80% сам). Занятие 5–6 заданий (мотивация низкая).

**Отвлекающие картинки:** другая ситуация, другой первый звук, уже знакомый предмет;
правильная — на случайном месте; stol и miza никогда в одном задании.

**Картинки:** настоящие фото, 2–3 на слово, чистый фон, без текста (против сверхизбирательности
— та же логика, что `docs/verbs-photo-shotlist.md`).

**Взрослый:** ступень; галочки «понимает по-русски» (по умолчанию все включены, снимаются
незнакомые); задержка подсказки; число заданий; подписи под картинкой (выкл.; русская — в тёплой
зоне, словенская ВЕЛИКИМИ — в синей); фото дома и школы; прогресс по словам; лист для
учительницы (PDF, по-словенски); отметка «узнал в жизни».

**Носитель-проверяющий** ставит приложение и слушает все слова в нём. Нужен экран
«Прослушать все слова» (список, кнопка проигрывания русского и словенского).

## 4. Словарь (школьные ситуации, в этом порядке)

⭐ почти как по-русски, ◐ похоже, ○ другое слово.

1. **Malica:** voda⭐ sok⭐ čaj⭐ jabolko◐ banana◐ hruška◐ mleko◐ sir◐ — потом kruh○ malica○
2. **Тело:** nos⭐ uho⭐ noga⭐ roke◐
3. **В классе:** šola⭐ knjiga◐ miza○ zvezek○ svinčnik○ barvice○ škarje○ lepilo○ tabla○ torba○
4. **Раздевалка, двор:** copati○ jakna○ kapa○ čevlji○ žoga○ avtobus◐
5. **stol** (стул) — ложный друг «стол»; позже, никогда рядом с картинкой стола.

Исключены: mama (это «говорящий»), oko (ребёнок говорит «глаз»), jagoda, слова, которых
ребёнок не знает по-русски. Для чтения позже избегать конечных L/V ([u̯]) и безударного E.

1. ✅ Название: «Учим словенский». Фото — школы. Голос — ElevenLabs + носитель.
2. ✅ Проба голоса (4 голоса × 5 слов).
3. ✅ Голос выбран владельцем 2026-10-22: **Ana** (`XGfMwCpKmpWdTb1sermJ`). Носитель проверяет уже готовые записи.
4. Озвучка: ~40 словенских + ~40 русских слов + 3 фразы истории. ✅ Набор Malica (8+8) записан 2026-10-22: `tools/learn_slovene/audio/{sl,ru}/<id>.mp3`, обработка `process-audio.mjs` (срезание щелчка выключено: ело начало «hruška», «груша», «чай», «молоко»).
5. Проверка носителем в приложении, перезапись плохих.
6. Картинки: фотобанки закрыты в облачной среде, владелец выбрал генерацию Gemini (`generate-photos.mjs`, `candidates/` не в git). ✅ Malica: по 3 на слово отобраны с владельцем → `tools/learn_slovene/media/<id>_<1..3>.webp`; отвлекающие не из еды — zoga, knjiga, cevlji, svincnik, kapa, skarje (1–2 шт.). Не брать: пачку сока без надписей (похожа на молоко), чай в прозрачной кружке без пара (похож на сок), белый пакет молока.
7. Значки «дом» и «школа» по умолчанию.

**Этап 2 — движок** (отдельный рендерер, условно `bilingual_words`, своя CSS):
две записи на карточку и проигрывание по очереди с подсветкой; рамки «дом»/«школа» с фото
ученика (безопасные зоны iOS); цепочка подсказок по таймеру; подбор отвлекающих; освоение по
словам и подсказка о переходе; экран взрослого; «Прослушать все слова»; история; лист для учительницы.

**Этап 3 — выпуск:** тесты, снимки (планшет, iPhone с safe-area), ZIP темы, каталог со
статусом `individual`, версия, деплой.

**Порядок:** сначала проба на ребёнке — набор Malica (8 слов), ступени Б–Д, без истории и
сложного учёта; 1–2 недели наблюдения; потом остальное; потом режим 2.

## 8. Что сделано в коде (v0.1.0, 2026-10-22)

Тема `learn_slovene` (рендерер `bilingual_words`), статус `individual`. Первая проба: набор Malica.

| Файл | Что |
|---|---|
| `src/topics/renderers/bilingual_words/engine.js` | задания: `bw_pair` (режим 1), `bw_find` (2–4: `mode.audioOrder` `ru_sl`/`sl`, `mode.optionCount` 2/3), `bw_listen_all`. Отвлекающие — в `mode.distractors` (не в `cards`, иначе выбор слов взрослым их отфильтрует): другая ситуация (`group`), другой первый звук, `neverWith` (stol/miza) |
| `FindTask.jsx` | цепочка подсказок по таймеру (повтор → русское → выделение), ошибка без звука: бледнеет, показ ответа + пара; ответ после русской подсказки/выделения/ошибки → `onCorrect(..., { assisted: true })`; ошибка → `onStreakReset` |
| `PairTask.jsx`, `ListenAllTask.jsx`, `SpeakerTile.jsx`, `useSpeakers.js` | показ пары; «Прослушать все слова» для носителя; рамки дом/школа; последовательное проигрывание с отменой |
| `src/features/session/SessionScreen.jsx` | `bw_pair`, `bw_find` в `OWNS_FEEDBACK_TYPES`: без общего звонка «правильно/неправильно» |
| `tools/learn_slovene/build.mjs` | `words.json` → `topic.json` + ZIP (проверяет, что все файлы на месте) |

Режимы в приложении: «1. Показ пары» (= ступень Б), «2. Найди: оба слова» (В), «3. Найди по-словенски» (Г),
«4. Три картинки» (Д), «Прослушать все слова». Выбор слов — обычный «Изменить» (это и есть галочки «понимает по-русски»).

**Пока не сделано (после пробы):** история «дом / школа» (ступень А); фото дома и школы ученика (сейчас нарисованные
значки); учёт освоения по словам между занятиями и подсказка о переходе; повтор слова через 2–3 задания после ошибки;
лист для учительницы; остальные наборы слов.

Проверено: тесты `engine.test.js`, `renderer.smoke.test.jsx`; снимки (Playwright, планшет 1024×700, iPhone 390×700 и
844×330 с безопасными зонами). Подвох: `padding: 5%` у карточки считается от ширины ряда, а не карточки — отступ через `--bw-opt`.
