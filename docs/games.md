# Игры: гонки с физическими кубиками

Встроенная тема `games` открывает библиотеку с играми «Гонки», «До облаков» и
«Налей до отметки».
Новые игры добавляются в эту же библиотеку.
Исходный макет согласован с владельцем в разговоре 2026-11-06.

## Правила первой версии

- Перед первым броском и между ходами два декоративных объёмных кубика катятся,
  вращаются и подпрыгивают. Они ждут столько, сколько нужно для физических бросков.
  Нажатие «Кубики брошены» или на область анимации останавливает её и открывает ввод.
  Показанные грани никогда не становятся результатами: оба числа вводятся вручную.
- Анимация появляется после завершения последнего шага машинок, а не поверх него.
  Пауза останавливает и движение машинок, и анимацию кубиков. При системном
  уменьшении движения кубики статичны, порядок игры тот же.
- Ребёнок и взрослый бросают настоящие кубики 1–6. Приложение кубики не бросает.
- Введите оба числа. Ребёнок отвечает на вопрос «Кто едет дальше?» тремя кнопками
  «Я», «Папа» (или выбранное имя взрослого), «Одинаково». Кнопки оформлены как
  текстовые ответы в режиме «Сравни в жизни», без знаков и буквенных значков.
- Верный ответ автоматически запускает обе машинки. Отдельной кнопки движения нет;
  крупные кубики только показывают числа. При неверном ответе можно попробовать
  снова; прогресс машинок не меняется. Ответы и ввод блокируются на время движения.
- Каждая машинка продвигается на своё число шагов; сравнение не отнимает ход.
- Старт — 0, финиш — 19. За три броска можно набрать максимум 18, поэтому
  каждый игрок сделает минимум четыре броска. Достаточно дойти или перейти
  финиш; точного попадания не требуется.
- Результат определяется после обоих перемещений. Дошли оба в одном раунде — ничья.
- Победа ребёнка или ничья открывает существующее призовое окно с его видео.
  Победа взрослого показывает результат без видео. Дополнительной награды взрослому нет.
  Правило ничьей сохранено из предложенного и принятого варианта гонки.
- Видео, его длительность и случайный выбор берутся из существующей системы.
  Настройки и список видео фиксируются при открытии игры; второй раз за ту же
  победу призовое окно не открывается.
- Имя ребёнка — из активного профиля. Имя взрослого можно поменять перед стартом
  (например, на «Мама» или имя специалиста); отдельного профиля взрослого нет.
- Пауза останавливает перемещение. Выход из незавершённой гонки — через паузу.
  Перезагрузка страницы сбрасывает партию. Гонки не создают статистику учебных
  сессий и не изменяют звёзды обычных занятий.

## Интеграция

- `src/topics/builtinGamesTopic.js`, `builtinTopics.js`, `builtinAssets.js` — встроенная тема.
- `src/features/games/GamesHome.jsx` — библиотека, открывается через `ModePickerScreen`.
- `src/features/games/GamesScreen.jsx` — подготовка и партия, открывается через `ParamsRoute`.
- `src/features/games/raceEngine.js` — чистые правила и переходы состояния.
- `scripts/build-topic-inventory.mjs` — тема включена в серверную административную ведомость.
- Страница заполняет экран и учитывает существующие `--app-safe-*` отступы.
  Горизонтальный экран — основной; вертикальный имеет компактную раскладку.

## Проверка

```sh
npx vitest run src/features/games/raceEngine.test.js --maxWorkers=2
npx playwright test -c tests/responsive/games.playwright.config.mjs
npm run build
```

Браузерная проверка использует настоящий экран игры с тестовым учеником и
проверяет ввод, сравнение, паузу, оба результата, ничью, однократную выдачу приза
и раскладку на четырёх размерах с безопасными отступами. YouTube в ней не
воспроизводится; таймер и воспроизведение покрыты тестами общего `RewardVideoModal`.

Для ручной проверки: `npm run dev`, затем `/tests/responsive/games.html`.

## До облаков (`skyscrapers`, тема 1.1.0)

Вторая игра использует тот же ввод физических кубиков, анимацию ожидания,
профиль ребёнка, имя взрослого, правила сравнения, паузу и призовое видео.
Вопрос — «Кто построит больше этажей?», ответы — «Я», введённое имя, «Одинаково».
Каждый строит своё выпавшее число этажей. Победа на 20 этажах; точного попадания
не требуется, выше 20 строить нельзя. Ничья определяется по полному раунду.

- `TowerScene.jsx` — SVG-сцена, два одинаковых внешних крана, башни, жильцы,
  отдельная анимация установки каждого этажа. Кран поднимает готовый блок,
  переносит над крышей, опускает, освобождает крюк и возвращается за следующим.
  Оба крана работают параллельно. Завершивший своё число этажей кран ждёт другого.
- Этажи появляются строго после завершения цикла крана. `requestAnimationFrame`
  останавливается на паузе и продолжает с сохранённого места, без двойного зачёта.
  После последнего этажа есть короткая сцена с флагом и радугой до призового окна.
- Балконы на чётных этажах: 2-й слева, 4-й справа и так далее. Жильцы коротко
  машут рукой при заселении, затем остаются неподвижными.
- `towerGeometry.js` — одна координатная сетка для пола, этажей, облаков, стрел,
  тросов и строп. Стрелы обоих кранов на одной высоте и доходят до центров башен.
  Для 19-го и 20-го этажей остаётся запас под подвешенный блок и стропы.
- Общий `raceEngine.js` принимает целевое число: 19 для гонки, 20 для стройки.
  При достижении лимита лишние блоки не создаются; пустые циклы крана пропускаются.
- При уменьшении движения декоративные эффекты отключены, монтаж сокращён;
  число этажей, правила, ввод и награды не меняются.

Дополнительные проверки:

```sh
npx vitest run src/features/games/towerGeometry.test.js src/features/games/raceEngine.test.js --maxWorkers=2
npx playwright test -c tests/responsive/towers.playwright.config.mjs
```

Геометрия проверяется на всех 20 этажах для обоих кранов, в 101 точке цикла.
Браузер проверяет настоящий монтаж 19-го и 20-го этажей, лимит 20, паузу,
чередование балконов, ничью с видео, победу взрослого без видео, повторную игру
и раскладку на планшете и телефоне. Существующая гонка проверяется отдельно.

## Налей до отметки (`water_fill`, тема 1.2.0)

Третья игра: два персонажа придерживают одинаковые стаканы одной рукой и
открывают свой кран другой. Перед стартом каждому выбирают персонажа (мальчик,
девочка, мужчина, женщина). Имя второго игрока независимо от персонажа задаёт
подпись на кнопке ответа. Выбор и имя сохраняются на повторную партию, без
новых глобальных настроек и без отдельного профиля взрослого.

- Вопрос — «Кто нальёт больше воды?», ответы — «Я», введённое имя, «Одинаково».
  Неверный ответ не запускает воду. Верный автоматически запускает оба крана.
- Один пункт кубика — одна равная порция. Одинаковые ширина стаканов и струй,
  один масштаб и высота основания: уровень линейно соответствует объёму.
  Больший бросок продлевает наливание. Кран с меньшим броском закрывается раньше.
- Цель — линия 20. В отличие от стройки, последняя порция не обрезается:
  над линией есть запас. Из 19 максимум получается 25; внутренняя вместимость
  26 порций оставляет ещё запас ниже края. Счётчик `20 / 20` показывает достижение
  цели, фактический уровень воды может быть выше линии. Результат — после обоих
  полных бросков и закрытия ручек; ничья, если оба достигли линии в одном раунде.
- `waterGeometry.js` — единая шкала, объёмы и состояние потока. `WaterScene.jsx`
  — персонажи, краны, прозрачные стаканы, струя, пузырьки, блики и кивок после
  наливания. Анимация использует RAF; пауза сохраняет её текущую точку.
- `WaterCharacters.jsx` — выбор на стартовом экране. Профиль девочки предлагает
  персонажа-девочку; исходный второй персонаж — мужчина, выбор свободный.
- Общий движок принимает отдельные целевой уровень, вместимость и отложенный
  результат. Гонки и стройка сохраняют свои прежние жёсткие ограничения.
- Повторяются прежние катающиеся кубики, случайный видеоприз ребёнка и его
  длительность. Взрослый выигрывает без видео; победа ребёнка и ничья дают приз.

```sh
npx vitest run src/features/games/waterGeometry.test.js src/features/games/raceEngine.test.js src/features/games/towerGeometry.test.js --maxWorkers=2
npx playwright test -c tests/responsive/water.playwright.config.mjs
```

Проверки: равные порции и ёмкости, последний бросок 19+6 без перелива, пауза,
обе полные подачи до результата, ручки закрыты до видеоприза, выбор персонажей,
повторная партия, победа взрослого без видео и четыре размера экрана. Гонки и
стройка проверяются своими браузерными наборами после изменения общего движка.
