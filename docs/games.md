# Игры: гонки с физическими кубиками

Первая игра в отдельной встроенной теме `games`. Тема открывает библиотеку игр,
пока с одной карточкой «Гонки». Новые игры добавляются в эту же библиотеку.
Исходный макет согласован с владельцем в разговоре 2026-11-06.

## Правила первой версии

- Ребёнок и взрослый бросают настоящие кубики 1–6. Приложение кубики не бросает.
- Введите оба числа, выберите, у кого больше (или «Поровну»), нажмите «Поехали».
  При неверном сравнении можно попробовать снова; прогресс машинок не меняется.
- Каждая машинка продвигается на своё число шагов; сравнение не отнимает ход.
- Старт — 0, финиш — 19. За три броска можно набрать максимум 18, поэтому
  каждый игрок сделает минимум четыре броска. Достаточно дойти или перейти
  финиш; точного попадания не требуется.
- Результат определяется после обоих перемещений. Дошли оба в одном раунде — ничья.
- Победа ребёнка или ничья открывает существующее призовое окно с его видео.
  Победа взрослого показывает результат без видео. Дополнительной награды взрослому нет.
  Правило ничьей сохранено из предложенного и принятого варианта гонки.
- Видео, его длительность и случайный выбор берутся из существующей системы.
  Настройки и список видео фиксируются при открытии игры; второй раз за ту же
  победу призовое окно не открывается.
- Имя ребёнка — из активного профиля. Имя взрослого можно поменять перед стартом
  (например, на «Мама» или имя специалиста); отдельного профиля взрослого нет.
- Пауза останавливает перемещение. Выход из незавершённой гонки — через паузу.
  Перезагрузка страницы сбрасывает партию. Гонки не создают статистику учебных
  сессий и не изменяют звёзды обычных занятий.

## Интеграция

- `src/topics/builtinGamesTopic.js`, `builtinTopics.js`, `builtinAssets.js` — встроенная тема.
- `src/features/games/GamesHome.jsx` — библиотека, открывается через `ModePickerScreen`.
- `src/features/games/GamesScreen.jsx` — подготовка и партия, открывается через `ParamsRoute`.
- `src/features/games/raceEngine.js` — чистые правила и переходы состояния.
- `scripts/build-topic-inventory.mjs` — тема включена в серверную административную ведомость.
- Страница заполняет экран и учитывает существующие `--app-safe-*` отступы.
  Горизонтальный экран — основной; вертикальный имеет компактную раскладку.

## Проверка

```sh
npx vitest run src/features/games/raceEngine.test.js --maxWorkers=2
npx playwright test -c tests/responsive/games.playwright.config.mjs
npm run build
```

Браузерная проверка использует настоящий экран игры с тестовым учеником и
проверяет ввод, сравнение, паузу, оба результата, ничью, однократную выдачу приза
и раскладку на четырёх размерах с безопасными отступами. YouTube в ней не
воспроизводится; таймер и воспроизведение покрыты тестами общего `RewardVideoModal`.

Для ручной проверки: `npm run dev`, затем `/tests/responsive/games.html`.
