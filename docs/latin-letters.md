# «Латиница» (latin_letters) — новая тема, проектирование (начато 2026-11-07)

Тема для тех, кто учит детей писать латиницей: печатные буквы и школьный курсив, тетради для
печати и письмо на экране. Первая аудитория — русскоязычные родители и педагоги детей, которые
учат английский; цель — со временем покрыть основные школьные стили латиницы.

## Решения владельца

- **Отдельная тема**, не язык и не стиль внутри `propis2` или `print_letters` (2026-11-07).
- Начинаем с **английского алфавита**; другие языки латиницы (диакритика) — позже, данными.
- Цель — «исчерпывающая» тема, то есть библиотека стилей, а не одна пропись.

## Предложено, ждёт подтверждения владельца

### Стили — это данные, а не код

Школьных образцов латиницы десятки (США: Zaner-Bloser, D'Nealian, Handwriting Without Tears;
Великобритания: Nelson, Letter-join, Penpals, Twinkl; Австралия — свой шрифт почти в каждом
штате; Германия, Франция, Италия, Польша, Чехия, Словения, Скандинавия…), но по форме они
сводятся к ~5 семействам:

| Семейство | Признаки | Примеры |
|---|---|---|
| 1. Прямая печатная | вертикальные буквы, без хвостов | ZB manuscript, HWT |
| 2. Печатная с выходами (pre-cursive) | лёгкий наклон, хвостики-выходы | D'Nealian, Twinkl/Sassoon, австралийские foundation |
| 3. Петлевой наклонный курсив | петли, рукописные заглавные | ZB cursive, Palmer, Франция, Италия, Польша, российские школьные английские прописи |
| 4. Связное письмо без петель | соединения без петель, заглавные почти печатные | Nelson, Letter-join, австралийские cursive, Vereinfachte Ausgangsschrift |
| 5. Italic | овальные клинья, частичные соединения | Getty-Dubay, отчасти Скандинавия |

Внутри семейства стили отличаются отдельными буквами (f, k, r, z, петли у b/l), наклоном,
правилами разрывов. Поэтому: **один движок; стиль = набор глифов + правила соединений +
разлиновка + наклон; алфавит = данные** (тот же принцип, что у `propis2`: буквы никогда не
захардкожены строкой).

### Порядок стилей

1. **Печатная латиница** (семейство 1, опция хвостиков из семейства 2) — принимается везде.
2. **Российский школьный английский курсив** (семейство 3): петли, наклон, четырёхлинейка.
   Образцы — из российских прописей (к УМК Spotlight и др.), не из американских: по форме он
   близок к ZB cursive, но не совпадает.
3. Под англоязычный рынок: британское связное (семейство 4) и D'Nealian (семейство 2).

Дорогая часть — не код, а буквы: 52 глифа на стиль с порядком штрихов, входами/выходами и
соединениями, каждый сверяется с владельцем. Реалистично 1–2 стиля за заход.

### Чем отличается от соседних тем и что можно переиспользовать

- `print_letters` — только кириллица, только заглавные, буквы на клетке (2 клетки высотой).
  Латинице нужны строчные с верхними и нижними выносными (b d h k l / g j p q y) и
  **английская четырёхлинейная разлиновка** — это другая геометрия строки. Конструктор
  тетрадей, PDF, «Пишу на экране», «Почини букву» — механики, которые стоит повторить.
- `propis2` (+ общий движок в `src/topics/renderers/propis/`) — курсив с соединениями; основа
  для стиля 2.
- `letter_writing` — не трогать (независимая тема).

Предложение: **импортировать** общие модули из `print_letters`/`propis` (как `propis2` импортирует
движок `propis`), а не копировать, как `print_letters` скопировал редактор `propis2` — копия
разъезжается при каждой правке.

### Права

Начертания букв как таковые обычно не охраняются, шрифты и страницы издательств — охраняются.
Рисуем свои глифы по методике; в интерфейсе стили называем нейтрально («американский
школьный», «британский связный»), без торговых марок. Каталог первоисточников —
`docs/research/handwriting/` (только ссылки, PDF в репозиторий не кладём).

## Открытые вопросы (решает владелец)

1. Разлиновка первой версии: английская четырёхлинейка, клетка или обе на выбор?
2. Первый режим: конструктор тетрадей для печати (как `print_letters`) или письмо на экране?
3. Возраст и уровень: дошкольники 4–6 (как `print_letters`) или школьники 2–4 класса?
4. Название темы в каталоге: «Латиница», «Английские прописи», другое?
