# SI — словенское школьное письмо (*šolska pisava*)

Язык: **Slovenščina**. Алфавит: 25 букв (22 общих с английским + Č, Š, Ž). Школьная традиция связного рукописного письма, не путать со стилизованным курсивным компьютерным шрифтом.

## Что фиксировать при переносе в собственный редактор прописей

Для каждой буквы A–Ž: отдельная заглавная/строчная форма, последовательность штрихов, положение надстрочного знака, старт/финиш, вход/выход, высота и нижние выносные элементы, варианты соединения с соседними буквами.

**Не делайте вывод, что gov.si содержит изображения всех форм букв:** текущие нормативы определяют образовательные цели; для начертаний нужны дополнительные школьные иллюстрации и пособия.
