# Mironium — школьные образцы рукописной латиницы

Дата проверки источников: 2026-11-05. **Это библиотека ссылок на первоисточники для методической разработки, а не набор шрифтов с лицензией на внедрение в приложение.**

| Профиль | Страна / система | Что изучать | Каталог |
|---|---|---|---|
| **SI — Slovenian school handwriting** | Словения, *slovenske pisane črke* | 25 букв, Č/Š/Ž, начальные и конечные штрихи, соединение, действующая программа 1–3 классов | [slovenian/](slovenian/) |
| **EN-US — Zaner-Bloser** | США | print / manuscript и связное *cursive*, заглавные/строчные, группы штрихов | [zaner-bloser/](zaner-bloser/) |
| **EN-GB — Nelson Handwriting** | Англия, Oxford University Press | letter families, joins, break letters, размеры, листы для тренировки | [nelson-uk/](nelson-uk/) |

**Примечание:** под «славянским» в текущем сравнении понимается *словенский* школьный почерк (латиница). Болгарское, русское и другие кириллические чистописания не смешаны с этими образцами.

## Структура и статус

В каждой папке есть `README.md` с перечнем источников и `sources.json` для автоматизации. В [zaner-bloser/](zaner-bloser/) уже имелся каталог американских образцов и отдельный загрузчик — он сохранён.

**Оригинальные защищённые PDF намеренно не копируются в публичный GitHub-репозиторий.** Даже если PDF можно бесплатно прочитать, издательские материалы нельзя автоматически перепубликовывать. У Zaner-Bloser есть ограничения на загрузку/хранение/распространение; Nelson Ready Reference прямо запрещает копирование и распространение без прав. Словенский учебный план имеет условия Attribution–NonCommercial–ShareAlike. Всегда изучайте условия у правообладателя.

Для личного исследовательского использования файлы открываются по прямым ссылкам, а PDF при разрешённом использовании можно скачивать из оригинальных источников; метаданные и адреса сохранены. **Не импортируйте PDF, изображения страниц или шрифты напрямую в Mironium.**

## Приоритет сопоставления

1. Алфавит и строчные буквы (профиль каждой буквы).
2. Заглавные буквы и начало/окончание траектории.
3. Соединения в словах (у Nelson имеются `break letters`).
4. Четырёхлинейная сетка, наклон и пропорции.
5. Раздельное хранение изображений букв, stroke order и правил ligature.

Рабочая схема: одно ядро генератора + стили `si-school`, `en-us-zaner-bloser`, `en-gb-nelson`.
