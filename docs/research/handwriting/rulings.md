## Что из этого следует

- **Две англоязычные традиции разлиновки, не одна.** Американская (Zaner-Bloser): три равные полосы, строчная
  = половина заглавной, линия строчных пунктиром. Британская (Nelson): полоса строчных крупнее, выносные ≈ ¾ её,
  пунктиром обе средние линии. Значит, разлиновка — свойство **стиля**, как и решено (`docs/latin-letters.md`).
- **Размер растёт вниз по возрасту, пропорция постоянна** (Nelson: строчная 6,0 → 5,1 → 4,3 мм с 1-го по 3-й
  год). Размер — настройка тетради, пропорция — данные стиля.
- **Наклон:** Nelson вводит 8° от вертикали с Pupil Book 3 (Ready Reference Guide); печатные ZB — прямые.
- **Словения:** нормативы (учебный план 1–3 и методические рекомендации 2026) линовку не задают; там только
  порядок: большие печатные → малые печатные (1–2 класс) → письменные (2 класс). Школьную линовку надо брать из
  школьных тетрадей/прописей, в списке источников их нет.
- **Российские английские прописи — пробел.** В `sources.json` их нет, а это основная аудитория. До них
  пропорции «русской английской четырёхлинейки» не подтверждены.

## Для рисования букв (следующие шаги)

- KSM manuscript upper/lower (ZB-style): форма, начало и порядок штрихов печатных букв, стрелки.
- KSM cursive upper/lower (ZB-style): курсив.
- Nelson Ready Reference Guide: формы Starter / Books 1–6 / с наклоном, печатные, заглавные; семьи букв
  (Set 1: c a o d g q s f e; Set 2: i l t u j y; Set 3: r n m h k b p; Set 4: v w x z) и группы соединений.
- Zaner-Bloser 2025 2C: базовые штрихи курсива (undercurve, downcurve, overcurve, diagonal).
