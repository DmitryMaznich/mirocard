# Части прописных букв («Что пишем» / «Штрихи») — передача для следующей сессии

Начато 2026-11-16, состояние на 2026-11-19 (прод 1.1.151, колоды `propis2` 0.7.1, `propis2_lang` 0.11.1).
Задача следующей сессии: **разрезать каждую русскую прописную букву (строчную и заглавную) на штрихи-элементы
школьной методики**, чтобы взрослый мог дать ребёнку писать только часть буквы. Владелец: «многие буквы
неправильно, давай позже отшлифуем разрезание» (2026-11-16) — поэтому в приложении нарезка прописных сейчас
**выключена**.

## Что уже работает (не переделывать)

- **Интерфейс.** Строка из одной буквы → её штрихи нажимаются: на компьютере в панели строки справа
  (`PartsPad`, раздел «Что пишем»), на телефоне — кнопка «Штрихи» в полосе над клавиатурой, буква во всплывающем
  окне (`PartsPicker`, `src/features/propis2/Propis2Editor.jsx`). Правила владельца: **никаких подписей, кнопок по
  штрихам, «Вся буква»** — только кликабельная буква; на месте невыбранного на листе **ничего не рисуется**.
- **Хранение.** `row.parts = { of, keep }`: `of` — буква, для которой выбирали; `keep` — индексы частей, которые
  пишем. Перепечатали строку другой буквой — выбор не действует (`model.js rowPartsOf`). В строку движка — флаг
  `#p0.2` (`pageToLines`, перед `#y<стиль>`).
- **Движок.** `src/handwriting/wordEngine.js`: `PARTS_FLAG`, `partsGlyphMap` (у буквы — `hiddenParts`),
  буква ставится целиком как обычно, потом режется на части (`splitIntoParts`), скрытые выбрасываются, у них нет
  стартовой точки. Выбранная часть стоит ровно там же, где в целой букве.
- **Печатные (стиль «Печатные», Илюхина)** — каждый штрих = часть, работает (тест `printStyle.test.jsx`).

## Что делать — сама разрезка

Всё в одном файле: **`src/handwriting/letterParts.js`**.

- Часть = кусок одного штриха глифа `{ stroke, from, to }` в долях длины пути (`piecePathD` режет ломаной по длине).
- Сейчас части берутся: печатные (`glyph.upright`) — штрихи; прописные — `glyph.partCuts?.[si]` (свой разрез,
  **пока ни у одной буквы нет**), иначе `autoCuts(d)` — но только если включено `setAutoCuts(true)` (в приложении
  `false`; стенд и тесты включают).
- `autoCuts` режет в **остром** развороте пера: вверху (поднялся по линии и пошёл вниз — и, палочка а) и внизу,
  только если перо снова идёт вверх по всей палочке (п т р). Круглый верх овала (о е с, чаша а) не режет.
  Пороги: `PROMINENCE 0.45`, `BOTTOM_PROMINENCE 0.85`, `TURN_COS -0.35`, `END_SHARE 0.1`.

**Текущая автоматика на картинке** (части разными цветами, число частей серым) —
`docs/mockups/propis2-parts/auto-cuts-lower-2026-11-19.png` и `…-upper-…png` (+ `.html`). С неё и начинать:
показать владельцу, по каждой букве записать, где резать.

Рекомендуемый путь (моё мнение, обсудить с владельцем в начале):
1. **Ручной разрез — данные, не код.** Автоматика не знает методики (например, у в её длинная петля, у з нижняя
   петля, у б флажок). Завести файл `tools/handwriting/cyrillic/part_cuts.json` — `{ "а": [[0.62]], "Б": [[], [0.4]] }`
   (по букве — массив по штрихам, в каждом доли длины, где резать) — и при сборке колоды
   (`scripts/build-propis2-deck.mjs`, где читается `wide.json`) класть его в глиф как `partCuts`. `wide.json` (формы
   букв) не трогать. `glyphMapOf` (`src/topics/renderers/propis2/pageTask.js`) передаёт поля глифа как есть, так что
   `partCuts` дойдёт до `letterPieces` без правок движка.
2. Подбирать доли на стенде (ниже), каждую букву — картинкой владельцу; принятое — в `part_cuts.json`.
3. Когда все буквы приняты — `autoCuts` можно удалить или оставить подсказкой для стенда; в приложении частями
   становятся только `partCuts`.
4. Методические элементы владельца уже описаны в `tools/propis2/parts/README.md` (лист 2026-10-29: «палка» из
   ножки р, «левая/правая» П, «шапка» Р, петля В, флажок К …) — это **те же элементы**, ими и проверять, где резать.

## Элементы и траектория — две техники письма (2026-11-19, начато с «р»)

Решено с владельцем: у буквы есть **элементы** (что остаётся на бумаге) и **траектория** (как по ним шло перо). Разрез
не меняет порядок и направление письма. Две техники над одними и теми же элементами:
- **безотрывно (по умолчанию, владелец так учил сына):** путь как в глифе; **возврат** (перо по бумаге по уже нарисованному —
  «р»: вниз по палочке, обратно вверх до средней линии, крючок — почти «г», от средней линии до средней линии) новой линии не даёт, в анимации — бегущее перо; точка начала одна;
- **с отрывом:** каждый элемент от своей точки начала; путь пера по воздуху между ними **не показывается** (владелец: «там закончилось и потом началось»).
Переносы по воздуху бывают и в безотрывном письме (владелец: такие буквы есть — какие, ещё не названо).

Данные — `tools/handwriting/cyrillic/letter_elements.json` (готовы и приняты: «р»; размечены «п» — как «р», палочка до нижней строки — и «и»: первая палочка с закруглением до средней линии, подъём от средней линии к верху идёт точно по второй палочке и считается возвратом — перо по линии элемента, который оно сейчас напишет; вторая палочка — от верхней линии): по штриху буквы `retrace: [[a, b]]` и `cuts: [a]`,
позиции — в сегментах пути от начала штриха (не в долях длины: так не зависят от растяжения глифа). Код —
`letterPaths` / `letterMoves(glyph, "joined" | "lifted")` в `src/handwriting/letterParts.js`, тесты
`src/handwriting/letterTrajectory.test.js`. Стенд-анимация: `node tools/propis2/parts-review/trajectory-sheet.mjs р > out.html`
(картинка «р п и» — `docs/mockups/propis2-parts/trajectory-2026-11-19.html`).

**Выравнивание элементов (владелец 2026-11-19: «у обоих штрихов верхние и нижние точки должны быть на одной линии»).** Правка
формы в `wide.json`, только внутри штриха — начало и конец (к ним идут соединения) не тронуты: у кривой растягиваются ручки вдоль
своих касательных, концы и направления на концах прежние. «и»: верх второй палочки 11,48 → 10 (по её же наклону), закругление первой
59,69 → 60,73 (как у второй); «п», «р»: верх крючка 12,17 → 11,12 (как у палочки). Проверка: слова разложены движком на старом и новом
`wide.json` — концы всех штрихов внутри слов совпали (≤ 0,004), соединения те же; слово с «и» в начале сдвигается целиком на 0,36.
Не сделано: верх палочки «п»/«р» (11,12) не поднят на верхнюю линию — это точка начала, к ней приходит соединение; «ц», «й» —
те же палочки, что у «и», не выровнены. В прод форма уйдёт только с пересборкой колоды `propis2`.

**В приложение не подключено.** Дальше: принять «р» у владельца → разметить остальные буквы → в движке строк не рисовать возврат
вторым слоем, выбор техники (тетрадь/строка), части «Что пишем» = элементы (сначала решить сдвиг индексов `row.parts`, см. ниже).
`partCuts` из плана выше заменяется этим файлом.

```bash
cp tools/propis2/parts-review/sheet.test.jsx.txt src/topics/renderers/propis2/zzParts.test.jsx
LETTERS="абвгдеёжзийклмнопрстуфхцчшщъыьэюя" OUT=$PWD/out.html npx vitest run src/topics/renderers/propis2/zzParts.test.jsx
rm src/topics/renderers/propis2/zzParts.test.jsx   # не коммитить
```
Берёт опубликованную колоду `propis2` из каталога. Чтобы стенд видел новый `part_cuts.json` до пересборки колоды —
либо пересобрать колоду, либо в тексте стенда подмешать `partCuts` к глифам перед `letterPieces`.
PNG из HTML — Playwright (`page.screenshot({ fullPage: true })`).

## Подводные камни

- **Индексы `keep` сдвинутся.** Сейчас у прописных из нескольких штрихов (б ё й к х э, А Б В Г Ё Ж З Й К Л М О П Р
  Т Ф Х Э Ю — по штрихам, без разреза) части = штрихи, и у пользователей уже могут быть сохранённые строки с
  `row.parts`. Как только у такой буквы появится разрез, номера частей поменяются и строка начнёт писать не то.
  Решение: хранить в `row.parts` число частей (`n`) или версию разреза и игнорировать выбор, если они не совпали
  (`rowPartsOf` в `src/topics/renderers/propis2/model.js`), — сделать **до** включения разрезов.
- **Буквы из элементов** (`glyph.compose`: ш = 6+6+6, ы) — частей нет (`partsGlyph` их пропускает в
  `Propis2Editor.jsx`). Отдельный вопрос владельцу: части = элементы сборки?
- **Части только у строки из одной буквы.** Слово/слог — «Штрихов» нет (так решено, не менять без владельца).
- **Соединения.** Часть режется по глифу буквы; соединение к следующей букве в строку из одной буквы не входит,
  но выход (хвостик) — часть штриха. Решить с владельцем, отдельная ли это часть.
- Разрез — ломаная по длине пути (`PER_SEGMENT 24` точек на сегмент): на крутых изгибах конец части может чуть
  «гранить»; при видимых углах — поднять плотность.
- Другие языки прописи (болгарский, казахский) берут те же русские глифы: разрез русской буквы подействует и там.
