# Варианты темы «Прописи» (propis2) — другой алфавит без форка кода

Начато 2026-10-18 по запросу болгарского пользователя: та же тема, но болгарская кириллица. Задача шире одного
пользователя: отрепетировать, как подготовить вариант темы под конкретного человека **без копии кода**. Критерий успеха:
второй вариант (например, украинский) делается без единой правки в `src/`, только данными.

## Как устроено

- **Вариант — это отдельная тема-ZIP с тем же рендерером `propis2`.** Свой id (`propis2_bg`), своя версия, своя запись в
  каталоге. Приложение выбирает рендерер, движок и экран конструктора по `meta.renderer`, а не по id
  (`App.jsx`, `useSessionEngine.js`, `SessionScreen.jsx`), поэтому код не копируется.
- **Кому видна:** статус `individual` в `public/decks/catalog.json`. Тему выдаёт на аккаунт администратор (выдача
  `beta`/`individual` тем, `backend/server.mjs`). Остальные её не видят.
- **Данные варианта:** `tools/propis2/variants/<id>/variant.json`. Сборка: `node scripts/build-propis2-deck.mjs --variant <id>`
  накладывает его на `tools/propis2/topic.json` + `tools/propis/wide.json` (`scripts/lib/propis2-variant.mjs`):
  - `meta` заменяет поля базы (renderer остаётся, добавляется `variantOf: "propis2"`);
  - `modes` — какие режимы базы оставить (по id);
  - `words` / `texts` — свои слова и тексты для диктанта (базовые русские не берутся; пустые не пишутся вовсе: пустой массив
    `texts` установщик принимает за тему чтения и отказывается её ставить);
  - `glyphs` — формы букв, которые отличаются: заменяют глиф базы с тем же `label` (или добавляются). Остальные буквы берутся
    из русского банка;
  - `catalog` — название, описание, статус и доступ для каталога.
- **Что читает рантайм** (`meta` установленной темы):
  - `meta.alphabet = { lower, noCapital }` → `src/topics/renderers/propis2/alphabet.js` (`topicAlphabet`). Из него берут буквы
    карточки «Узнай букву» / «Строчная и заглавная», диктант букв, плитки букв конструктора и алфавит на обороте обложки.
    Заглавная, для которой нет глифа, считается отсутствующей, поэтому пустая карточка не появится. Без `meta.alphabet` — русский
    алфавит, как было;
  - `meta.coverWords = { headings, signs, punctuation }` → слова на обороте обложки (`cover/backContent.js`), которые пишет ребёнок;
  - `meta.methodology: false` → не показывать готовые тетради «Методика» и комплекты (`kits.json`): они на русских буквах и словах.

## Болгарский вариант (`propis2_bg`) — состояние

v0.1.0 (2026-10-18), собран, статус `individual`:

- алфавит из 30 букв (без Ё, Ы, Э); Ь только строчная (стоит лишь в «ьо»);
- **Ъ** в болгарском — гласная, у неё есть заглавная. Но заглавной Ъ в банке глифов нет, поэтому пока она только строчная
  (отбрасывается автоматически). Когда её запишем, в `glyphs` варианта появится `Ъ`, и она станет заглавной без правки кода;
- режимы: конструктор, «Узнай букву», «Строчная и заглавная». **Диктанта нет**: нужны болгарские слова и тексты и озвучка на
  болгарском (сейчас ключи и записи — `/audio/propis-dictation/` на русском, `dictationAudio.js`). Чтобы его включить, нужна
  отдельная папка аудио варианта (`meta`-путь в `dictationAudioUrl`), это правка кода, ещё не сделанная;
- **все формы букв пока русские** (`glyphs: []`). Эталон получен (шрифт, см. ниже). Было: ждём фото болгарской прописи 1-го класса (все буквы, строчные и
  заглавные), затем таблица отличий, затем запись отличающихся глифов в инструменте записи (`handwriting_capture`), затем
  проверка соединений в `wordEngine` на словах;
- слова на обложке (`coverWords`) — черновик, **нужна проверка носителем**. «>»/«<» записаны как «голямо»/«малко», а не
  «по-голямо»/«по-малко»: в банке нет глифа дефиса внутри слова (есть только знак минус `№-`). Это пробел и русской темы
  («кто-то»).

### Эталон заказчика: шрифт Boyan Maga (2026-10-18)

Заказчик прислал TTF «Boyan_Maga-Regular» (89 глифов, все 60 болгарских букв есть; в таблице `name` нет ни лицензии, ни
автора). **Шрифт в репозиторий не кладём и в тему не встраиваем**, он только образец для глаза. Сравнение со всем нашим
банком: `docs/propis2-variants/bg-vs-ru-lower.png`, `bg-vs-ru-upper.png` (красное — шрифт, тёмное — наши глифы; ряды не
выровнены по базовой линии, сравнивать формы).

Вывод: это та же школьная пропись, что и наша, а не особое болгарское письмо. Отличаются:

| Буква | Что не так у нас | Что делать |
|---|---|---|
| **Ъ** (загл.) | нет вовсе | записать |
| **Ь** (загл.) | нет вовсе | записать, если нужна (в словах не встречается, только в азбуке); в `noCapital` её убрать |
| **ц, щ, Ц, Щ** | хвост у нас короткий крючок, у шрифта длинная петля вниз, как у «у» | записать заново как `glyphs` варианта |
| **Ф** (загл.) | у шрифта верх с флажком и стойка ниже строки | записать |
| П, Т, Д (загл.) | мелкая разница в начальном штрихе (у шрифта крючок слева на перекладине) | по желанию заказчика, это не ошибка |

Строчные, кроме ц и щ, совпадают с нашими. Итого надо записать 5–7 глифов. Шрифт даёт только контур, а не путь пера:
нет порядка штрихов, точки начала, соединений. Поэтому глифы нужно записать в инструменте записи, обвести контур шрифта не
получится. После записи проверить соединения ц, щ с соседними буквами на словах (`цвете`, `щъркел`, `лъжица`).

### Наклон и сетка (2026-10-18, замечание владельца)

- **Наклон другой.** По контуру шрифта стойки и, н, ш, п, т, И, Н, Ш, П, Т стоят под **77–78°** к горизонтали; у нас
  **65°** (`ANGLE_FROM_HORIZONTAL_DEG`, `propisRuling.js`). Разница 13°. Пропорции совпадают: заглавные ≈ 2 высоты строчной,
  выносные ≈ 1,1.
- **Сдвиг (shear) всех наших глифов до 78° даёт наклон шрифта:** `docs/propis2-variants/bg-slant-shear.png` (красное —
  шрифт, тёмное — наши, зелёное — наши со сдвигом). Сдвиг аффинный: если сдвинуть и буквы, и невидимую сетку наклонных, к
  которой движок привязывает буквы и соединения, все соединения сохраняются. Перезаписывать 60 букв не нужно.
- Чтобы это сработало, угол должен стать параметром темы (`meta.slantDeg`), а не константой модуля. Сейчас 65° зашиты
  примерно в 20 местах: `PrintPageView.jsx` (11), `SortCaseView.jsx` (4), `propisRuling.js` (3), `pathGeometry.js`,
  `glyphOverrides.js` (`SLANT 0,4663`).
- **Сетка.** В болгарских тетрадях нет наклонных линий, только горизонтальные. Нужен вид бумаги «строки без наклонных»:
  разлиновка строки как у прописи, наклонные не рисуются (буквы всё равно привязываются к невидимой сетке, как уже делается на
  «Линейке» и «Клетке»). Точное устройство болгарской строки (сколько линий, шаг в мм, какие жирные) — **ждём фото тетради от
  заказчика**.

## Что не входит в этот вариант (осознанно)

- Интерфейс остаётся русским: пользователь с ним справляется. Пакет варианта несёт только то, что видит и пишет ребёнок.
- Библиотека тетрадей **общая** с `propis2` (ключи `propis2:*`, `storage.js` / `syncLib.js`). Пока у пользователя одна из двух тем,
  это незаметно. Если у кого-то будут обе, его тетради появятся в обеих и будут написаны буквами той темы, в которой открыты.
  Разделять библиотеку (префикс по id темы) стоит, когда это кому-то реально помешает.
- Метки похожести букв для подбора неправильных вариантов (`tags` в `LETTER_DATA`) — русские. Для болгарских форм, которые
  будут другими, их, возможно, придётся переопределить в варианте; сейчас формы русские, и метки верны.

## Новая версия варианта

1. Поднять `meta.version` в `tools/propis2/variants/<id>/variant.json`.
2. `node scripts/build-propis2-deck.mjs --variant <id>` (ZIP + запись в каталоге).
3. Удалить ZIP прошлой версии (`git rm public/decks/<id>_v<old>.zip`), как и для остальных тем.
4. Тест: `npx vitest run src/topics/renderers/propis2/variant.test.js`: ставит собранный ZIP через настоящий установщик.
