# Parking game art, v1

Generated illustrated toy atlas for Mironium: three top-down cars (yellow, blue, coral) in the first row, matching garage entrances in the second row. Three columns, two rows; WebP dimensions 1152 × 768. The original generated PNG is preserved in the execution workspace. The game loads this atlas as a separate static asset rather than adding it to the single-file app bundle.

The desk bell image is generated. The bell sound is an excerpt of [desk bell center.mp3 by tonmayster](https://freesound.org/people/tonmayster/sounds/685111/). The source is licensed under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The excerpt is mono, trimmed to a single strike, and attenuated with a short fade at the end.
