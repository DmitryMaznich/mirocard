Подложки для обводки британских букв (Nelson Handwriting, Ready Reference Guide: «Books 1 to 6», заглавные и цифры).
Собраны tools/latin_letters/make_underlays.py, 62 файла: lo_a…lo_z (строчные), up_A…up_Z (заглавные), num_1…num_0 (цифры).

Как обводить в мастерской (tools/letter_capture/handwriting_capture.html):
1. «Фото-подложка» → выбрать файл. Масштаб 1, без сдвига: буква сама встаёт на линии.
   Строка = линия 5, высота строчных = линия 3, хвосты g j p q y f = линия 6, палочки b d h k l и заглавные — чуть ниже линии 2.
2. Выключить «Показывать образец-подложку для обводки» (это русская шрифтовая подсказка), «Прилипание к дугам» и «Дуги закруглений на сетке»:
   буквы прямые, наклонная сетка 65° не их. «Выравнивать по сетке» не включать.
3. Обводить своим движением пера: порядок и направление штрихов — как учат по Нельсону.
Пропорции тетрадей (выносные 0,74 / 0,72 вместо 0,86 на этой странице) применяются при сборке, обводить как есть.
