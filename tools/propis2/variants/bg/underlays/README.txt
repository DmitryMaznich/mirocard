Подложки Boyan Maga для обводки в инструменте записи (handwriting_capture / letter_capture)

1. В инструменте: «Фото-подложка» -> загрузить файл буквы. Масштаб оставить 1, смещение не трогать:
   подложка сама встаёт во вторую ячейку, строка на линии 5, верх строчных на 3, верх заглавных на 2.
2. Серое — буква шрифта (уже в нашем наклоне 65°: болгарский наклон 78° и пропорции тема добавит сама).
   Цветная линия — путь пера, который предложила программа; точки с цифрами — начало штрихов.
   Где он верный — повторить, где нет — вести по-своему.
3. Подпись буквы в инструменте — сама буква (к, К, ю, Ю ...). Входной штрих и выход шрифта обводить тоже:
   по ним буквы соединяются в словах.
4. Сохранить набор (экспорт JSON) и прислать — как с заглавной Ъ.

Файлы: lo_<буква>.png — строчная, up_<буква>.png — заглавная.
