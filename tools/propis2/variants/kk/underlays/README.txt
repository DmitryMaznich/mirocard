Подложки казахских букв для обводки в инструменте записи (tools/letter_capture/handwriting_capture.html)

1. В инструменте: «Фото-подложка» -> загрузить файл буквы. Масштаб 1, смещение не трогать:
   строка на линии 5, верх строчных на 3, верх заглавных на 2 (как у болгарских подложек).
2. Серое — буква с плаката, уже в нашем наклоне 65° и наших пропорциях. Плакат мелкий, контур размытый:
   это ориентир формы, а не точный трафарет. Ровность даст сглаживание при сборке.
3. Подпись буквы в инструменте — сама буква (ә, Ә, һ, Һ, І, у). Вход и выход обводить тоже:
   по ним буквы соединяются в словах.
4. Сохранить набор (экспорт JSON) и прислать.

Файлы: lo_<буква>.png — строчная, up_<буква>.png — заглавная.
  lo_ә, up_ә, lo_һ, up_һ, up_і — особые казахские буквы;
  lo_у — строчная у с петлёй (наша русская у без петли совпала бы с казахской ү).
Источник: два плаката алфавита от владельца (2026-10-29), в репозитории их нет. Сборка: make_underlays.py.
