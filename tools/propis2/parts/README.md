Куски собирает `build_part_candidates.py` (в натуральном размере глифа: движок сам уменьшает на узкой строке). Вход — штрихи глифов:
```js
// временный vitest в src/: dump.test.js
import { it } from "vitest"; import { readFileSync, writeFileSync } from "node:fs";
import { buildGlyphMap } from "./topics/renderers/propis2/pageTask.js";
const wide = JSON.parse(readFileSync("tools/propis/wide.json", "utf-8")).glyphs;
it("dump", () => { const map = buildGlyphMap({ wide }); const out = {};
  for (const l of "ПРВБГЛлУИЭХЖэхжбаЦЩФНКпрвг".split("")) { const g = map.get(l); if (g) out[l] = g.strokes.map((s) => s.d); }
  writeFileSync("/tmp/glyph_strokes.json", JSON.stringify(out)); });
```
`python3 tools/propis2/parts/build_part_candidates.py /tmp/glyph_strokes.json /tmp/new_elements.json`, затем глифы из `new_elements.json` добавить в `wide`
харнеса (`tools/propis2/dev/`) и посмотреть строками `row kind = "element"`.

**Статус:** формы 1–3, 7, 8, 12, 13, 15, 18, 19, 21 совпадают с образцами; 4, 5, 6, 10, 22 расходятся (см. таблицу), 14, 16, 20 близки, но границы куска не подтверждены.
