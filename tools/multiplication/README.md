# «Умножение» (`multiplication`) — тема в приложении

Методика, решения по ступеням и источники — `docs/multiplication-methodology.md`. Макет — `docs/mockups/multiplication-2026-11-26/index.html`.

- Версия 0.2.0 (2026-11-27): интерфейс «стол и полка» по `docs/multiplication-design-brief.md` (макет
  `docs/mockups/multiplication-2026-11-26/design-v2.html`): без колец, слова на кнопках, ошибка без красного, занятие — 8 заданий
  (`finite`, полоска из 8 яблок), видео в конце включает взрослый. Ошибка внутри задания — `onStreakReset`, не `onMistake`
  (тот перезапускает экран и стирает сделанное). 0.1.0 (тот же день) — первая версия, интерфейс отклонён.
- Каталог `beta` (видят только аккаунты, которым тему выдал администратор), доступ `free`.
- Четыре режима = ступени 0–3: `equal_check` «Поровну?», `make_equal` «Сделай поровну», `skip_count` «Считаем группами»,
  `sum_to_product` «Сложение → умножение». Код — `src/topics/renderers/multiplication/`.
- Многоязычная по контракту `docs/localization/authoring-language-rules.md` (как `comparison_language_pilot`):
  `ui/{ru,sl,en}.json` — тексты взрослому; `content/{ru,sl,en}.json` — реплики ребёнку, отдельным архивом на язык.
  Язык материала выбирается при установке темы и меняется в меню темы, не в настройках режима.
- **Запись умножения — часть языкового пакета** (`notation.sign`, `notation.order`): ru «3 × 4» = по 3, 4 раза (сначала
  сколько в группе); sl «4 · 3» = štirikrat po 3 (сначала сколько групп, знак точка); en «4 × 3» = four lots of 3.
  Словенский порядок — по словенским школьным сайтам (ucko.si, kveez.com); английский выбран по распространённому
  «groups of»; оба надо сверить с учебником ребёнка.
- Голоса записанного нет (`audio: "none"`). Реплики читает голос браузера **только на языке материала**: если на устройстве
  нет словенского голоса, словенское занятие молчит, а не читается русским голосом (`voice.js`).
- Уровень: параметр режима `level` — «Сам по успехам» (`auto`: начинает с последнего достигнутого уровня этого ученика на
  этом устройстве и меняет его по правилу из методики) или фиксированный уровень на всё занятие (`levelStore.js`).
  Задание = зерно (`seed`), из которого экран строит упражнение для текущего уровня (`mechanics.js`).
- Фото тарелки, яблока, банана вшиты в код (`assets.js`); коробки с яйцами нарисованы — нужны фото (`docs/multiplication-shotlist.md`).

Сборка: `node tools/multiplication/build.mjs` (ядро + архив на каждый язык, обновляет `catalog.json`).
Проверка: `npm run topics:validate-languages`, `npx vitest run src/topics/renderers/multiplication`.
Тема требует приложение ≥ `meta.minAppVersion` — без поднятой версии приложения установка падает с «Не удалось установить языковой пакет».
