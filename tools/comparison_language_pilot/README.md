# Изолированный языковой пилот «Сравнения»

Это отдельная тема `comparison_language_pilot`, скопированная с двух первых режимов
`comparison` 2.37.0 (основание записано в `topic.json → sourceCopy`): визуальные
количества и сравнение чисел с крокодилом. Остальные шесть режимов пока не входят в пилот. Исходная тема, её ZIP, параметры и история
не изменяются. CSS, renderer, engine, карточки и пространство хранения свои.

- `ui/ru.json`, `ui/sl.json`: название, методика и подписи параметров взрослого.
  Семантические ключи строятся из постоянных ID режима и параметров.
- `content/ru.json`, `content/sl.json`: целые учебные реплики, подсказка равенства,
  доступное имя ответа и учебный результат. У пакетов свои ID и версии.
- `languageContract.packages.*.modeIds`: фактическая доступность по режимам.
- Язык материала выбирается в модальном окне при скачивании темы. В окне показаны
  нативные названия языков, доступные режимы, наличие речи и фактический размер
  недостающих файлов. Выбор хранится для пары ученик/тема и действует во всех режимах.
  Изменение доступно в меню темы и на её главном экране, а не в параметрах режима.
  Предпочтение ученика выше предпочтения аккаунта; сохранённый выбор выше обоих.
- Контекст языка/пакета фиксируется в состоянии занятия и
  `statistics.conditions.languageContext`, проходит через сохранение и историю.
  Другая версия пакета или другой язык не восстанавливают старую очередь.
- Версия 0.3: общий ZIP содержит renderer, нейтральную графику и небольшие
  UI-словари RU/SL. Учебный материал каждого языка — отдельный ZIP. Скачивается
  только выбранный язык; общая основа и скачанные пакеты переиспользуются на устройстве.
  Исходники одной темы и одни математические навыки остаются общими.
- Контракт поддерживает текст, языковые изображения и записанную речь с явными
  путями, размером и SHA-256. В версии 0.4 русским пакетом озвучена подсказка после ошибки; словенский без речи; обычные сигналы
  правильного/неправильного ответа остаются общими.
- Словенские формулировки перепроверяет исполнитель: грамматика, естественность
  и точное соответствие условию и ответу. Пользовательская вычитка не является
  условием продолжения работы. См. [языковую вычитку](../../docs/localization/pilot-sl-language-review.md).
- Загрузка и проверка завершаются до атомарной замены файлов/метаданных в IndexedDB.
  Ошибка загрузки или транзакции сохраняет предыдущую рабочую тему. История и
  настройки ученика не удаляются; начатое занятие сохраняет свой язык.

Сборка: `node tools/comparison_language_pilot/build.mjs`.
Проверка исходников и опубликованного ZIP: `npm run topics:validate-languages`.
Регрессии: `npx vitest run src/topics/renderers/comparison_language_pilot/pilot.test.jsx`.

В каталоге пилот скрыт и доступен через существующий `catalog_all_access`.
Для ручной проверки можно скачать бесплатный ZIP
`/decks/comparison_language_pilot_v0.4.0.zip` и импортировать в «Темы → + ZIP».
После выбора ZIP открывается то же окно выбора языка, затем загружается только его пакет.
Скрытость в каталоге не является ограничением скачивания бесплатного архива.
Автоматической установки и копирования прогресса оригинала нет.

Принятие пилота не означает готовности всех экранов приложения или остальных
тем на словенском. Следующий шаг — перенос остальных режимов в эту копию по одному с языковой
вычиткой и проверкой реальных сценариев.

Версия 0.2 хранит параметры по режимам. У первого режима явно включено чтение
старых общих параметров 0.1 до первого сохранения новых. Параметры другого режима
и история сохраняются. Каждый режим ограничен своей metadata-карточкой; ответы
с крокодилом не повышают уровень визуального режима. RU/SL внутри одного режима
продолжают относиться к одному математическому навыку. При импорте обновления
кэш renderer этой темы сбрасывается.


Подробный протокол и ограничения: [раздельная загрузка](../../docs/localization/topic-language-download.md).


Обновление 0.4 / приложение 1.0.2675: русский пакет содержит существующую запись
«Посмотри ещё раз» из `public/audio/addition-subtraction/phrases/look_again.mp3`.
Это озвучка подсказки после ошибки в обоих режимах, а не всех заданий. Исходный
банк и его записи не изменены. Файл включён только в RU ZIP под
`content/ru/0.4.0/retry.mp3`; SL остаётся без речи. Каталог и окно выбора явно
показывают частичный охват (`audioScope: feedback`). Генерация новых голосов
и браузерный TTS не используются. Исходная запись взята из действующего банка;
это не заявление о новой пользовательской приёмке её произношения.

Задача закрепляет путь записи из своего языкового пакета. После неверного ответа
renderer вызывает стандартное воспроизведение файла темы из IndexedDB; выключенный
звук запрещает речь. Смена UI/языка темы не подменяет запись начатой задачи.
Записи сопоставляются с текстовыми ключами через `recordings`, ссылки валидируются
на объявленные аудиоресурсы. Для проверки выбрать русский, начать любой из двух
режимов и дать неверный ответ; повторить без сети. При словенском должны остаться
только обычные сигналы ответа, русская фраза звучать не должна.
