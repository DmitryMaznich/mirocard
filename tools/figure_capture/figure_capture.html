Мастерская фигур

▦

1. Растровая подложка

Сначала подберите общий масштаб, затем при необходимости растяните растр отдельно по X или Y. Верхний левый угол подложки остаётся на месте.

2. Сетка

Меньше шаг — клеток на полотне больше; больше шаг — клеток меньше. Сетка видна всегда.

Сетка готова.

Точное положение сетки — по 2 пикселя за нажатие.

3. Карточка

Выберите один файл из tools/symmetry_draw/figures. Идентификатор и режим сохраняются, меняется только вектор фигуры.

Итоговая карточка: 20 × 10 клеток; граница после 10-й клетки.

4. Обводка

Все инструменты находятся в панели над сеткой. «●» ставит отдельную точку размером с узел; узел или точку можно перетащить либо удалить.
